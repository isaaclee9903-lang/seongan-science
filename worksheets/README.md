# 라스 종이 학습지 (시범)

RAS 수업(`lessons/`)과 수업 발표(`presentations/`)를 바탕으로 만드는 A4 흑백 종이 학습지. 차시마다 2~3쪽, 나중에 묶어서 책으로 만든다.

- 근거 조사: `reports/학습지 지면 디자인 원리.md` (끝의 "학습지 디자인 기준 초안" 41항목)
- 공통 틀: `_ws.css`(인쇄 틀), `_fig3d.js`(입체 선 그림) — 여백 위 15·오른쪽 15·아래 17·왼쪽(묶는 쪽) 20mm, 본문 명조 10pt, 제목·문제는 Pretendard, 회색은 10%(글자 뒤)·20%(그림 면)만
- 차시: `<이름>/index.html` 하나에 학생판과 교사판이 같이 들어 있다. 주소 끝 `?teacher=1`이면 정답이 보이고 끝에 "정답과 해설" 쪽이 붙는다(쪽 나뉨은 학생판과 같음)
- PDF 뽑기: `python tools/worksheet/make_pdf.py <이름>` → `<이름>/<이름>-학생.pdf`, `<이름>-교사.pdf` (검사용 쪽 그림은 `--png 폴더`)

## 쪽을 꽉 채우는 법 (2026-11-08 코일이 받는 힘에서 정함)
- 선생님 기준: **쪽 아래에 불필요한 빈 곳이 없게 하는 것이 최우선.** 한 갈래가 다음 쪽으로 넘어가는 것은 괜찮다. 차시당 최대 4쪽.
- 쪽마다 `<div class="page">…</div>`로 묶는다. `make_pdf.py`가 쪽마다 찬 높이를 mm로 알려 준다(판면 265mm, "남음 10mm 이하"가 목표, "넘침"이면 그 쪽 내용이 다음 쪽으로 밀림).
- 문제 2단은 자동 2단(`.qs`) 대신 `.qcols`(왼쪽 단·오른쪽 단을 직접 나눔)로 쪽마다 짠다. 두 단 높이를 비슷하게 맞춘다.
- 빈 곳은 그림 폭(`--figw`, `--maxw`), 답 줄 수(`--n`), 표 칸 높이(`--rh`)로 메운다. 내용을 억지로 늘리지 말고, 늘릴 때는 RAS·발표에 있던 활동(연습 문제, 생각 멈춤)을 가져온다.
- 교사판은 학생판과 줄 높이가 똑같아야 한다(정답을 굵게 하지 않고 색·밑줄로, 예시 답안은 답 줄 위에 겹침).

## 입체 그림 도구 `_fig3d.js`
- 3D 좌표(x 오른쪽, y 위, z 앞)로 상자·말굽자석·구리선·화살표를 놓으면, 비스듬히 내려다본 흑백 선 그림(빛 방향 하나, 면 명암)으로 그려 준다. 예: `worksheets/motor-force/index.html`의 `swing()`(전기 그네), 전동기, 오른손.
- 그리는 순서 = 부른 순서(먼 것부터). 교사판에만 보일 요소는 `cls:'ans-fig'`.

## 만드는 규칙
- 내용은 그 차시의 `curriculum/` 기준 문서 범위 안에서만. RAS 읽기·발표의 문장을 학습지 말투(~다)로 줄여 쓴다.
- 그림은 RAS 그림의 구도를 따르되 **흰 바탕 선 그림 SVG로 다시 그린다**(검은 우주 바탕·색 구분은 흑백 복사에서 뭉개짐). 색 대신 실선·점선·빗금·회색 20%로 구분한다. 컬러본은 같은 그림에 색만 입힌다.
- 쪽 구성: 1쪽 개념(그림 + 빈칸 + 개념 상자 + 해 보기) → 2쪽 탐구(과정·결과 표·정리) + 다음 개념 → 3쪽 남은 개념 + 확인 문제(객관식 → 자료 해석 → 서술형, 2단).
- 빈칸은 `<span class="bl" style="--w:16mm"><i>정답</i></span>`, 객관식 정답은 `<li class="ok">`, 서술형 예시 답안은 `<div class="lines" style="--n:3"><div class="ex">…</div></div>`.
- 보고 전에 PDF를 쪽 그림으로 뽑아 확대해서 이름표 겹침·쪽 넘침을 본다.

## 아직 정하지 않은 것
- 책 묶기(목차·홀수 쪽 시작·쪽 번호 이어 붙이기), 컬러본
- 학교 복사기에서 회색 10%·20%와 0.3pt 선이 남는지 (시험 복사 필요)
- 교사판 PDF를 공개 저장소에 둘지 (지금은 PDF를 올리지 않음)
