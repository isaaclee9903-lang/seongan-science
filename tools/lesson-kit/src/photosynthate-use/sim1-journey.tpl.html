감자까지 양분의 길

잎에서 만들어진 양분이 어떻게 감자에 저장되는지 차례대로 따라가요.

입자의 수와 크기, 시간은 줄여서 보여 주는 모형이에요
1낮에 잎의 엽록체에서 포도당을 만들어요.
2포도당을 녹말로 바꾸어 저장해요.
3밤이 되면 녹말을 설탕으로 바꿔요.
4설탕을 체관으로 각 기관에 운반해요.
5운반된 양분을 쓰고, 남은 것은 저장해요.
결과
  1. 1포도당은 녹말로 바뀌어 엽록체에 저장돼요.
  2. 2녹말은 물에 잘 녹지 않아요. 그래서 물에 잘 녹는 설탕 형태로 바뀌어 운반돼요.
  3. 3설탕은 밤에 체관을 통해 식물의 각 기관으로 가요.
  4. 4운반된 양분은 호흡으로 에너지를 얻거나, 몸을 구성하는 성분이 되어 생장하는 데 쓰여요.
  5. 5쓰고 남은 양분은 열매, 줄기, 뿌리, 씨 등에 저장돼요. 감자는 줄기에 녹말로 저장한 것이에요.
