원소 기호와 화학식

원소 이름에서 글자를 골라 원소 기호를 만들고, 화학식을 보고 어떤 원소로 이루어졌는지 찾아봐요.

위 카드에서 원소를 골라요
원소 기호 규칙 (베르셀리우스가 제안한 것을 바탕으로)
1라틴어나 영어로 된 원소 이름의 첫 글자를 알파벳의 대문자로 나타내요.수소 Hydrogen → H · 탄소 Carbon → C
2첫 글자가 같을 때는 중간 글자를 택하여 첫 글자 다음에 소문자로 나타내요.헬륨 Helium → He · 염소 Chlorine → Cl
결과이름에서 글자를 눌러 기호를 만들어요. 처음 누른 글자는 대문자, 다음 글자는 소문자로 들어가요.

그림은 원소로 된 물질의 모습을 그린 것이에요. 수소·질소·산소는 색이 없는 기체, 염소는 황록색 기체예요.

2. 이 물질은 어떤 원소로 이루어졌을까? 모두 골라요
결과화학식 속 원소 기호를 보고 원소를 골라요.

물질을 원소 기호와 숫자로 나타낸 것을 화학식이라고 해요.

원소 기호와 화학식을 사용하면 다른 언어를 사용하는 사람들도 물질을 이루는 성분을 쉽게 알 수 있어요. 그래서 정보를 편리하게 교환할 수 있어요.

도로 표지판이 간단한 기호로 내용을 빠르게 전달하는 것과 같아요. '물'을 영어, 중국어, 스페인어로는 다르게 부르지만, 화학식은 어디서나 H2O예요.

입자 모형의 크기와 색은 보기 좋게 정한 모형이에요. 화학식 속 숫자의 뜻은 다음 시간에 배워요.
