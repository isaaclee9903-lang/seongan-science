# 종이 학습지 만들기 (RAS 수업 → A4 흑백 학습지)

학생에게 인쇄해 나눠 주는 학습지다. 차시마다 하나씩 만들고, 나중에 모아 책으로 묶는다. 2026-11-08에 두 차시를 만들어 틀을 정했다. 기준 예시는 아래 두 개다.
- `worksheets/parallax/` 별까지의 거리 (3쪽, 첫 시범. 선생님 "너무 마음에 든다")
- `worksheets/motor-force/` 자기장 속 코일이 받는 힘 (4쪽, 쪽 채우기 방법과 입체 그림 도구를 여기서 정함) ← **새 차시는 이 파일을 복사해서 시작**

## 0. 먼저 읽을 것 (건너뛰지 않는다)
1. `worksheets/README.md` — 틀 사용법, 쪽 채우는 법, 그림 도구
2. `reports/학습지 지면 디자인 원리.md` 끝의 "학습지 디자인 기준 초안" (여백·글자 크기·회색 단계·선 굵기의 근거)
3. 해당 단원 `curriculum/` 기준 문서 — **범위를 넘지 않는다**(`CLAUDE.md` 최우선 규칙). "사용 금지" 항목(법칙 이름, 공식, 계산)은 문제에도 넣지 않는다
4. 그 차시의 RAS 수업 글(`lessons/<수업>/reading.html`, 정리 페이지)과 발표(`presentations/<수업>/index.html`) — 글에서 흐름·빈칸·생각 멈춤·오개념·퀴즈를, 발표에서 연습 문제·확인 문제를 가져온다. RAS나 발표가 없으면 먼저 선생님께 여쭌다

## 1. 정해진 것 (선생님 결정, 2026-11-08)
- **A4, 흑백 복사 기준.** 잘 되면 나중에 컬러본(같은 그림에 색만 입힘)
- **교사용 정답판은 따로.** 같은 HTML을 주소 끝 `?teacher=1`로 열어 뽑는다. 정답은 라스 파랑, 끝에 "정답과 해설" 쪽이 붙는다
- **차시당 최대 4쪽**, 분량에 따라 2~4쪽으로 조절
- **쪽 아래에 불필요한 빈 곳이 없게 하는 것이 최우선.** 선생님이 좋아한 점: "쪽마다 내용이 꽉 차 있고, 1번 설명이 1쪽에서 2쪽으로 안 끊김". 다만 갈래(개념)가 다음 쪽으로 넘어가는 것은 괜찮다. 그림·표·문제 하나가 쪽 경계에서 잘리면 안 된다
- 디자인은 잘 팔리는 문제집의 공통 원리(개념 → 바로 확인 → 탐구 → 객관식 → 서술형)를 따르되 특정 업체를 베끼지 않는다
- 말투는 "~다"(학습지체). RAS의 "~요", 발표의 "~함"을 바꿔 쓴다
- 제작자 표기 없음. 머리 오른쪽에는 반·번호·이름 칸 대신 그 차시 수업 페이지 QR(15mm, `.ws-qr`, "태블릿 수업 페이지 / 읽기 · 가상 실험"). 2026-11-10 선생님 결정: 한 권으로 묶어 이름은 앞표지에 쓰고, 학습지와 수업 페이지를 잇는다. QR은 `segno`로 만든 선 그림(주소 `…/lessons/<수업>/`, 오류 정정 M), 뽑은 뒤 `cv2.QRCodeDetector`로 읽히는지 확인

## 2. 쪽 구성 (기본형, 분량 따라 바꿈)
1쪽 머리(차시 번호·제목·학습 목표) → 개념 갈래(글 + 그림 + 빈칸 + 개념 상자) → 탐구(과정, 결과 칸)
2쪽 다음 개념 갈래, 잘못된 생각 바로잡기, 규칙 찾기와 연습
3쪽 남은 개념 + 확인 문제 시작
4쪽 확인 문제(객관식 → 자료 해석 → 서술형) + 한눈에 정리(빈칸 표)
- 갈래 제목은 검은 네모 번호 + 굵은 고딕. 개념 상자는 왼쪽 회색 머리 칸 + 오른쪽 내용
- 빈칸은 교과서 낱말이 답이 되게. 서술형에는 넣을 낱말 조건이나 채점 요소를 정해 둔다
- 문제는 차시당 7~11개. 객관식 선지 ①~⑤, 합답형은 <보기> ㄱ·ㄴ·ㄷ

## 3. 그림
- RAS 그림을 그대로 붙이지 않는다. 검은 우주 바탕, 색으로만 나눈 표시는 흑백 복사에서 뭉개진다. **RAS 구도를 따라 흰 바탕 선 그림 SVG로 다시 그린다.** 색 대신 실선·점선·빗금·회색 20%로 구분한다
- 평면 그림(배치도, 각, 하늘 사진)은 SVG를 직접 쓴다(`parallax` 예)
- 장치·입체(자석, 코일, 실험 기구)는 `worksheets/_fig3d.js`로 3D 좌표에 놓고 그린다(`motor-force`의 `swing()`, 전동기, 오른손 예). 빛 방향 하나로 면 명암이 자동으로 들어간다
  - 보는 각(`yaw`, `pitch`)은 **핵심 방향이 한눈에 읽히게** 고른다. 예: 말굽자석은 옆에서 본 'ㄷ' 모양이 보이게 yaw 66°로 해서 안쪽=왼쪽, 바깥쪽=오른쪽이 되게 했다. 가리는 기둥은 가는 막대로, 가리는 면은 반투명(`alpha`)으로
  - 결과·답이 되는 화살표는 `cls:'ans-fig'`(교사판에만 보임)
- 같은 장치를 조건만 바꿔 여러 칸으로 보여 주면(결과 네 경우, 연습, 문제 그림) 그림 함수 하나를 옵션만 바꿔 다시 쓴다
- 그림 아래 "그림 n" 설명. 교과서 그림을 바탕으로 했으면 그림 번호를 적고, 과장했으면 과장했다고 적는다

## 4. 만들기
1. `worksheets/motor-force/index.html`을 `worksheets/<수업이름>/index.html`로 복사한다. 머리(`@page` 머리말 글, 차시 번호·제목·목표)와 본문을 바꾼다
2. **쪽마다 `<div class="page">`로 묶는다.** 한 묶음 = 인쇄 한 쪽이다
3. 확인 문제의 2단은 `.qcols`(왼쪽 단 / 오른쪽 단)로 **쪽마다 직접** 나눈다. 자동 2단(`.qs`)은 단 균형이 흔들려 쓰지 않는다. 문제 번호는 왼쪽 단 위→아래, 오른쪽 단 위→아래 순서
4. PDF 뽑기: `python tools/worksheet/make_pdf.py <수업이름> --png <scratchpad 폴더>`
   - 쪽마다 찬 높이가 나온다(판면 265mm). **목표: 모든 쪽 "남음 10mm 이하", "넘침" 없음**, 학생판·교사판 쪽 수가 같고(교사판은 정답과 해설 쪽만 더함)
   - 빈 곳은 그림 폭(`--figw`, `--maxw`), 답 줄 수(`--n`), 표 칸 높이(`--rh`)로 메운다. 그래도 크게 비면 RAS·발표에 있던 활동(연습 문제, 생각 멈춤, 확인 문제)을 가져와 채운다. 억지 내용은 넣지 않는다
   - 문제 단 높이는 `python tools/worksheet/measure.py worksheets/<수업이름>/index.html`로 재서 두 단을 맞춘다(쪽·단·문제마다 mm)
   - 넘치면 그 쪽의 그림을 조금 줄이거나 답 줄을 줄인다. 한 번에 한두 값만 바꾸고 다시 잰다
5. 교사판이 학생판과 줄 높이가 달라지면 쪽 나뉨이 어긋난다. 정답 표시는 굵게 하지 않고 색·밑줄로, 예시 답안은 답 줄 위에 겹친다(틀에 이미 되어 있음). 새 요소를 넣을 때도 지킨다

## 5. 보고 전 점검 (쪽 그림을 확대해서 본다)
1. 모든 쪽 아래 빈 곳이 10mm 이하인가? 그림·표·문제가 쪽 경계에서 잘리지 않았나? 갈래 제목만 쪽 끝에 홀로 남지 않았나?
2. 그림 속 이름표가 선·다른 글자와 겹치지 않나? (전체 쪽 그림만 보지 말고 그림 부분을 잘라 확대)
3. 흑백으로 봐도 구분되나? 회색 바탕 위 글자는 10% 이하 회색인가?
4. 교사판: 빈칸 정답, 객관식 정답, 서술형 예시 답안, 그림 속 답 화살표가 모두 보이나? 정답과 해설에 채점 요소가 있나?
5. 교육과정 범위를 넘는 용어·공식·계산이 없나?
6. 공통 틀(`_ws.css`, `_fig3d.js`)을 고쳤다면 다른 차시도 다시 뽑아 쪽 수가 그대로인지 본다

## 6. 저장·보고·게시
- PDF는 저장소에 올리지 않는다(`.gitignore`, 교사판 정답 때문). 선생님께는 학생판·교사판 PDF를 파일로 보내 드린다
- 같은 폴더를 여러 세션이 쓰므로 브랜치를 바꾸지 않는다. scratchpad에 main에서 만든 작업 사본(`git worktree add`)에 내 파일만 복사해 `claude/` 브랜치로 커밋·푸시한다
- 보고에 쪽 구성 표, 쪽마다 찬 높이, 그림을 어떻게 다시 그렸는지, 선생님이 확인할 것(교과서 그림과 다를 수 있는 점, 실제 수업에서 하는 활동인지)을 적는다
- 게시(main 병합)는 선생님이 "게시해"라고 할 때만 한다

## 6½. 단원 속지(내지)와 한 권 묶기 (2026-11-09 Ⅷ 별과 우주에서 정함)
선생님 요청: 대단원·중단원마다 속지 한 장씩, 그리고 대단원 하나를 "속지 + 차시 학습지" 한 PDF로. 기준 예시: `worksheets/divider/` (Ⅷ 대단원 1장, 중단원 2장).
- **파일 하나에 자료만 더한다.** `worksheets/divider/index.html` 위쪽 `UNITS`에 대단원 한 묶음(`kind:'unit'`, 로마 숫자, 이름, 단원 질문, 소개 글, 그림, `parts`)과 중단원 묶음(`kind:'part'`, 번호, 이름, 소개 글, 그림, 핵심 낱말, `lessons[]`)을 넣는다. `lessons[]`의 `ws`는 `worksheets/` 아래 차시 폴더 이름
- 주소 끝 `?d=8`(대단원), `?d=8-1`(중단원)로 한 장씩 열린다
- **쪽 짜임(바꾸지 않는다)**
  - 대단원: 머리줄(중2 과학 학습지, 2026-11-09부터 "라스" 뺌) → 큰 로마 숫자 + "대단원" + 이름 → 굵은 줄 → 단원 질문(명조 16pt) + 소개 글 → 큰 그림 → 차례(중단원 2단, 차시 번호와 질문)
  - 중단원: 머리줄 → 검은 네모 번호(학습지 갈래 번호를 크게) + 이름 → 소개 글 → 큰 그림 → 핵심 낱말 줄 → 차시 표(차시·질문과 학습 목표·공부한 날·스스로 점검 ○△✕)
  - 쪽 번호·머리말 없음. 학습지와 같은 여백·서체·검정과 회색 두 단계만. 라스 파랑도 쓰지 않는다
- **글:** 단원 질문과 학습 목표는 교과서 표현 그대로(교과서 파일의 대단원·중단원 도입 쪽, `curriculum/` 학습 목표). 소개 글은 새로 쓰고(교과서 문단을 베끼지 않음), 핵심 낱말은 기준 문서 '용어'에서 고른다
- **그림:** 단원마다 새로 그린다(`FIG.<이름>` 함수, 흰 바탕 선 그림·점묘, 씨앗 있는 난수로 늘 같은 그림). 대단원은 단원 전체를 아우르는 장면(Ⅷ: 북두칠성·은하수·천문대가 있는 밤하늘), 중단원은 그 중단원의 대표 활동이나 모형(Ⅷ-1: 교과서 활동 별자리 입체 모형, Ⅷ-2: 우리은하 위·옆 모습). 수치는 기준 문서에 있는 것만. 이름표는 흰 테(`paint-order="stroke"`)로 점·선과 떼어 놓는다
- **묶기:** `python tools/worksheet/make_book.py <대단원 열쇠> [--remake] [--png 폴더]` → 속지 PDF와 `worksheets/<로마 숫자>-<이름>-학생.pdf`, `-교사.pdf`(책갈피 대단원 > 중단원 > 차시). 학습지가 아직 없는 차시는 건너뛰고 알려 준다. 차시 학습지를 고쳤으면 `--remake`
- **점검:** 속지가 한 쪽에 들어가는가(도구가 알려 줌), 쪽 그림을 확대해 이름표 겹침, 학습지 머리의 차시 번호가 속지 차례와 맞는가(Ⅷ에서 우리은하가 03으로 잘못 붙어 있던 것을 묶다가 찾음), 학습지 머리 `ws-unit`에 중단원 이름이 들어 있는가
- **표지와 한 학기 한 권 (2026-11-09 선생님 결정):** 두 대단원(Ⅶ·Ⅷ)을 한 권으로, 앞표지·뒷표지를 붙인다. `UNITS`의 `front`(kind:'cover', 학년도·학기, 제목 "2학년 과학 학습지", 대단원 목록, 그림: 2026-11-10부터 기하학 칸 격자 `FIG.tiles` 5×5, 검정·회색 20%·흰색, 속지 그림을 다시 쓰지 않음)와 `back`(kind:'back'). "라스"는 쓰지 않는다. 학교 로고는 흑백으로 바꾼 `worksheets/divider/seongan-logo.png`를 작게(앞표지 오른쪽 아래 13mm, 뒷표지 아래 가운데 9mm). 뒷표지는 로고와 학교 이름만(1안). 묶기 `python tools/worksheet/make_book.py 7 8 --cover front [--remake]` → `worksheets/2학년-과학-학습지-학생.pdf`·`-교사.pdf`. 양면 인쇄용으로 앞표지 뒤·뒷표지 앞에 빈 쪽, 전체 짝수 쪽
- 아직 안 정한 것: 쪽 번호를 책 전체로 이어 붙일지(지금은 차시마다 1부터), 차시를 홀수 쪽에서 시작할지
