# 호흡(breathing) 전면 수정: 교과서 문장 대조표 (2026-11-08)

교과서: 중학교 과학 2(임성숙) 212~215쪽, 225쪽 스스로 정리, 227쪽 단원 마무리 3번, 313~314쪽 정답. 고치기 전(옛 수업)과 고친 뒤를 문장 단위로 견줌.

## 1. 본문 문장

| 교과서 문장(쪽) | 고치기 전 | 고친 뒤 |
|---|---|---|
| 달리기를 하면 호흡이 가빠지며 숨을 빠르게 들이쉬고 내쉬게 된다(212) | 첫 화면 한 줄 | 첫 화면 + 가슴 3D '달리기 뒤처럼' 빠르게 숨쉬기 |
| 산소를 받아들이고 이산화 탄소를 내보낸다, 호흡계 정의, 코·숨관·숨관가지·폐(212) | 글만 | 글 + 그림 ① 호흡계 3D 영상(코부터 공기 알갱이) + 정리 2 그림 번호 문제 |
| 콧속 → 숨관 → 숨관가지 → 허파꽈리(212) | 글만 | 글 + 그림 ①, 퀴즈 ① 1번(그림 번호 차례) |
| 폐는 포도송이처럼 생긴 수많은 허파꽈리(212) | 글만 | 글 + 그림 ② 허파꽈리 송이 3D 영상 |
| 허파꽈리는 한 겹의 얇은 세포층, 주변을 모세혈관이 둘러쌈(212 그림 설명) | **빠짐** | 읽기 ① 글, 그림 ②, 기체 교환 단면에 '한 겹의 얇은 세포층' 이름표 |
| 가로막은 가슴과 배의 경계에 있는 근육으로 된 막(212 그림 설명) | **빠짐** | 용어 풀이, 퀴즈 ① 4번, 가슴 3D 확인하기 4번 |
| 허파꽈리가 많아 유리한 점(212 질문, 답 314·225) | 답만(교과서 쪽 근거 미확인) | 생각 멈춤 + 큰 주머니/작은 주머니 그림, 퀴즈 ① 3번, 정리 4(225쪽 융털·허파꽈리), 글쓰기 주제. 근거 314쪽 "표면적이 넓은 형태로 되어 있어 물질 이동에 유리" |
| "그렇다면 공기는 어떻게 폐 속으로 드나들 수 있을까?"(212) | **빠짐** | 읽기 ① 끝 문장 |
| 탐구 준비물·활동하기 1~4·(가)(나)·정리하기 1~4·주의 문장(213) | 조작 2버튼만, 만들기·정리하기 1~4 없음 | 모형 실험실: 만들기 1~3(준비물 칩, 안전, 풍선 여러 번 불기 팁), 조작하기 4(가)(나), 정리하기 1~4 그대로. 읽기 ② 영상 |
| 폐에는 근육이 없어 스스로 수축·이완 못함, 갈비뼈·가로막 → 흉강·폐 부피 → 압력(214) | 글만 | 글 + 그림 ④ 실제 갈비뼈·가로막 3D(누르면 1~4 차례) |
| 그림 Ⅵ-13 네 단계(들숨/날숨)(214) | 두 칸 글 | 그림 ④ 표가 차례대로 켜짐, 가슴 3D 실험, 정리 3 차례 세우기 |
| 들숨·날숨 본문 단락, 공기는 압력이 높은 곳에서 낮은 곳으로(214) | 요약만 | 본문 단락 그대로, 가슴 3D 압력 막대(높낮이만) |
| 흉강 정의(214) | 용어 풀이 | 용어 풀이 + 가슴 3D 이름표·왜 그럴까 |
| 허파꽈리-모세혈관, 모세혈관-조직세포 사이 교환, 산소가 에너지를 얻는 데 쓰임, 이산화 탄소가 날숨으로(215) | 요약 | 본문 그대로 + 그림 ⑤(그림 Ⅵ-14 지도 + 단면) |
| 폐에서의 기체 교환, 조직세포에서의 기체 교환 설명(215 그림) | 핵심 정리 한 줄 | 본문 두 단락 + 확산 실제 계산 단면 + 기체 교환 실험실(예측→움직이기→농도 막대) |
| 확산 정의(215) | 용어 풀이 | 용어 풀이 + 단면 그림 + 퀴즈 ② 6번 |
| 스스로 평가 1(빈칸 3개)(215) | 정리 빈칸 4개(확산 하나 더) | 퀴즈 ② 2번과 정리 1을 교과서 빈칸 3개 그대로 |
| 스스로 평가 2 숨 쉴 때 일어나는 일 설명(215, 답 313) | 글쓰기 주제 | 글쓰기 주제 유지 + 정리 3 차례 |
| 친구에게 설명: 밀폐된 공간 환기(215) | 생각 멈춤 답만 | 닫힌 방 그림(사람 8명, 창문 열기), 생각 멈춤, 퀴즈 ② 5번, 글쓰기 |
| 스스로 정리 빈칸 허파꽈리·가로막·조직세포, 들숨·날숨 요약(225) | **빠짐** | 정리 4 |
| 단원 마무리 3번 들숨/날숨 표 고르기(227) | **빠짐** | 퀴즈 ② 1번, 가슴 3D 확인하기 2번 |

## 2. 퀴즈 바꾼 것
- 외우기 문제(호흡계가 아닌 것 고르기, 작은 고무풍선은 무엇) → 그림 번호 문제(공기가 지나는 차례), 적용 문제(고무 막을 당기면 몸에서는?, 숨을 크게 들이쉰 순간의 압력, 달리기 중 다리 근육의 기체 교환, 밀폐된 교실 환기).
- 보기 순서가 모두 첫 번째가 정답이 되지 않게 돌림.
