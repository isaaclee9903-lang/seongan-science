## 2. 고친 오류
- 해 보기 ㉠~㉣: 이전 판과 기준 문서는 ㉠ 영양소, ㉡ 산소, ㉢ 노폐물, ㉣ 이산화 탄소였다. 교과서 221쪽 그림을 확대해 보니 ㉠은 왼쪽 폐에서 혈액 → 폐(위쪽 화살표), ㉡은 오른쪽 폐에서 폐 → 혈액(아래쪽), ㉢은 혈액 → 콩팥, ㉣은 작은창자 → 혈액이다. 그래서 **㉠ 이산화 탄소, ㉡ 산소, ㉢ 노폐물, ㉣ 영양소**로 고쳤다(교과서 답지에는 이 문항 답이 없음). `curriculum/중2_동물과에너지_기관계상호작용.md`도 고침.

## 3. 퀴즈 바꾼 점
- 퀴즈 ① 5문항, ② 7문항(모두 12). 외우기만 하던 문항을 그림 문제(㉡·㉣), 적용 문제(그림 Ⅵ-18 쓰임이 아닌 것, 숨이 가빠지는 까닭, 가슴 압박), 차례 문제(영양소의 길), 단원 마무리 5번 형식으로 바꿨다.
- 퀴즈 엔진이 보기를 섞지 않으므로 배설 수업과 같이 정답 자리를 돌렸다(rot).

## 4. 범위 밖으로 넣지 않은 것
세포호흡 화학식·미토콘드리아, 호흡수·심박수 수치, 호르몬·신경 조절, 산소 부채, 간문맥(영양소 길은 '혈액을 통해 심장을 거쳐'로만 이름 붙임). 3D 길은 실제 혈관을 따라가지만 이름표는 교과서 낱말(폐동맥·폐정맥·대동맥·대정맥·우심방·우심실·좌심방·좌심실)만 썼다.
