# 한국 베스트셀러 문제집·학습지의 지면 구성과 편집 관례 (중2 과학 A4 흑백 학습지용 공통 원리 도출)

조사일: 2026-11-08. 도구: 웹 검색·웹 페이지 읽기 약 20회.
조사 한계(먼저 읽을 것): 서점 상세 페이지의 "미리보기" 사진은 이미지라서 글로 읽을 수 없었고, 출판사(비상교육 도서 사이트)는 인증서 만료로 열리지 않았다. 그래서 **실측 치수(여백·글자 크기·단 간격)는 하나도 확보하지 못했다.** 확보한 것은 (1) 판형·쪽수 같은 서지 정보, (2) 단계(섹션) 이름과 순서, (3) 사용자 후기·위키에 적힌 지면 묘사다. 아래 "Inferences"에 적은 지면 관례(선지 배열, 서술형 칸 등)는 일반적 관찰에 기댄 추론이며 이번 조사에서 출처로 확인한 사실이 아니다.

## 1. 한 단원(차시) 안의 순서와 개념:문제 비율

### Takeaway
중학 과학 문제집의 공통 순서는 "개념 설명(1~2쪽) + 바로 옆 기초 확인 문제 → (탐구 정리 + 확인 문제) → 내신형 객관식 다수 + 서술형 몇 개 → 고난도 소수 → 대단원 평가"이며, 시험 직전용 빈칸 요약은 별책·미니북으로 분리하는 경향이 뚜렷하다. 수능 N제는 "핵심 개념 정리 → 대표 기출 → 예상 문제 → 단원 끝 고난도"로 같은 뼈대를 더 압축한다.

### Cited Findings
- 오투(비상) 단계 순서: 개념 설명 → 개념 쏙쏙 → (탐구) → (여기서 잠깐) → 내신 쑥쑥 → 실력 탄탄 → 단원 평가 문제 → 시험 대비 교재 → 정답과 해설. — [나무위키 '오투'](https://namu.wiki/w/%EC%98%A4%ED%88%AC)
- 오투: 중단원 개념 설명은 소단원마다 1~2쪽이며, 각 쪽에 설명과 '개념 쏙쏙' 문제가 함께 놓인다. 개념 쏙쏙은 교과서 수준보다 쉬우며 대부분 주관식(단답). — [나무위키 '오투'](https://namu.wiki/w/%EC%98%A4%ED%88%AC)
- 오투: 탐구 뒤 문제는 O/X → 주관식 → 서술형 순으로 대개 3문항. — [나무위키 '오투'](https://namu.wiki/w/%EC%98%A4%ED%88%AC)
- 오투: '내신 쑥쑥'은 단원당 객관식 15~30문항 + 서술형 3문항, '실력 탄탄'은 단원당 약 2문항(최대 4), '단원 평가'는 약 25문항(서술형 포함), 난이도는 내신 쑥쑥과 실력 탄탄 사이. — [나무위키 '오투'](https://namu.wiki/w/%EC%98%A4%ED%88%AC)
- 오투 후기(2016년판): 순서는 "개념 정리(개념 쏙쏙) → 탐구 & 여기서 잠깐 → 단계별 실전문제(내신 쑥쑥, 서술형 문제, 실력탄탄, 단원 평가)". 단원 하나가 약 10~50쪽. 본책 약 190쪽. — [알라딘 서재 후기](https://blog.aladin.co.kr/781355168/8228661)
- 오투 2027년판(2022 개정) 2-1: 368쪽, 210×297 mm(A4), 994 g, 2026-09-01 발행. 출판사 소개 문구는 "개념+탐구+문제" 체계. — [알라딘 상품 페이지](https://www.aladin.co.kr/shop/wproduct.aspx?ItemId=400743355); [교보문고 검색 결과 요약](https://product.kyobobook.co.kr/detail/S000217412085)

- 완자는 개념 설명에 더 무게, 오투는 문제 양에 무게를 둔다는 비교. 하이탑의 실력 강화가 오투 실력 탄탄보다 어렵다는 비교. — [나무위키 '오투'](https://namu.wiki/w/%EC%98%A4%ED%88%AC)
- 메가스터디 N제 화학Ⅰ(2026): 주제(01~16)마다 핵심 개념 정리('고빈출'·'빈출' 표시) → 대표 기출 문제 → 적중 예상 문제, 단원 끝에 '1등급 도전 문제', 책 끝에 정답과 해설. — [메가스터디 북몰](https://megastudy.net/mobile/smart/book_mall/view.asp?book_cd=24612)
- 과학탐구 N제는 대개 100% 자작 문제이며 과년도 N제·실전 모의고사 우수 문항을 엮어 낸다는 설명. — [더위키 'N제'](https://thewiki.kr/w/N제)
- 다른 비상교육 중등 과학 교재 소개: '꼼꼼정리 확인 문제', '중단원 마무리 문제', 기본→핵심→실력 문제 단계. — (검색 요약에서만 확인, 원문 미확인) [알라딘 분류 페이지](https://www.aladin.co.kr/m/mbrowse.aspx?CID=248572)

### Inferences
- 공통 뼈대는 3단: ① 개념(설명+즉시 확인, 단답/빈칸/O·X) ② 적용(탐구·자료 해석, 객관식 다수) ③ 확장(서술형·고난도 소수). 난이도는 문항 수가 줄어드는 방향으로 올라간다(쉬운 문제 많이, 어려운 문제 적게).
- 오투 수치(소단원 개념 1~2쪽, 중단원 내신 객관식 15~30 + 서술형 3, 실력 2)를 2~3쪽 학습지에 옮기면 대략: 1쪽 = 개념 정리 + 빈칸·O/X 확인(5~8개), 2쪽 = 탐구·자료 해석 + 객관식 4~6문항, 3쪽 = 서술형 2~3문항 + 도전 1문항. 즉 개념:문제 ≈ 1:1.5~2 수준. (오투 단원당 쪽수 전체 비율은 출처에 없음 — 추론)
- "확인 문제를 개념 바로 옆에 둔다"(오투 개념 쏙쏙)는 원리는 학습지에서도 개념 칸 오른쪽/아래에 짧은 확인 칸을 붙이는 방식으로 쓸 수 있다.

### Gaps
- 완자·체크체크·EBS 중학 뉴런·쎈의 섹션 이름과 문항 수를 1차 출처로 확인하지 못함(나무위키 문서 404, 서점 소개문 이미지).
- 한 쪽당 문항 수의 실측치(예: 객관식 2단 배열 시 쪽당 몇 문항)는 출처 없음.

## 2. 개념 상자·핵심 요약·빈칸·탐구 정리·자료 해석의 지면 배치

### Takeaway
확인된 관례: 개념 쪽에는 본문 옆 보조 상자(오투 '플러스 강의', 하이탑 '날개')가 붙고, 탐구는 "목표–과정–결과–정리 → 확인 문제" 고정 틀이며, 빈칸 요약은 본책보다 별책(시험 대비 교재·미니북)에 몰린다. 빈칸 정답을 같은 쪽 아래 구석에 작게 두는 자기 채점 방식도 있다.

### Cited Findings
- 오투 개념 쪽: 기본 개념을 한쪽에 두고 '플러스 강의' 상자로 추가 읽을거리, 용어는 문제로 익히고 '개념 쏙쏙'으로 확인. — [알라딘 서재 후기](https://blog.aladin.co.kr/781355168/8228661)
- 오투 탐구 쪽: 목표·과정·결과·정리 뒤 실험 기반 확인 문제. — [알라딘 서재 후기](https://blog.aladin.co.kr/781355168/8228661)
- 오투 본책에는 연필로 칠했다 지우면 글자가 가려지는 '가림 칸'(정답 숨김)이 있다(예: 석회 동굴의 탄산칼슘). — [알라딘 서재 후기](https://blog.aladin.co.kr/781355168/8228661)
- 오투 '핵심 미니북': 사진·표가 들어간 얇은 요약책, '핵심체크'의 답을 쪽 오른쪽 아래에 인쇄해 스스로 채점. 별표·형광 표시를 미리 하지 않아 학생이 직접 표시하게 둠. — [알라딘 서재 후기](https://blog.aladin.co.kr/781355168/8228661)
- 오투 '시험 대비 교재'(별책): 잠깐 테스트(짧은 개념 쓰기) / 계산력·암기력 강화 문제 / 중단원 핵심요약–기출문제 / 서술형 문제 정복하기의 4부. — [알라딘 서재 후기](https://blog.aladin.co.kr/781355168/8228661); 빈칸 개념 채우기·암기·계산·기출·서술형으로 짧게 구성되나 개념 내용은 얇다는 평 — [나무위키 '오투'](https://namu.wiki/w/%EC%98%A4%ED%88%AC)
- 오투 '여기서 잠깐': 핵심 개념의 상세 분석과 예제(기초~심화), 처음 배우는 학생에게는 어려운 편. — [나무위키 '오투'](https://namu.wiki/w/%EC%98%A4%ED%88%AC)
- 메가스터디 N제: 핵심 개념 정리에 출제 빈도 표시('고빈출'·'빈출'). — [메가스터디 북몰](https://megastudy.net/mobile/smart/book_mall/view.asp?book_cd=24612)
- 하이탑: 본문 바깥 '날개' 칸과 각주에 심화 내용. 처음 학습자는 어느 내용이 학년 범위인지 구분하기 어렵다는 지적. — [나무위키 '하이탑'](https://namu.wiki/w/%ED%95%98%EC%9D%B4%ED%83%91)

### Inferences
- 학습지 원리: (a) 본문 단(넓게)+보조 단(좁게, 날개)의 2구역 지면이 업계 공통. 다만 하이탑 비판처럼 날개에 범위 밖 내용을 넣으면 혼란 — 날개는 "용어 뜻·단위·주의"처럼 범위 안 보조로만 쓰는 것이 안전하다(이 저장소의 교육과정 범위 규칙과도 맞음).
- (b) 탐구 정리는 "목표–과정–결과–정리" 4칸 고정 틀이 가장 흔한 문법이다.
- (c) 빈칸 요약은 "시험 직전 반복용"이라 본 학습 흐름과 분리하는 편이 낫다 — 학습지에선 마지막 쪽 하단 또는 뒷면 "핵심 정리 빈칸" 띠로 두고, 정답은 쪽 구석에 작게(또는 교사용에만).
- (d) 출제 빈도 표시는 수능 N제 관례이며 중학 학습지에는 "중요" 표시 정도로 축소 가능.

### Gaps
- 빈칸 표기 형태(괄호 "(　　)" vs 밑줄 "____" vs 네모)의 브랜드별 차이는 미리보기 이미지를 못 읽어 확인 못함.
- 개념 상자 테두리·바탕 농도 등 흑백 인쇄 처리 방식 자료 없음.

## 3. 그림·도표 위치, 그림 번호·캡션, <보기> 상자

### Takeaway
그림 배치·캡션 양식에 대한 출처 있는 실측 정보는 거의 없다. 확인된 것은 수능형 문항의 <보기> ㄱ·ㄴ·ㄷ 합답형 관례와 그 선지 배열 두 가지뿐이다.

### Cited Findings
- 수능 과탐에서 판단을 요구하는 문항은 대다수가 <보기>와 ㄱ, ㄴ, ㄷ으로 출제되고, 계산 문항은 선지에 실제 숫자가 들어간다. 선지 배열은 대체로 (① ㄱ ② ㄷ ③ ㄱ, ㄴ ④ ㄴ, ㄷ ⑤ ㄱ, ㄴ, ㄷ) 류 두 가지 패턴. — [나무위키 '수능/과학탐구 영역'(검색 요약)](https://namu.wiki/w/%EB%8C%80%ED%95%99%EC%88%98%ED%95%99%EB%8A%A5%EB%A0%A5%EC%8B%9C%ED%97%98/%EA%B3%BC%ED%95%99%ED%83%90%EA%B5%AC%20%EC%98%81%EC%97%AD)
- 비례 관계 문항은 자료 해석과 엮어 "ㄱ, ㄴ, ㄷ의 선지로 엮는 경우가 많다". — 같은 출처
- 오투 단원 도입: 사진 1쪽 + 설명, 단원마다 '문자도'(글자 그림). 오투 해설의 탐구 부분에는 그림 포함. — [알라딘 서재 후기](https://blog.aladin.co.kr/781355168/8228661)

### Inferences (출처 미확인, 일반적 관찰)
- 국내 문제집·시험지는 문항 안 그림을 "문제 발문 → 그림(가운데 정렬) → <보기> → 선지" 순서로 쌓는 것이 표준이며, 그림 이름은 번호(그림 1)보다 (가), (나), A, B, ㉠ 같은 기호 붙이기가 더 흔하다. 교과서식 "그림 Ⅰ-8" 번호는 교과서·개념 쪽에서 쓰인다.
- <보기> 상자는 위쪽 테두리 가운데에 "<보기>"를 얹은 얇은 선 상자가 관례.

### Gaps
- 그림 캡션 글자 크기·위치, 그림과 글 단의 관계(단 폭 맞춤 vs 전폭) 실측 자료 없음. 직접 실물 대조 필요.

## 4. 문항 번호·선지 배열·서술형 칸·난이도 표시·배점

### Takeaway
출처로 확인된 것은 수능 과탐 형식(과목당 20문항·4쪽·30분·만점 50점, 2점/3점 혼합, 1쪽에 쉬운 회상형·4쪽에 추론형)과 하이탑 서술형 답 칸 길이가 모범 답안과 안 맞는다는 비판 정도다. 선지 열 배치·서술형 줄 수는 출처 미확인.

### Cited Findings

- 시대인재 서바이벌 모의고사는 "문항 배치, 시험지 양식 등 실제 수능을" 구현한 것으로 소개됨. — [나무위키 '시대인재'](https://namu.wiki/w/%EC%8B%9C%EB%8C%80%EC%9D%B8%EC%9E%AC)

### Inferences (출처 미확인)

## 6. 교사용·정답과 해설 구성

### Takeaway
학생용은 "별책 정답과 해설"이 기본이며 해설은 빠른 정답표가 아니라 문항별 상세 해설(탐구는 그림 포함, 서술형은 채점 기준·배점 포함)이다. 교사용 판은 존재가 확인되나(오투 교사용 2013) 형식은 미확인. 수능형 모의고사는 해설지를 아예 주지 않기도 한다.

### Cited Findings
- 오투 정답과 해설: 본책과 같은 디자인, 빠른 정답 목록이 아니라 상세 해설, 탐구 부분에 그림, 서술형 해설에 배점과 그림 포함. — [알라딘 서재 후기](https://blog.aladin.co.kr/781355168/8228661)
- 오투 단점으로 시험 대비 교재가 본책에서 분리되어 있지 않다는 지적(분리형 선호). — [알라딘 서재 후기](https://blog.aladin.co.kr/781355168/8228661)
- [교사용] 오투 중등 과학 2-1(2013) 상품이 존재(품절). — [알라딘 검색 결과](https://www.aladin.co.kr/shop/wproduct.aspx?ItemId=33597021)
- 하이탑: 학년당 해설 1권 별도. 해설 오류·형식 불일치 비판. — [나무위키 '하이탑'](https://namu.wiki/w/%ED%95%98%EC%9D%B4%ED%83%91)
- 시대인재 과탐 서바이벌은 해설지를 제공하지 않고 강사·연구실이 자체 해설을 만들어 배포. — [나무위키 '시대인재'](https://namu.wiki/w/%EC%8B%9C%EB%8C%80%EC%9D%B8%EC%9E%AC)

- 메가스터디 N제는 책 끝에 [정답과 해설]. — [메가스터디 북몰](https://megastudy.net/mobile/smart/book_mall/view.asp?book_cd=24612)

### Inferences
- 학습지 묶음책에는 "학생용(빈칸) + 교사용(같은 쪽에 답 인쇄)" 두 판을 같은 원본에서 뽑는 방식이 가장 경제적이다. 흑백이라 빨간 글씨가 불가하므로 교사용 답은 굵은 글씨+회색 바탕, 또는 손글씨체로 구분해야 한다(추론).
- 서술형 해설에는 모범 답안 + 채점 요소(핵심 낱말)를 함께 적는 것이 업계 관례(오투 근거).
- 정오표 문제(시대인재)는 자체 제작물의 검수 단계 필요성을 보여 준다.

### Gaps
- 교사용 판에서 답을 어떻게 표시하는지(색, 위치) 확인 못함. 빠른 정답표 유무도 브랜드별 미확인.

## 7. 시대인재·오르비(수능 N제·모의고사) 양식 vs 전통 중학 문제집

### Takeaway
확인된 차이는 "목적과 형식"이다: 수능형은 실제 시험지 양식 재현·자작 문항 밀도·해설 최소화, 중학 문제집은 다색 디자인·도입 사진·만화 코너·별책 다수(미니북·시험대비·해설)로 학습 흐름 전체를 감싼다. "미니멀하고 타이포가 좋다"는 시대인재 평판을 뒷받침하는 편집 후기는 찾지 못했다.

### Cited Findings
- 오투 디자인: 흰색·노랑·초록 위주, 시험대비 교재 표지 주황·노랑·흰색·내지 회색·청록, 단원 도입 사진 1쪽·문자도, 단원 평가 뒤 만화 코너('과학 탐정 똘똘이'). — [알라딘 서재 후기](https://blog.aladin.co.kr/781355168/8228661)
- 오투 부록: 화보집, 요점 정리 노트. — [나무위키 '오투'](https://namu.wiki/w/%EC%98%A4%ED%88%AC)
- 시대인재 서바이벌: 문항 배치·시험지 양식이 실제 수능 재현. 문항은 사내 콘텐츠 팀이 만들고 출제와 검토를 분리. 시대인재북스는 (주)하이컨시의 출판 부문. — [나무위키 '시대인재'](https://namu.wiki/w/%EC%8B%9C%EB%8C%80%EC%9D%B8%EC%9E%AC)
- 오르비 게시글들은 시대인재 자료를 주로 문항 질·난이도·가격으로 평가하며, 편집 디자인을 따로 평한 글은 찾지 못함. 회차별 질 편차가 크다는 언급. — [오르비 '시대인재 모의고사 퀄 어떤가요?'](https://orbi.kr/00074269094); [오르비 '시대 인재 물리 서바이벌 후기'](https://orbi.kr/00013208202)
- 생명과학Ⅱ 수능 문제지는 여백 없이 꽉 채우는 경우가 많다는 서술(체감 설명). — [나무위키 '수능/과학탐구 영역' 검색 요약](https://namu.wiki/w/%EB%8C%80%ED%95%99%EC%88%98%ED%95%99%EB%8A%A5%EB%A0%A5%EC%8B%9C%ED%97%98/%EA%B3%BC%ED%95%99%ED%83%90%EA%B5%AC%20%EC%98%81%EC%97%AD)

### Inferences
- 흑백 A4 학습지가 가져올 것: 수능형에서는 "시험지 문법"(발문–자료–<보기>–선지의 일정한 쌓기, 2단 문항 배치, 쉬운 것→어려운 것 순서, 장식 없는 얇은 선), 중학 문제집에서는 "학습 흐름"(개념→즉시 확인→탐구 틀→내신형→서술형→도전, 빈칸 요약 분리, 상세 해설). 마스코트·만화·다색은 흑백 묶음책에 맞지 않고, 이 저장소의 'AI티 금지·장식 최소' 방침과도 맞지 않는다.
