# 중2 과학 Ⅴ. 식물과 에너지 — 1. 광합성과 호흡 / 03 식물도 호흡을 할까?

출처: 중학교 과학 2 교과서(임성숙) 176~177쪽, 스스로 정리 181~182쪽, 단원 마무리 183~184쪽(4·8·9번), 정답 313쪽. 2026-11-13 교과서 파일과 문장 단위로 다시 대조.

## 학습 목표 (이번 시간에 나는!)
- 식물의 호흡과 광합성의 관계를 설명할 수 있다.

## 본문 핵심
- 식물도 싹을 틔우고 꽃을 피우며 다양한 생명활동을 하려면 에너지가 필요하다.
- 식물세포에서는 광합성으로 만들어진 양분이 산소와 반응하여 이산화 탄소와 물로 분해되면서 에너지가 방출된다. 양분을 분해하여 에너지를 얻는 과정이 **호흡**이다.
- 양분(포도당) + 산소 → 이산화 탄소 + 물 + 에너지
- 광합성 때는 이산화 탄소를 흡수하고 산소를 방출하지만, 호흡할 때는 반대로 산소를 흡수하고 이산화 탄소를 방출한다.
- 광합성은 빛이 있을 때 일어나지만, 호흡은 빛이 없을 때도 항상 일어나며 뿌리, 줄기, 잎 등 살아있는 모든 세포에서 일어난다.
- 그림 Ⅴ-4(토마토 낮과 밤): 낮에는 광합성으로 발생한 산소 중 일부를 호흡에 이용하고 남는 것은 방출한다. 호흡으로 발생한 이산화 탄소는 대부분 광합성에 이용한다. 밤에는 호흡만 일어나 산소를 흡수하고 이산화 탄소를 방출하며 에너지를 얻는다.
- 광합성이 빛에너지를 이용하여 양분에 에너지를 저장하는 과정이라면, 호흡은 양분을 분해하여 생활에 필요한 에너지를 얻는 과정이다.
- 옆 글(177쪽): 식물의 광합성으로 생산된 물질은 생물의 호흡에 이용되고, 생물의 호흡으로 생산된 물질은 식물의 광합성에 이용된다.

## 해 보기 (177쪽): 식물에서 출입하는 에너지와 물질의 변화 분석하기
잎 위의 순환 그림: 물 + 이산화 탄소 —(빛에너지, 광합성)→ 포도당 + 산소 —(호흡)→ 에너지, 다시 물 + 이산화 탄소.
비교표:
| | 광합성 | 호흡 |
|---|---|---|
| 필요한 물질 | (이산화 탄소), 물 | 포도당, 산소 |
| 생산되는 물질 | 포도당, 산소 | (이산화 탄소), 물 |
| 물질의 변화 | 포도당(양분) 합성 | 포도당(양분) (분해) |
| 에너지 출입 | 에너지 (저장) | 에너지 (방출) |
| 일어나는 시기 | (빛)이 있을 때 | 항상 |
2. 광합성으로 만들어진 양분을 이용하여 에너지를 만들기까지 과정을 설명한다.

## 스스로 평가 (177쪽)
1. 양분을 분해하여 ( 에너지 )을/를 얻는 과정을 ( 호흡 )(이)라고 하며, 이 ( 에너지 )은/는 식물의 여러 가지 생명활동에 이용된다.
2. 식물이 산소를 흡수하는 까닭을 설명해 보자. → 양분을 분해하여 생명활동에 필요한 에너지를 얻는 호흡에 산소가 필요하기 때문이다.
- 친구에게 설명: "밀폐된 방에서 식물을 키울 때 낮과 밤에 방 안 산소와 이산화 탄소의 양은 같을까?" → 다르다. 낮에는 광합성으로 이산화 탄소가 줄고 산소가 늘며, 밤에는 호흡만 일어나 산소가 줄고 이산화 탄소가 는다.

## 단원 문제에서 가져온 것 (2026-11-13 대조)
- 스스로 정리 3번(181쪽): 식물의 호흡 — ㄱ. 산소가 발생한다(X) ㄴ. 에너지를 생산한다 ㄷ. 호흡은 항상 일어난다 → 정답 ㄴ, ㄷ.
- 단원 마무리 4번(183쪽): 낮과 밤 기체 교환 그림, ㄷ. "빛이 없을 때는 광합성과 호흡이 모두 일어난다"는 틀림 → 정답 ④(ㄱ, ㄴ).
- 단원 마무리 8번 (3)(184쪽): LED등을 끄면 "광합성은 일어나지 않고 호흡만 일어나므로 산소 농도는 감소하고 이산화 탄소 농도는 증가" → 측정 실험실의 끄고 측정하기 근거.
- 단원 마무리 9번(184쪽): 맑은 날 하루 이산화 탄소 흡수량(위)·방출량(아래) 상댓값 그래프(0~4, 1~2). 정답 "낮에는 광합성량이 호흡량보다 많으므로 흡수량이 방출량보다 많고, 밤에는 호흡만 일어나므로 방출량이 더 많다" → 광합성량과 호흡량의 **정성적 비교**는 사용 가능.
- 이 차시에는 석회수·지시약 같은 호흡 실험이 없다. 측정 장치는 앞 차시(172쪽) 탐구 장치를 그대로 쓴다.
