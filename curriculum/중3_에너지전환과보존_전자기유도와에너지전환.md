# 교육과정 기준 문서 — 중3 과학 Ⅵ. 에너지 전환과 보존 › 2. 에너지의 전환과 이용 (01·02)

> **출처:** 교과서 사진 7장 (225~231쪽). 01 「움직이는 자석이 전기를 만들어」(225~227쪽), 02 「에너지는 전환되고 보존돼」(228~231쪽)
> **교육과정:** 2022 개정으로 판단(중3 교과서). 출판사 미확인
> **선생님 결정 (2026-10-25):**
> - 01·02를 **한 번에** 수업한다(웹 자료도 한 수업으로 묶음).
> - 02의 배움활동(손발전기 A·B, 꼬마전구·버저, 스위치 1·2)은 **웹에 넣지 않고 다른 예시**로 바꾼다 → 자전거 발전기(전조등·스피커·휴대 전화 충전).
> - 이번 수업은 선생님이 **판서와 함께 진행**한다. 읽기 자료는 핵심 낱말을 **빈칸**으로 두어 미리 답이 보이지 않게 한다(눌러서 열기).
> - 실험은 나중에 하므로 전자기 유도와 발전기를 **그림·움직임으로 충분히** 보여 준다. 유튜브 영상 멈춤 퀴즈를 넣는다(우주 탐사 수업 형식).

## 1. 학습 목표 (교과서 '이 단원을 배우면')
- 01: 자석의 운동에 의해 전류가 발생하는 현상을 관찰하고 설명할 수 있다.
- 02: 역학적 에너지가 전기 에너지로 전환되며, 이때 전체 에너지는 보존된다는 것을 설명할 수 있다.

## 2. 교과서에서 다루는 내용
| 개념 | 교과서 표현 |
|---|---|
| 함께 시작하기 | 흔들어서 불을 켤 수 있는 손전등. 자가 발전 손전등 사진(전구, 스위치, 코일, 자석). "이 손전등은 전지를 끼워 사용하는 손전등과 구조가 어떻게 다를까?" 자가 발전 손전등을 흔들면 손전등 속에서 자석이 움직이고, 이때 전기가 만들어진다 |
| 배움활동 (실험) | 자석이나 코일을 움직여 전류 만들기. 코일과 검류계를 연결한 후 1. 자석을 움직여 코일 속에 넣거나 뺄 때 2. 자석을 코일 속에 넣고 움직이지 않을 때 3. 코일을 움직여 자석을 코일 속에 넣거나 뺄 때 검류계를 관찰. 준비물: 코일, 검류계, 막대자석, 집게 달린 전선, 장갑. 정리: 결과 표, 코일에 전류가 흐르기 위한 조건 |
| 전자기 유도 | 코일 근처에서 자석을 움직이거나, 자석 근처에서 코일을 움직이면 코일에 전류가 흐른다. 자석을 코일 속에 넣고 움직이지 않으면 코일에 전류가 흐르지 않는다. 자석이나 코일을 움직여 코일을 통과하는 자기장이 변하면 코일에 전류가 흐르게 되는데, 이 현상을 **전자기 유도**라고 한다. 이때 흐르는 전류를 **유도 전류**라고 한다 |
| 그림 Ⅵ-7 | 전자기 유도를 이용하는 자가 발전 손전등. 흔들면 손전등 속에서 자석이 코일을 통과하면서 유도 전류가 만들어지고, 이 유도 전류를 이용하여 전구의 불을 켠다 (확대 그림: 코일, 자석, 유도 전류 화살표) |
| 발전기 | 생활 속에서 우리가 사용하는 전기는 대부분 발전소의 **발전기**로부터 얻는다. 발전기는 자석과 코일로 이루어져 있다. 다양한 에너지를 이용하여 코일을 회전시키면 전자기 유도 현상이 일어나 전기가 생산된다 |
| 그림 Ⅵ-8 발전기의 구조 | 말굽 모양 자석(위 S, 아래 N) 사이의 사각 코일, 손잡이, 전구. "발전기의 코일이 자석 사이에서 회전한다." "전자기 유도 현상이 일어나 유도 전류가 흘러 전기가 만들어진다." |
| 과학, 역사를 만나다 | 우리나라 최초의 발전기: 1883년 고종이 미국에 사절단 파견, 미국 에디슨 회사에 발전 설비 주문, 1887년 경복궁에 최초의 발전기 (웹에는 넣지 않음: 요청하지 않은 일화는 늘리지 않음) |
| 배움활동 | 발전소에서 전기가 만들어지는 원리 알아보기. 회전 날개를 끼운 발전기를 검류계와 연결, 회전 날개를 입으로 불거나 손으로 돌릴 때 검류계 바늘 관찰. 정리: 바늘이 움직이는 까닭, 수력 발전소와 풍력 발전소에서는 어떤 에너지가 발전기를 돌려 전기를 만들까 |
| 01 정리하기 | 자석 근처에서 코일을 움직이면 코일에 전류가 흐르는데, 이러한 현상을 (전자기 유도)라고 한다 / 전자기 유도가 일어날 때 코일에 흐르는 전류를 (유도 전류)라고 한다 / 코일이나 자석이 움직일 때 일어나는 전자기 유도를 이용하여 전기를 만드는 장치를 (발전기)라고 한다 |
| 02 예상하기 | 동일한 두 플라스틱 관 중 하나에만 코일을 감고(발광 다이오드 연결), 동일한 자석을 동시에 떨어뜨림. 발광 다이오드에서 어떤 현상? 어느 자석이 먼저 도착? |
| 역학적 에너지 감소 | 공기와의 마찰이 없을 때 낙하하는 자석의 역학적 에너지는 보존된다. 그림 Ⅵ-9처럼 (가), (나)를 동시에 떨어뜨리면 (나)가 (가)보다 지면에 늦게 떨어진다. (가)의 역학적 에너지는 보존되지만, (나)의 역학적 에너지의 일부는 전자기 유도에 사용되면서 그 양이 감소하기 때문이다. 자석이 운동하여 전자기 유도 현상이 일어날 때 자석의 역학적 에너지는 보존되지 않는다 |
| 그림 Ⅵ-9 | 전자기 유도 현상이 일어날 때 역학적 에너지 전환과 보존. 위·아래에서 위치 에너지, 운동 에너지, 역학적 에너지 막대. (나)는 아래에서 운동 에너지가 (가)보다 작고 역학적 에너지가 줄어 있음. 활동+ 그림 이해하기: (가), (나)가 지면에 도달한 순간의 속력 비교 |
| 배움활동 (웹에서 바꿈) | 전자기 유도가 일어날 때 에너지 전환 알아보기: 손발전기 A·B, 꼬마전구, 버저, 스위치 1·2. 손발전기 A 손잡이를 10회 돌릴 때 B의 손잡이가 돌아가는 횟수 |
| 에너지 전환 | 손발전기 A의 손잡이를 돌리는 역학적 에너지는 전자기 유도에 의해 전기 에너지로 전환된다. 이 전기 에너지는 꼬마전구에서 빛에너지로, 버저에서 소리 에너지로, 손발전기 B에서 역학적 에너지로 전환된다. 전자기 유도가 일어날 때 역학적 에너지는 소멸되지 않고 전기 에너지로 전환된다. 이 전기 에너지의 양은 전환된 빛, 소리, 역학적 에너지의 양의 합과 같다 (그림 Ⅵ-10 두 손발전기 사이의 에너지 전환: 띠 그림) |
| 화학 에너지 | 화학 결합에 의해 물질 속에 저장된 에너지. 우리가 먹는 음식이나 건전지, 각종 연료에는 화학 에너지가 저장되어 있다 |
| 에너지 보존 | 우리 주변에서는 에너지가 전환되는 예를 쉽게 찾을 수 있다. 이 과정에서 에너지는 새로 생기거나 소멸되지 않고 그 총합이 일정하게 보존된다 |
| 그림 Ⅵ-11 여러 가지 에너지 전환 | 손전등: 전기 에너지 → (빛에너지) / 기타 연주: 역학적 에너지 → 소리 에너지 / 손뼉: 역학적 에너지 → (소리 에너지) / 모닥불: 화학 에너지 → 빛, 열에너지 |
| 배움활동 | 에너지가 전환되고 보존되는 예 조사하고 발표하기(인포그래픽). 예시 자동차: 화학 에너지 → 전기 에너지 → 빛에너지·소리 에너지, 열에너지, 역학적 에너지 |
| 02 정리하기 (O, X) | 자석이 움직여 전자기 유도 현상이 일어날 때 자석의 역학적 에너지의 일부는 소멸된다 (X) / 에너지는 한 형태에서 다른 형태로 전환되며, 이 과정에서 새로 생기거나 소멸되지 않는다 (O) |

## 3. 웹에서 쓰는 다른 예시 (선생님 요청으로 교과서 배움활동 대신)
- **자전거 발전기:** 페달을 밟는 역학적 에너지 → 발전기(전자기 유도) → 전기 에너지 → 전조등 빛에너지, 스피커 소리 에너지, 휴대 전화 배터리의 화학 에너지(충전). 켠 기구가 많을수록 페달이 무거워진다(전기 에너지가 더 많이 필요하므로 더 많은 역학적 에너지를 전환해야 함). 정량값 없이 띠 굵기로만 보여 준다. 교과서 손발전기 실험의 정리 2번(닫은 스위치에 따라 B가 돌아가는 횟수가 다른 까닭)과 같은 생각을 다른 장면으로 묻는다.
- 전구·전선이 따뜻해지는 **열에너지**도 가는 띠로 넣는다(교과서 자동차 예시에 열에너지가 있음).
- 수력·풍력 발전소: 물이 떨어지며 수차를 돌림, 바람이 날개를 돌림 → 발전기. 교과서 활동 정리 2번의 답으로 쓴다(물·바람의 역학적 에너지 → 전기 에너지).

## 5. 쓰지 않는 것 (초과)
- 패러데이 법칙, 렌츠 법칙, 자기 선속, 유도 기전력과 그 크기 식, 오른손 법칙으로 유도 전류 방향 정하기
- 교류·직류, 정류자·슬립 링 이름, 변압기, 송전 전압
- 맴돌이 전류(구리판 사이 자석 영상은 "구리판에도 전류가 유도된다"까지만 설명)
- 에너지 효율 계산, 발전량·전력 수치, 위치 에너지·운동 에너지 계산(9.8mh, ½mv²는 앞 단원 표기이지만 이번 웹에서는 쓰지 않음)
- 유도 전류의 세기에 영향을 주는 요인(자석 세기·감은 수·빠르기)은 교과서 사진에 없음 → "빠르게 움직일수록 바늘이 크게 움직인다"는 그림 움직임으로만 보이고 글로 규칙을 세우지 않는다
- 패러데이 이야기, 우리나라 최초의 발전기 일화(요청하지 않은 일화)
