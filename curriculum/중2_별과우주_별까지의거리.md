# 교육과정 기준 문서 — 중2 과학 Ⅷ. 별과 우주 › 01 별까지의 거리는 어떻게 알 수 있을까?

> **출처:** 교과서 사진 4장 (도입 '별까지의 거리는 어떻게 알 수 있을까?', 탐구 '물체까지의 거리와 시차의 관계 알아보기', '# 연주 시차와 별까지의 거리' + 그림 Ⅷ-2, 해 보기 '연주 시차로 별까지의 거리 비교하기' + 스스로 평가)
> **교육과정:** 2022 개정으로 판단 (평가하기가 지식·이해 / 과정·기능 / 가치·태도로 나뉨, 그림 번호 Ⅷ). 쪽수는 사진에 없음 → 미확인
> **규칙:** 웹페이지의 모든 글·시뮬레이션·퀴즈는 이 문서 범위 안에서만 만든다.

## 1. 학습 목표 (교과서 '이번 시간에 나는!')
- 시차와 거리의 관계를 설명할 수 있다.
- 연주 시차를 이용하여 별까지의 거리를 비교할 수 있다.

## 2. 교과서에서 다루는 내용
| 개념 | 교과서 표현 |
|---|---|
| 도입 상황 | 칠판 앞에 선생님이 서 계시면 앉은 자리에 따라 가려지는 칠판 글씨가 다르다 |
| 시차 현상 | 하나의 물체를 서로 다른 위치에서 보면 관측자의 위치에 따라 물체가 보이는 방향이 달라진다. 물체는 멀리 있는 배경에 대해 서로 다른 곳에 있는 것처럼 보인다 |
| 시차 | 관측자의 위치에 따라 물체가 보이는 방향이 달라지는 정도. 크기는 **두 관측 지점과 물체가 이루는 각도**로 나타낸다 |
| 사진 (그림 Ⅷ-1) | 두 등대(빨간·흰 말 등대)와 관측 지점 두 곳, 가운데 물체 → '시차' 각 (사진은 교과서 저작물이라 웹에 쓰지 않고 새로 그린다) |
| 탐구 | 시차 측정 판, 별 모형 (가)·(나), 접착테이프, 자, 각도기. ① 별 모형 붙이기 ② 아래쪽 구멍 두 개 뜯어 위아래로 접어 세우기 ③ 눈높이로 들고 양쪽 구멍으로 번갈아 관찰, 보이는 위치 표시 ④ 왼쪽 구멍으로 본 위치는 왼쪽 구멍과, 오른쪽 구멍으로 본 위치는 오른쪽 구멍과 자로 잇기 ⑤ 각도기로 (가)와 (나)의 시차 측정 → "시차가 더 큰 것은?" |
| 측정 판 눈금 | ①~⑪ 번호 눈금 |
| 탐구 정리 | 관측 지점부터 별 모형까지의 거리와 시차 사이의 관계를 설명 |
| 시차와 거리 | 시차는 관측자와 물체 사이의 거리가 **멀수록 작아진다** |
| 연주 시차 | 지구가 공전하며 위치가 변하므로 별이 보이는 방향이 달라짐. 지구가 A일 때 별 X는 X₁, **반년 뒤** B일 때 X₂에 있는 것처럼 보임. 별 X의 시차는 **∠AXB**, **시차의 ½을 연주 시차** |
| 연주 시차와 거리 | 연주 시차도 관측자와의 거리에 따라 달라짐 → 연주 시차로 별까지의 거리를 **비교**. 지구와 가까이 있는 별일수록 연주 시차가 크다 |
| 단위 | 태양을 제외한 별은 매우 멀어서 연주 시차가 매우 작음 → 단위 ″(초). 1°(도) = 60′(분) = 3600″(초), 1″은 1°의 1/3600 |
| 그림 Ⅷ-2 | 별 X(가까움)·별 Y(멀리), 배경 띠의 X₁·Y₁·Y₂·X₂, 지구 공전 궤도와 태양. "지구와 가까이 있는 별 X의 연주 시차는 더 멀리 있는 별 Y의 연주 시차보다 크다" |
| 해 보기 | 2013년 발사된 **가이아 우주 망원경**: 별의 위치와 움직임, 특징을 알아내는 임무. 지구와 함께 움직이며 별의 위치를 관측. **6개월 간격**으로 측정한 별 A, B의 위치 사진 (가)(나). ① 두 별의 위치가 변한 까닭 ② 연주 시차를 비교해 더 멀리 있는 별 고르기 |
| 파섹 | 연주 시차가 **1″**인 별까지의 거리 = **1 pc(파섹)**. 1 pc ≈ **3.26 광년** |
| 광년 | 거리 단위. 빛이 1년 동안 갈 수 있는 거리 = 1 광년 |
| 측정 한계 | 지구로부터 **100 pc 이상** 떨어진 별은 연주 시차가 너무 작아 연주 시차로 거리를 알기 어렵다 |
| 스스로 평가 | 1. 별까지의 거리는 ( 연주 시차 )을/를 측정하여 구할 수 있으며, 가까울수록 연주 시차가 ( 크다 ). 2. 지구가 공전하지 않는다면 별의 연주 시차는 어떻게 될지 설명. 친구에게: "연주 시차의 단위로 °(도) 대신 ″(초)를 사용하는 까닭은?" |
| 평가하기 | 지식·이해: 거리와 시차의 관계 설명 / 과정·기능: 모형을 정확히 관찰하여 시차를 구함 / 가치·태도: 거리와 시차의 관계를 알아보는 과정에서 흥미 |

## 3. 표기
- 용어(띄어쓰기): 시차, 연주 시차, 시차 측정 판, 별 모형, 가이아 우주 망원경, 공전, 공전 궤도, 관측자, 관측 지점
- 각도 단위: °(도), ′(분), ″(초). 1° = 60′ = 3600″
- 거리 단위: pc(파섹), 광년. 1 pc ≈ 3.26 광년
- 그림 기호: 지구 위치 A, B / 별 X, Y / 보이는 위치 X₁, X₂, Y₁, Y₂ / 시차 ∠AXB

## 4. 사용 금지 (넘기 쉬운 것)
- **거리(pc) = 1 ÷ 연주 시차(″)** 공식과 그 계산 (예: "연주 시차 0.5″ → 2 pc"). 교과서는 1″ ↔ 1 pc 정의와 '비교'까지만 다룸
- 삼각함수(tan), 삼각 측량 계산, 각도로 거리 구하기
- 천문단위(AU), 공전 궤도 반지름 수치, 빛의 속력 수치, 1 pc·1 광년의 km 값
- 겉보기 등급·절대 등급·밝기와 거리(다음 차시 내용), 별의 색과 표면 온도, 분광형
- 고유 운동, 연주 광행차, 세차
- 다른 거리 측정법(세페이드 변광성, 적색 이동 등)
- 시뮬레이션 화면의 각도 수치를 '실제 연주 시차 값'처럼 보이게 하는 것 (실제 값은 1″보다 작음 → 그림에서는 각도를 크게 과장하고 안내 문구를 단다)

## 5. 정성적으로만 다루는 것
- 시차 측정 판 가상 실험의 각도(°)는 **모형의 측정값**으로만 보여 준다 (교과서 탐구처럼 각도기로 재는 값). 거리와 각도 사이의 식은 보여 주지 않는다.
- 연주 시차 시뮬레이션은 각도를 수치 없이 **호의 크기·막대**로 비교한다.
- "연주 시차가 1″보다 작은 별이 대부분" 정도의 비교 표현은 쓸 수 있다 (가장 가까운 별의 연주 시차도 1″보다 작음 — 출처 확인 후 사용).
