# 교육과정 기준 문서 — 중2 과학 Ⅱ. 지권의 변화 › 06 커다란 암석은 어떻게 흙이 되었을까?

> **출처:** 교과서 사진 4장 (72~75쪽: 도입 '커다란 암석은 어떻게 흙이 되었을까?' + 해 보기 '모형실험으로 풍화 과정 알아보기' + 본문(풍화) + 그림 Ⅱ-11 여러 가지 풍화 작용 + '# 토양의 생성 과정'(그림 Ⅱ-12) + '# 암석의 순환'(그림 Ⅱ-13) + 스스로 평가)

> **규칙:** 웹페이지의 모든 글·시뮬레이션·퀴즈는 이 문서 범위 안에서만 만든다.

## 2. 교과서에서 다루는 내용
| 개념 | 교과서 표현 |
|---|---|
| 도입 (72쪽) | 거북바위, 코끼리바위, 사자바위 등 우리나라의 산에는 모양이 특이해 이름이 붙은 바위가 많이 있다. 이런 독특한 생김새를 가진 바위는 커다란 바위가 이리저리 깎이고 부서져 만들어졌다. 어떻게 단단한 바위가 부서질 수 있었을까? |
| 해 보기 (72쪽) | 모형실험으로 풍화 과정 알아보기 (결론 도출 / 모형으로 설명). 준비물: 굵은 빨대, 가위, 고무찰흙, 물, 자, 스포이트. 과정: 1 굵은 빨대를 10 cm 길이로 자른 뒤 한쪽 끝을 고무찰흙으로 막는다. 2 빨대에 물을 가득 넣은 뒤 입구를 고무찰흙으로 막는다. 3 양쪽을 막은 빨대를 얼린다(빨대 속 물이 얼면 고무찰흙은 어떻게 변할까?). 4 고무찰흙의 모양을 관찰하고 까닭을 이야기한다. 5 빨대를 암석이라고 할 때 자연의 어떤 현상에 비유할 수 있는지 토의한다 |
| 풍화 (73쪽) | 빨대를 막은 고무찰흙이 갈라진 것처럼 단단한 암석도 시간이 지나면 부서진다. 암석이 **물이나 공기, 생물 등의 작용**으로 잘게 부서지거나 성분이 변해 분해되는 현상을 **풍화**라고 한다 |
| 물(얼음) | 암석 틈에 스며든 물이 얼면 **부피가 늘어나며** 암석의 틈을 넓힌다 |
| 생물 | 암석 틈에 뿌리를 내린 식물도 자라나며 암석 틈을 넓힐 수 있다. 이 틈이 점점 커지면 암석이 부서진다. 암석 표면에 자라는 **이끼** 때문에 암석의 성분이 변하기도 한다 |
| 압력 | 땅속에 있던 암석이 땅 위로 드러나면서 암석을 누르는 **압력이 약해져** 암석 표면이 얇게 떨어져 나가기도 한다 |
| 이산화 탄소 + 물 | 이산화 탄소가 녹은 물은 **석회암을 녹여 석회 동굴**을 만들기도 한다 |
| 정리 | 이렇게 암석은 여러 요인으로 풍화되며 서서히 토양으로 변한다 |
| 그림 Ⅱ-11 여러 가지 풍화 작용 | 물: 암석 틈에 스며든 물이 얼어 얼음이 되면서 부피가 늘어나 틈을 넓히고 암석을 부순다 / 생물: 암석 틈을 파고든 식물의 뿌리가 점점 크게 자라며 암석을 부순다. 암석 표면의 이끼는 암석의 성분을 바꾸기도 한다 / 압력: 지하 깊은 곳의 암석이 땅 위로 드러나면 암석을 누르고 있던 압력이 약해지면서 암석의 겉 부분이 얇게 벗겨져 떨어진다 / 이산화 탄소 + 물: 이산화 탄소가 녹아 있는 물이 석회암을 녹여 석회 동굴을 만든다 |
| 토양 (74쪽) | 암석이 오랜 시간 풍화 작용을 받으면 더욱 잘게 부서져 식물이 자랄 수 있는 흙이 되는데, 이를 **토양**이라고 한다 |
| 토양의 생성 과정 | 땅속에 있던 단단한 암석이 지표로 드러나면 풍화 작용을 받아 암석 조각으로 부서진다. 암석 조각은 계속 풍화되어 더욱 잘게 부서져 자갈이나 모래가 되고, 겉 부분에는 식물이 자랄 수 있는 흙이 만들어진다. 이곳에 생물이 살아가면서 더욱 분해된 물질이 물에 녹아 아래로 쌓이면서 토양은 점차 두꺼워진다 |
| 토양의 역할 | 토양은 생물에게 영양분을 공급하고, 생물은 죽어 토양의 영양분이 된다. 또 토양은 다양한 생물이 살아가는 터전이 된다 |
| 그림 Ⅱ-12 토양의 생성 과정 | ① 단단한 암석이 풍화되어 부서진다. ② 암석이 더 잘게 부서져 표면에 흙이 생기고 식물이 자란다. ③ 다양한 생물이 살며 더욱 분해된 물질이 아래로 쌓이며 토양이 생성된다. 층 이름(위부터): **식물이 잘 자라는 층 / 물에 녹은 물질과 진흙 등으로 이루어진 층 / 암석 조각과 모래 등으로 이루어진 층 / 풍화 작용이 거의 일어나지 않은 암석층**. 그림에 토끼, 나무뿌리, 풀 |
| 암석의 순환 (75쪽) | 암석은 처음 만들어진 형태로 계속 있는 것이 아니라 풍화 작용이나 주변 환경의 변화에 따라 다른 암석으로 변한다. 지하의 마그마가 지표나 지하에서 식으면 화성암이 된다. 지표에 드러난 암석은 풍화되어 퇴적물이 되고, 퇴적물은 단단하게 굳어 퇴적암을 만든다. 퇴적암이나 화성암이 지하 깊은 곳에서 높은 열과 압력을 받으면 변성암이 된다. 온도가 더 높아지면 녹아서 마그마가 되고, 이 마그마가 식어 굳으면 다시 화성암이 된다. 이렇게 암석이 오랜 시간 동안 끊임없이 변하는 과정을 **암석의 순환**이라고 한다 |
| 그림 Ⅱ-13 암석의 순환 | 상자: 화성암, 퇴적물, 퇴적암, 변성암, 마그마. 화살표: 화성암 → 퇴적물(풍화·침식·운반), 퇴적물 → 퇴적암(다져지고 굳어짐), 퇴적암 → 퇴적물(풍화·침식·운반), 변성암 → 퇴적물(풍화·침식·운반), 퇴적암 → 변성암(높은 열과 압력), 화성암 → 변성암(높은 열과 압력), 화성암 → 마그마(녹음), 변성암 → 마그마(녹음), 마그마 → 화성암(식음). 배경: 바다, 화산, 땅속 층 |
| 스스로 평가 | 1 암석이 잘게 부서지는 현상을 (풍화)(이)라고 하며, 암석은 이 작용을 거쳐 식물이 잘 자랄 수 있는 (토양)이/가 된다. 2 우리 주변에서 볼 수 있는 여러 가지 암석은 어떤 순환 과정을 거쳐 지금의 모습이 되었을지 설명해 보자 |
| 친구에게 설명 | "토양은 사람을 비롯한 생물에 어떤 영향을 줄까?" |

## 4. 사용 금지 (넘기 쉬운 것)
- 기계적 풍화·화학적 풍화 같은 풍화의 분류 이름, 박리 작용·서릿발 작용·절리 같은 용어
- 물이 얼 때 부피가 늘어나는 비율(약 9 %) 같은 수치, 화학 반응식(탄산칼슘, 탄산)
- 종유석·석순·석주 같은 동굴 지형 이름 (그림에는 그리되 글로 이름을 쓰지 않음)
- 토양 층의 기호 이름(A층·B층·C층·O층), 표토·심토·모질물 같은 용어, 토양 생성 기간 수치
- 침식·운반의 정의와 하천·빙하·바람의 지형 (교과서 그림의 화살표 이름으로만 씀)
- 암석의 순환에서 교과서 그림에 없는 경로 (퇴적암 → 마그마 직접, 변성암 → 변성암 등), 판 구조, 섭입대
- 거북바위·코끼리바위·사자바위의 위치, 크기 등 교과서 밖 정보

## 5. 정성적으로만 다루는 것 / 모형 표시
- 풍화 장면(물, 생물, 압력, 이산화 탄소 + 물)은 수백~수천 년 걸리는 일을 몇 초로 줄인 모형이다. 화면에 "시간을 아주 빠르게 돌린 모형"이라고 밝힌다. 기간·횟수 숫자는 쓰지 않는다.
- 얼었다 녹았다를 '밤에는 얼고 낮에는 녹는다'로 보여 준다 (교과서는 반복을 직접 말하지 않음 → 미확인 목록).
- 토양 생성 장면은 교과서 그림 Ⅱ-12의 세 단계와 네 층 이름만 쓴다.
- 암석의 순환 장면은 교과서 그림 Ⅱ-13의 다섯 상자와 아홉 화살표만 쓴다.

## 6. 미확인 (선생님 확인 필요)
- **해 보기(빨대 얼리기) 모형실험** → 수업에서 실제로 하는지 몰라 가상 실험으로 만들지 않음. 읽기 글에는 교과서 문장("빨대를 막은 고무찰흙이 갈라진 것처럼")만 그대로 둠
- **얼었다 녹았다의 반복** → 교과서는 "물이 얼면 부피가 늘어나며 틈을 넓힌다"까지만 씀. 장면에서는 밤에 얼고 낮에 녹는 것이 여러 번 되풀이되며 틈이 점점 넓어지게 그림
- **'풍화·침식·운반'의 설명** → 침식을 정의하지 않고 "풍화되어 잘게 부서진 조각이 물이나 바람 등에 의해 운반되어 쌓여 퇴적물이 된다"(앞 차시 표현)로 씀
- **'압력'의 벗겨짐** → 덮고 있던 땅이 깎여 없어지며 암석이 드러나는 모습으로 그림 (교과서: "땅 위로 드러나면서")
- 이끼가 붙은 자리의 암석 색이 조금 변하는 것으로 '성분 변화'를 나타냄
