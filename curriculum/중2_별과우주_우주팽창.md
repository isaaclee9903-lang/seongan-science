# 교육과정 기준 문서 — 중2 과학 Ⅷ. 별과 우주 › 우주의 크기는 항상 일정할까?

> **출처:** 교과서 사진 2장 (도입 '우주의 크기는 항상 일정할까?', 탐구 '풍선 모형으로 알아보는 우주 팽창', 정리하기, 본문 + 그림 Ⅷ-9 우주 팽창, 스스로 평가. 294~295쪽, 단원 '2. 은하와 우주')
> **교육과정:** 2022 개정으로 판단 (앞 차시와 같은 교과서). 출판사 미확인
> **규칙:** 웹페이지의 모든 글·시뮬레이션·퀴즈는 이 문서 범위 안에서만 만든다.
> **만든 방식:** AUTO(프로토타입) 모드. 교과서 사진 2장으로 작성

## 1. 학습 목표 (교과서 '이번 시간에 나는!')
- 모형을 이용하여 우주가 팽창하고 있음을 설명할 수 있다.

## 2. 교과서에서 다루는 내용
| 개념 | 교과서 표현 |
|---|---|
| 도입 질문 | 우주에는 우리은하와 같은 은하들이 더 있을까? / (말풍선) 은하까지의 거리가 변했을까? |
| 허블 | 미국의 천문학자 **허블(Hubble, E. P., 1889~1953)**은 **1923년** 우리은하 바깥에 많은 은하들이 존재한다는 것을 밝혀냈다 |
| 외부 은하 | 우리은하 바깥에 분포하는 은하를 **외부 은하**라고 한다 |
| 관측 사실 | 허블은 외부 은하를 관측하여 **대부분의 외부 은하가 우리은하로부터 멀어지고 있다**는 사실을 알아내었다. 은하들이 멀어진다는 것은 무엇을 의미할까? |
| 탐구 | 풍선 모형으로 알아보는 우주 팽창 (목표: 모형실험으로 우주의 팽창을 설명할 수 있다) / 준비물: 풍선, 풍선 펌프, 줄자, 붙임딱지 |
| 탐구 과정 | 1 풍선에 펌프로 공기를 조금 넣은 뒤 붙임딱지를 적당한 간격으로 붙인다. 2 줄자를 이용해 두 붙임딱지 사이의 거리를 측정한다. 3 풍선에 공기를 더 넣은 뒤 두 붙임딱지 사이의 거리를 측정한다. → 풍선이 커지면 붙임딱지 사이의 간격은 어떻게 달라지는가? |
| 기록표 | 풍선을 조금 불었을 때 / 많이 불었을 때 — ①과 ② 사이의 거리(cm), ①과 ③ 사이의 거리(cm), ②와 ③ 사이의 거리(cm) |
| 정리하기 | 1 붙임딱지 사이의 간격이 달라질 때 기준이 되는 지점이 있는지 이야기해 보자. 2 풍선 표면을 우주에 비유한다면 풍선에 공기를 넣어 표면이 늘어나는 것과 풍선 표면에 붙인 붙임딱지는 각각 무엇을 뜻하는지 정리해 보자. (풍선 표면 – 우주 / 풍선 표면 늘어남 – ? / 붙임딱지 – ?) 3 실험 결과를 바탕으로 우주에서 은하들이 서로 멀어지는 까닭을 추리해 보자 |
| 평가하기 | 지식·이해: 은하들이 서로 멀어지는 까닭을 추리할 수 있다. 과정·기능: 풍선과 붙임딱지를 이용한 모형실험으로 우주의 팽창을 설명할 수 있다. 가치·태도: 모형을 이용하여 과학 현상을 설명할 수 있음에 흥미를 느낄 수 있다 |
| 본문 ① | 풍선 표면에 붙인 붙임딱지는 **움직이지 않지만**, 풍선 표면이 팽창하면서 붙임딱지 사이의 거리가 멀어진다. 우주에서 외부 은하가 서로 멀어지는 것도 **은하들이 직접 움직이는 것이 아니라 우주 공간이 팽창하기 때문**이다 |
| 본문 ② | 과학자들은 그림 Ⅷ-9와 같이 우주는 **약 138억 년 전 온도와 밀도가 매우 높은 한 점에서 대폭발이 일어나 시작**된 뒤 **점점 팽창**하여 현재와 같은 모습이 되었다고 설명한다 |
| 본문 ③ | 우주 공간은 **특정한 중심 없이 모든 방향으로 팽창**하고 있으며, **우주 어느 지점을 관측해도 대부분의 은하가 서로 멀어지고** 있다 |
| 그림 Ⅷ-9 | 우주 팽창: 대폭발(약 138억 년 전) → 점점 커지는 우주(은하) → 현재, '시간의 흐름' 화살표 |
| 스스로 평가 | 1 우주가 팽창할 때 팽창의 중심이 ( 있 / 없 )으며, 대부분의 외부 은하는 우리은하에서 점차 ( 가까워지고 / 멀어지고 ) 있다. 2 대부분의 은하가 서로 점점 멀어지고 있는 까닭을 설명해 보자 |
| 친구에게 설명 | "풍선 모형으로 우주의 팽창을 비유해 볼까?" |

## 3. 표기
- 용어: 은하, 우리은하, 외부 은하, 우주, 우주 공간, 팽창, 우주 팽창, 대폭발, 온도, 밀도, 풍선 모형, 모형실험, 붙임딱지, 줄자, 풍선 펌프
- 인물: 허블(Hubble, E. P., 1889~1953)
- 수치: 1923년, 약 138억 년 전, 거리 단위 cm(풍선 실험)
- 띄어쓰기: '외부 은하', '우주 공간', '우주 팽창'은 띄어 쓴다. '우리은하', '붙임딱지', '모형실험'은 붙인다(교과서 표기)

## 4. 사용 금지 (넘기 쉬운 것)
- 허블 법칙(후퇴 속도 = 허블 상수 × 거리), 허블 상수, 적색 편이·도플러 효과, 스펙트럼
- 우주 배경 복사, 가속 팽창, 암흑 물질·암흑 에너지, 급팽창(인플레이션)
- 빅뱅 직후의 입자·원소 생성, 최초의 별과 은하가 생긴 시기, 우주의 미래(계속 팽창 여부)
- '빅뱅'이라는 말(교과서는 '대폭발'), 우주의 크기·관측 가능한 우주의 수치, 빛의 속도
- 외부 은하의 이름(안드로메다 등), 은하의 분류(타원·나선·불규칙 은하) — 다음 차시일 수 있음
- "멀리 있는 은하일수록 빨리 멀어진다"는 규칙 (교과서 본문에 없음)

## 5. 정성적으로만 다루는 것
- 풍선 가상 실험의 cm 값은 모형에서 계산한 값이다. 거리가 늘어난다는 것만 묻고, 늘어난 비율이나 속도를 규칙으로 묻지 않는다.
- 우주의 시간 변화 애니메이션은 '대폭발(약 138억 년 전) → 현재'만 숫자로 쓴다. 중간 시점의 나이·크기는 숫자로 쓰지 않는다. 커지는 빠르기는 모형이다.
- 대폭발 순간은 '온도와 밀도가 매우 높은 한 점'으로 밝은 빛으로만 그린다. 그 뒤 빛이 옅어지는 것은 그림 표현이며, 온도·밀도 변화를 글·퀴즈로 묻지 않는다.
- 은하 그림은 사진이 아니라 개념 이해를 위한 모형이다. 은하의 수·모양·크기는 실제와 다르다.

## 6. 미확인
- 풍선 실험을 실제 수업에서 하는지 → 웹에서는 가상 실험으로만 하고, 읽기 글에서 "수업 시간에 한 실험"이라고 쓰지 않음
- 대폭발 직후 우주를 밝게 빛나는 공으로, 시간이 지나며 어두워지는 모습으로 그림(교과서 그림 Ⅷ-9처럼) → 온도가 낮아진다는 말은 쓰지 않음
- 은하가 처음부터 있던 것처럼 그림(교과서 그림처럼 작은 우주에도 은하를 그림) → 은하가 생긴 시기는 다루지 않음
- 다음 쪽 내용(외부 은하의 종류, 우주 탐사 등) → 사진에 없어 확인하지 못함
- 교과서 출판사 → 화면에 쪽수를 넣지 않음
