## 2. 교과서에서 다루는 내용
| 개념 | 교과서 표현 |
|---|---|
| 도입 그림 | 고양이가 어항 속 금붕어를 보고, 뒤쪽 유리에 고양이와 어항이 비쳐 보임 |
| 거울 | 거울은 빛의 반사를 이용해 물체의 모습을 비추는 도구이다. 우리는 거울로 얼굴을 비춰 보기도 하고, 뒤에 있는 물체를 보기도 한다. 거울뿐 아니라 유리나 잔잔한 수면 등에도 물체가 비쳐 보인다 |
| 상 | 거울이나 유리, 렌즈 등으로 물체를 볼 때 생기는 물체의 모습을 **상**이라고 한다 |
| 해 보기 (결과 해석 및 결론 도출) | 준비물: 반투명 거울, 집 그림 딱지, 집이 그려진 모눈종이, 집게 2개. ① 집이 그려진 모눈종이를 책상 위에 놓고, 표시된 선에 맞추어 반투명 거울을 수직으로 세운다 ② 반투명 거울 앞쪽에서 거울에 비친 상을 관찰한다 ③ 거울에 생긴 상의 위치에 맞게 집 그림 딱지를 거울 뒤쪽 모눈종이에 놓는다 ④ 반투명 거울을 치우고 거울을 놓았던 위치에서 집 그림과 상까지의 거리를 비교. 집 그림과 상의 모양과 크기를 비교 ⑤ 반투명 거울을 놓는 위치를 집 그림 쪽으로 가까이 하거나 멀리 하면서 집 그림과 이때 생긴 상의 위치를 비교 ⑥ 평면거울에 생기는 상의 특징을 설명. 말풍선: "상이 생긴 위치에 집 그림 딱지를 놓아요." |
| 평면거울의 상 | 평면거울 앞에 물체를 놓으면 항상 물체와 **같은 크기**의 상이 생긴다. 이때 거울에서 상까지의 거리와 거울에서 물체까지의 거리는 **같다** |
| 그림 Ⅲ-5 | 평면거울에 생긴 상 (토끼 인형과 자, 거울 속에 같은 크기의 상) |
| 거울로 물체를 보는 까닭 | 우리가 거울을 통해 물체를 볼 수 있는 것은 물체에서 나온 빛이 거울에 반사되어 우리 눈에 들어오기 때문이다 |
| 상의 위치 | 그러나 그림 Ⅲ-6처럼 우리는 거울에 반사되어 나온 빛을 보고 그 빛이 거울에서 나왔다고 인식한다. 즉, 우리 눈에 들어온 빛의 **연장선**이 만나는 곳에 물체가 있는 것으로 인식하고, 그곳이 상의 위치가 된다 |
| 그림 Ⅲ-6 ① | 광원에서 물체의 한 점으로 들어온 빛은 사방으로 반사되어 나간다 (화분, 사람, 세워 둔 거울) |
| 그림 Ⅲ-6 ② | 이 빛 중 일부가 거울 면에 닿은 뒤 반사되어 우리 눈에 들어온다 |
| 그림 Ⅲ-6 ③ | 거울에 반사되어 나온 빛을 거울 뒤쪽으로 연장하면 한 점에서 만난다 (점선) |
| 그림 Ⅲ-6 ④ | 사람은 거울 뒤쪽의 이 점에서 빛이 나오는 것처럼 느끼게 되어 거울 속에 물체가 있는 것처럼 보인다 |
| 스스로 평가 | 1. 평면거울 앞에 물체를 놓으면 물체와 크기가 (같은 / 다른) 상이 생기며, 거울에서 상까지의 거리와 물체까지의 거리는 (같다 / 다르다). 2. 우리가 평면거울로 물체를 볼 때 물체가 거울 속에 있는 것처럼 보이는 까닭을 설명 |
| 친구에게 설명 | "우리는 어떻게 평면거울을 통해 물체를 볼 수 있을까?" |

## 3. 01 차시에서 이어 쓰는 것
- 빛의 반사, 빛의 반사 법칙(입사각과 반사각의 크기는 항상 같다), 입사각, 반사각, 입사 광선, 반사 광선, 반사면, 반사면과 수직인 선, 광원, 직진
- 광원이 아닌 물체는 광원의 빛이 반사되어 눈에 들어오면 보인다

## 4. 표기
- 용어: 상, 평면거울, 반투명 거울, 연장선, 상의 위치, 집 그림, 집 그림 딱지, 모눈종이, 집게
- 띄어쓰기: '평면거울', '반투명 거울', '집 그림 딱지', '상의 위치', '거울 뒤쪽'
- 거리는 모눈 칸 수로만 센다 (cm 수치 없음)

## 5. 사용 금지 (넘기 쉬운 것)
- 실상·허상, 오목 거울·볼록 거울, 렌즈의 상, 배율, 초점
- 좌우가 바뀐다(좌우 반전)는 말: 교과서 본문에 없음 → 글로 쓰지 않음 (그림에는 거울에 비친 모습 그대로 그림)
- 전신을 보는 데 필요한 거울 길이, 두 거울 사이의 여러 상
- 법선이라는 말, 굴절 관련 내용(이번 차시와 무관)

## 6. 정성적으로만 다루는 것
- 작도 화면의 입사각·반사각 숫자는 01 차시의 반사 법칙 확인용으로만 보여 준다(정수 °).
- 거리는 "○칸 = ○칸"처럼 모눈 칸으로 비교한다.

## 7. 미확인
- '작도'라는 말: 교과서에 없음 → 화면 제목은 "빛의 경로 그리기(작도)"처럼 풀어 쓰고, 본문에는 '그리기'를 주로 씀
- 해 보기(반투명 거울)를 실제 수업에서 하는지 → 가상 실험 탭으로 만들었고, 하지 않으면 탭을 빼면 됨
- 물체의 한 점에서 거울에 수직인 선을 그어 상을 찾는 방법(거울에 수직, 같은 거리): 본문의 '같은 거리'와 해 보기 모눈에서 끌어낸 것 → 연습 문제로만 씀
- 교과서 출판사 → 화면에 쪽수를 넣지 않음
