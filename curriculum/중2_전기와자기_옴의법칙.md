# 교육과정 기준 문서 — 중2 과학 Ⅶ. 전기와 자기 › 1. 전기 (전류·전압·저항, 옴의 법칙)

> **출처:** 교과서 p.243~246 사진 4장, 이삭 선생님 수업 PPT 3개 (6-1-3 전류·전압·저항, 6-1-3 회로 만들기 활동, 6-1-4 옴의 법칙)
> **교육과정:** 2022 개정 (교과서 '평가하기'의 지식·이해 / 과정·기능 / 가치·태도 구분으로 판단)
> **규칙:** 웹페이지의 모든 글·시뮬레이션·퀴즈는 이 문서 범위 안에서만 만든다.

## 1. 교과서·PPT에서 다루는 내용
| 개념 | 교과서·PPT 표현 |
|---|---|
| 자유전자 | 특정 원자핵에 속박되지 않고 물질 내부를 자유롭게 돌아다닐 수 있는 전자 |
| 전류 | 전하의 흐름. 단위 A(암페어). 1 A = 1000 mA. 流(흐를 류) |
| 전류 방향 / 전자 이동 방향 | 전류는 (+)극 → (-)극, 전자는 (-)극 → (+)극. 서로 반대 (전자의 존재를 알기 전에 정한 약속) |
| 전자가 움직이는 까닭 | 전지를 연결하면 전지의 전압으로 전자가 이동. 전지가 없으면 불규칙하게 움직여 전류가 흐르지 않음 |
| 오개념 | 전지에서 전자가 생겨나는 것이 아님. 전선에는 이미 전자가 꽉 차 있음 → 전구가 바로 켜짐 |
| 전압 | 전류를 흐르게 하는 능력. 단위 V(볼트). 壓(누를 압) |
| 전기 회로 | 전류가 계속 흐를 수 있는 길. 끊어진 곳 없이 이어져야 함 |
| 수로 모형 | 펌프=전지, 물의 흐름=전류, 수로=도선, 수문=스위치, 물레방아=전구(저항), **수면의 높이 차=전압** |
| 건전지 | 건전지마다 전압이 정해져 있음 (1.5 V, 6 V → 펌프의 세기가 다름) |
| 전류계 | 회로에 **직렬** 연결(전류가 흐르는 길이 하나). (-)단자는 큰 값부터 5 A → 500 mA → 50 mA. 전류계와 전지만 연결하면 센 전류로 고장 |
| 전압계 | 회로에 **병렬** 연결(길이 갈라지게). (-)단자는 큰 값부터 30 V → 15 V → 3 V |
| 전기 저항 | 전류의 흐름을 방해하는 정도. 단위 Ω(옴). 1 V를 걸었을 때 1 A가 흐르는 도선의 저항 = 1 Ω |
| 저항의 특성 | 물질의 종류가 같을 때 길이가 짧고 굵을수록 저항이 작다 |
| 저항이 생기는 까닭 | 자유전자가 원자들과 충돌하면서 움직임에 방해를 받기 때문 |
| 탐구 | 디지털 전원 장치, 전류계, 전압계, 긴·짧은 니크롬선. **니크롬선에 걸리는 전압**을 0~4 V로 1 V씩 높이며 전류(mA) 측정, 그래프 |
| 옴의 법칙 | 전류의 세기 ∝ 전압, 전류의 세기 ∝ 1/저항. **I = V/R**, V = I × R. 그래프 기울기: 저항이 작을수록 가파름 |
| 단위 인물 | 볼타(1745~1827, V), 앙페르(1775~1836, A), 옴(1789~1854, Ω) |
| 생활 | 전기 기구는 220 V에서 작동, 선풍기 바람 세기 버튼 → 전류가 바뀜 |

## 2. 표기
- 기호: 전류 I, 전압 V, 저항 R. 단위: A, mA, V, Ω
- 공식: **I = V/R**, V = I × R (R = V/I는 "저항을 구해 보자" 맥락에서 사용)
- 용어: 전기 저항(저항), 전류의 세기, 직렬연결·병렬연결, 니크롬선, 디지털 전원 장치

## 3. 사용 금지 (넘기 쉬운 것)
- 키르히호프 법칙(명칭·식), 전위·전위차라는 용어, 전압 강하라는 용어
- 합성 저항 공식(R = R₁ + R₂, 1/R = 1/R₁ + 1/R₂), 저항의 직렬·병렬 연결 계산
- 비저항 공식(R = ρL/A), 전력(P = VI), 전력량, 줄열
- 전자의 실제 이동 속력 수치 (PPT의 "약 0.1 m/s"는 실제 값과 달라 쓰지 않음 → "아주 느리다"로만 표현)
- 내부 저항, 교류·직류

## 4. 교사 요청으로 넣되 정성적으로만 다루는 것
- **"옴의 법칙의 V는 건전지 전압이 아니라 저항 양 끝에 걸리는 전압"**: 교과서 표현 "니크롬선에 걸리는 전압"을 근거로 한다. 수로 모형에서는 "물레방아 위와 아래의 높이 차"에 대응시킨다.
- **"회로를 한 바퀴 돌면 높이 차(전압)는 0"**: 수로 모형의 높이로만 설명한다. 펌프에서 올라간 높이만큼 물레방아에서 내려와 출발점 높이로 돌아온다. 법칙 이름과 식은 쓰지 않는다.
- **저항 2개 도전 모드**: 높이가 두 계단으로 나뉘어 내려오는 것을 보여주고, 각 저항에 옴의 법칙을 적용하는 데까지만 다룬다. 합성 저항 공식은 쓰지 않는다.
