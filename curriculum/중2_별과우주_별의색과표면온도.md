# 교육과정 기준 문서 — 중2 과학 Ⅷ. 별과 우주 › 03 별의 색이 다양하게 나타나는 까닭은 무엇일까?

> **출처:** 교과서 사진 2장 (284~285쪽: 도입 '별의 색이 다양하게 나타나는 까닭은 무엇일까?', 해 보기 '별의 색과 표면 온도의 관계 알아보기', '# 별의 표면 온도와 색' + 그림 Ⅷ-6, 색 띠 그림, 스스로 평가)
> **교육과정:** 2022 개정으로 판단 (앞 차시와 같은 교과서). 출판사 미확인
> **규칙:** 웹페이지의 모든 글·시뮬레이션·퀴즈는 이 문서 범위 안에서만 만든다.

## 1. 학습 목표 (교과서 '이번 시간에 나는!')
- 별의 색과 표면 온도의 관계를 설명할 수 있다.

## 2. 교과서에서 다루는 내용
| 개념 | 교과서 표현 |
|---|---|
| 도입 | 전기난로를 켜면 안쪽 열선이 처음에는 붉은색이었다가 온도가 높아지면서 노란색으로 바뀐다. 온도에 따라 열선이 방출하는 빛의 색이 달라지기 때문. 빛을 방출하는 물체는 온도에 따라 색이 달라진다. 별은 스스로 빛을 내는 천체 |
| 해 보기 | **수업에서 함, 웹에서 표면 온도 숫자도 보여 줌(선생님 확인 2026-10-11)**. 준비물: 스마트 기기. 밤하늘에서 볼 수 있는 별 사진(스피카, 알데바란, 리겔, 베텔게우스, 베가, 안타레스). ① 스마트 기기로 각 별의 표면 온도 조사 ② 모둠별로 별자리 하나를 정해 별자리를 이루는 각 별의 색과 표면 온도를 조사·비교 ③ 별의 색과 표면 온도 사이의 관계 정리 (자료 조사 / 규칙성 추리) |
| 별의 색 | 밤하늘의 별을 관찰하면 밝기가 비슷해도 색깔은 조금씩 다르다 |
| 그림 Ⅷ-6 | 전갈자리의 안타레스와 드슈바. 서로 다른 색을 가진 두 별. 두 별의 표면 온도는 **청색의 드슈바가 붉은색의 안타레스보다 높다** |
| 표면 온도와 색 | 별의 색은 표면 온도에 따라 달라진다. 표면 온도가 높은 별은 **파란색 빛을 많이 방출하여 파란색**을 띠고, 표면 온도가 낮은 별은 **붉은색 빛을 많이 방출하여 붉은색**을 띤다. 따라서 별의 색을 이용해 표면 온도를 비교할 수 있다 |
| 태양 | 표면 온도가 **약 6000 ℃**로 노란색으로 보인다 |
| 색 띠 그림 | 위(파랑)에서 아래(빨강)로: **청색** 나오스 / **청백색** 스피카, 리겔 / **백색** 알타이르, 베가 / **황백색** 프로키온, 북극성 / **황색** 태양, 카펠라 / **주황색** 아크투루스, 알데바란 / **적색** 베텔게우스, 안타레스 |
| 스스로 평가 | 1. 별의 색을 이용해 별의 ( )을/를 비교할 수 있는데, 붉은색으로 보이는 별은 파란색으로 보이는 별보다 표면 온도가 (높다 / 낮다). 2. 전기난로를 켰을 때 열선의 색이 점차 변하는 까닭 설명 |
| 친구에게 설명 | "태양의 표면 온도가 내려가면 태양의 색은 어떻게 변할까?" |

## 3. 표기
- 용어: 표면 온도, 별의 색, 청색, 청백색, 백색, 황백색, 황색, 주황색, 적색, 파란색 빛, 붉은색 빛, 방출, 천체, 열선, 전기난로
- 별 이름(교과서 표기): 나오스, 스피카, 리겔, 알타이르, 베가, 프로키온, 북극성, 태양, 카펠라, 아크투루스, 알데바란, 베텔게우스, 안타레스, 드슈바, 전갈자리
- 온도 단위는 ℃ (태양 약 6000 ℃만 숫자로)

## 4. 사용 금지 (넘기 쉬운 것)
- 흑체, 흑체 복사, 빈의 변위 법칙, 플랑크, 파장(nm·μm), 스펙트럼 그래프의 세기 단위, 켈빈(K)
- 분광형(O B A F G K M), 색지수(B−V), 광도, 별의 크기, H-R도, 별의 진화(적색 거성 등)
- 등급 계산(앞 차시 금지 항목 그대로)

## 5. 정성적으로만 다루는 것
- '파란색 빛을 많이 / 붉은색 빛을 많이 방출'은 빛의 색깔별 양을 막대나 빛 알갱이로만 비교한다(축에 단위·파장 없음).
- 별의 표면 온도 숫자는 교과서 색 띠에 나온 별(과 드슈바)에만 '약 ○ ℃'로 1000 ℃ 단위 어림값을 쓴다. 태양은 교과서 값 약 6000 ℃. 전기난로 열선 온도는 숫자로 쓰지 않는다(낮다 ↔ 높다).
- 하늘 지도(d3-celestial)는 목록 자료의 색 정보로 별을 색칠해 보여 주되, 그 값(B−V)은 화면에 숫자로 쓰지 않는다.

## 6. 미확인
- 별별 표면 온도 어림값(공개 자료의 유효 온도 K에서 273을 빼고 1000 ℃ 단위로 어림): 나오스 약 4만, 드슈바 약 2만 7000, 스피카 약 2만 5000, 리겔 약 1만 2000, 베가 약 9000, 알타이르 약 7000, 프로키온 약 6000, 북극성 약 6000, 카펠라 약 5000, 아크투루스 약 4000, 알데바란 약 4000, 베텔게우스 약 3000, 안타레스 약 3000 (℃) → 선생님이 수업에서 쓰는 앱 값과 대조 필요
- 교과서 출판사 → 화면에 쪽수를 넣지 않음
