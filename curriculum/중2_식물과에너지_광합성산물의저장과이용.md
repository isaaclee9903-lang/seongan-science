# 중2 과학 Ⅴ. 식물과 에너지 — 1. 광합성과 호흡 / 04 광합성산물을 어떻게 저장하고, 어디에 이용할까?

출처: 중학교 과학 2 교과서(임성숙) 178~179쪽.

## 학습 목표 (이번 시간에 나는!)
- 광합성산물의 저장과 이용 과정을 이해하고, 모형으로 설명할 수 있다.

## 본문 핵심
- 식물 잎의 엽록체에서 광합성으로 만들어진 포도당은 녹말로 바뀌어 저장된다.
- 녹말은 물에 잘 녹지 않기 때문에 물에 잘 녹는 설탕 형태로 바뀌어 밤에 체관을 통해 식물의 각 기관으로 운반된다.
- 운반된 양분은 생명활동에 필요한 에너지를 얻기 위해 호흡에 쓰이거나, 몸을 구성하는 성분이 되어 생장하는 데 이용된다.
- 여러 가지 생명활동에 이용하고 남은 양분은 열매, 줄기, 뿌리, 씨 등에 포도당, 설탕, 녹말, 단백질, 지방 등 다양한 형태로 저장된다.
- 그림 Ⅴ-5: 줄기(사탕수수 설탕, 감자 녹말), 뿌리(사탕무 설탕, 고구마 녹말), 열매(옥수수 녹말, 포도 포도당), 씨앗(참깨·검은깨 지방, 완두 단백질).
- 식물은 광합성으로 만든 양분을 에너지원으로 쓰고, 식물체를 구성하는 성분으로 이용하여 생장한다. 저장된 양분은 사람을 비롯한 동물의 먹이가 되기도 한다. 광합성 결과 만들어진 산물은 다양한 생물의 생명활동에 꼭 필요한 에너지원이다. 광합성 결과 발생한 산소는 식물뿐 아니라 여러 생물의 호흡에 이용된다.

## 해 보기 (179쪽): 광합성산물의 저장과 이용 과정 표현하기 (모형으로 설명, 협력적 소통)
준비물: 도화지, 그림 도구, 스마트 기기
1. 저장과 이용 과정을 토의한다.
2. 각 과정을 표현할 수 있는 아이디어를 생성형 인공지능에 질문한다.
3. 인공지능의 답이 적절한지 검증하고, 보완할 점을 다시 질문하며 모형을 만든다.
4. 완성된 모형을 공유하고 과정을 설명한다.
5. 다른 모둠의 모형을 보고 잘한 점과 개선할 점을 이야기한다.
옆 말풍선: 에너지가 흡수되고 방출되는 과정을 강조하면 좋겠어 / 생활용품을 이용해서 모형을 만드는 방법도 있지 않을까?
화면 속 예시(인공지능이 그린 모형 그림, 2026-11-13 확대 확인): 해(빛에너지) → 잎에서 물 + 이산화 탄소 → 포도당 + 산소, 포도당 → 녹말 → 설탕, 줄기 속 두 관(파랑: 위로, 노랑: 설탕이 오가는 길), 다른 잎에서 산소 + 포도당 → 이산화 탄소 + 물과 에너지, 땅속 감자, 토마토 열매, 호흡·생장·꽃 피우기, 고구마·완두콩·사탕수수. 관 이름은 그림에 없음.

## 스스로 평가 (179쪽)
1. 식물은 광합성으로 만든 양분을 ( 에너지 )을/를 얻거나, 식물이 ( 생장 )하는 데 사용하고, 남은 양분은 각 기관에 저장한다.
2. 감자에 녹말이 저장되기까지의 과정을 설명해 보자.
- 친구에게 설명: "식물의 광합성은 다른 생물들에게 어떤 가치가 있을까?"

## 수업 반영 (2026-11-13 전면 수정 때 교과서 178~179쪽과 문장 단위 대조)
- 이전 판 그림에서 감자가 뿌리에 달려 있었음 → 오개념이라 고침. 새 3D에서는 땅속 줄기에서 뻗은 기는줄기 끝에 감자가 달림(그림 Ⅴ-5: 감자는 '줄기에' 칸). '기는줄기'는 그림 이름표로만 쓰고 설명·문제에는 쓰지 않음.
- 읽기 핵심 정리의 '녹말(엽록체에 저장)' → '녹말(잎에 저장)'으로 고침(교과서는 저장 장소를 엽록체라고 쓰지 않음). 잎 속 돋보기 그림에서는 엽록체 안에서 포도당이 이어져 녹말이 되는 모습으로 보임(01차시 녹말 확인과 연결).
- 양분의 길: 체관은 이름과 길(노란 관)로만 보이고 구조는 다루지 않음. 설탕은 아래로 감자·뿌리, 위로 새순·꽃으로 감(교과서 "각 기관으로 운반").
- 양분 창고: 틀렸을 때 답을 알려 주지 않고 생각할 거리를 줌. 맞히면 교과서 그림 Ⅴ-5의 기관·형태를 알려 줌.

## 미확인 (선생님 확인 필요)
- 잎 속 돋보기에서 녹말을 엽록체 안의 포도당 사슬로 그렸다(교과서 해 보기 그림의 녹말 기호와 비슷하게). 본문에는 엽록체라고 쓰지 않았다.
- 3D 감자 식물의 기는줄기·꽃·수염뿌리는 실제 감자 모양을 따른 그림 요소이고, 이름표('기는줄기', '꽃')만 붙였다.
- 그림 Ⅴ-5의 씨앗 사진 두 개(숟가락 위 검은깨와 흰깨)는 교과서에 작물 이름이 없어 "참깨"로 적었다. 지방 저장 보기로만 쓴다.
- 해 보기의 생성형 인공지능: 학생이 바로 쓸 수 있는지 몰라 페이지에서 직접 연결하지 않고, 질문 예시와 가상의 답을 검증하는 활동으로 만들었다. 가상의 답임을 화면에 적었다.
- 실제 도화지 모형을 만드는지 몰라, 페이지의 카드 모형은 도화지에 옮겨 그리기 전 설계로 쓸 수 있게 했다.
