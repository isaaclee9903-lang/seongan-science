# 교육과정 기준 문서 — 중2 과학 Ⅱ. 지권의 변화 › 지구 내부는 어떻게 생겼을까?

> **출처:** 교과서 사진 3장 (도입 '지구 내부는 어떻게 생겼을까?' + 그림 Ⅱ-2 지구 내부를 조사하는 방법, 그림 Ⅱ-3 지권의 층상 구조, 본문 '# 지권의 층상 구조' + 모호로비치치 우표 + 지구 중력 측정 위성 GOCE + 스스로 평가)
> **교육과정:** 2022 개정으로 판단 (Ⅶ·Ⅷ 단원과 같은 교과서). 출판사·쪽수 미확인
> **규칙:** 웹페이지의 모든 글·시뮬레이션·퀴즈는 이 문서 범위 안에서만 만든다.
> **만든 방식:** 디스커션 모드. 선생님 확인 사항(2026-10-11): 중2, 4쪽 기본형, 조사 방법은 수업 활동 없이 설명만. 콘셉트는 "지구 속으로 점점 들어가는 여행". 이 소단원 앞의 시작 단원은 나중에 만든다.

## 1. 학습 목표 (교과서 '이번 시간에 나는!')
- 지권의 층상 구조와 특징을 조사하고 설명할 수 있다.

## 2. 교과서에서 다루는 내용
| 개념 | 교과서 표현 |
|---|---|
| 도입 | X선 사진을 찍으면 직접 볼 수 없는 몸속 뼈의 모습을 볼 수 있다. 직접 볼 수 없는 지구 내부의 모습은 어떻게 알아낼 수 있을까? |
| 직접 조사 | 직접 **땅을 뚫어 땅속 물질을 조사**하거나 **화산 활동으로 분출하는 용암** 등을 분석하는 방법이 있다. 이런 방법은 지구 내부를 구성하는 물질을 직접 알아낼 수는 있지만 **지구 내부 전체의 모습을 알기는 어렵다** |
| 지진파 | 수면을 건드리면 물결이 생겨 퍼져 나가는 것처럼 지진이 발생하면 진동이 지구 전체로 퍼져 나가는데, 이 진동을 **지진파**라고 한다. 지진파를 분석하면 **지구 내부 물질의 상태와 내부 구조**를 알아낼 수 있다 |
| 층상 구조 | 지구 내부는 크게 **지각, 맨틀, 외핵, 내핵**으로 구분된 **층상 구조**를 이룬다 |
| 그림 Ⅱ-2 | 지구 내부를 조사하는 방법: 지진파 분석하기 / 화산 분출물 조사하기 / 직접 땅을 뚫어 조사하기(시추) |
| 그림 Ⅱ-3 | 지권의 층상 구조: 지각, 맨틀, 외핵, 내핵. 깊이 5~35 km, 2900 km, 5100 km, 6400 km. 확대 그림: 대륙 지각, 해양 지각, 맨틀 |
| 모호로비치치 | 1909년 지진학자인 **모호로비치치(Mohorovičić, A., 1857~1936)**는 지하 **약 35 km** 부근에서 **지진파의 속력이 크게 변하는 것**을 발견하였다. 그는 이곳부터 물질의 성질이 지표 부근과 달라지기 때문에 이런 현상이 생긴다고 설명하였다. 이후 여러 과학자들이 지진파를 연구하여 지구 내부의 층상 구조를 밝혀내었다 |
| 사진 설명 | 모호로비치치의 업적을 기념하여 그의 얼굴을 넣어 만든 우표 |
| 지각 | 지권 가장 바깥에 있는 **고체 상태의 얇은 층**이다. **여러 가지 암석**으로 이루어져 있으며, **대륙 지각과 해양 지각**으로 구분한다. 대륙 지각의 평균 두께는 **약 35 km**이고, 두꺼운 곳은 **약 70 km**에 달한다. 해양 지각의 평균 두께는 **약 5 km** 정도로 대륙 지각보다 얇다 |
| 맨틀 | 지각 아래에서부터 깊이 **약 2900 km**까지의 층으로, 지구 전체 부피의 **약 80 %**를 차지하고 있다. 맨틀은 **지각보다 밀도가 큰 고체 상태의 암석**으로 이루어져 있지만 **부분적으로 암석이 녹아 흐르는 성질**을 가진 곳도 있다 |
| 외핵 | 깊이 약 **2900 km에서 5100 km**까지의 층이다. 주로 **철과 니켈**로 구성되어 **맨틀보다 밀도가 크고 액체 상태**이다 |
| 내핵 | 외핵 아래인 깊이 약 **5100 km에서 지구 중심인 6400 km**까지의 층이다. 지구 가장 안쪽 층으로, **밀도가 가장 크며** 외핵처럼 주로 **철과 니켈**로 이루어져 있지만 **고체 상태**이다 |
| 인공위성 | 최근에는 인공위성을 활용해 지구 내부 구조를 연구하기도 한다. 지구의 중력은 물질의 밀도나 분포에 따라 달라지는데, 인공위성에서 지구의 중력을 정밀히 측정하여 **지각과 맨틀의 경계**를 밝히고 있다. (사진) **지구 중력 측정 위성 GOCE**, GOCE 위성이 알아낸 지각과 맨틀 경계 |
| 스스로 평가 | 1 지권은 지표면부터 순서대로 지각, (  ), (  ), 내핵으로 구분된 층상 구조를 이룬다. 2 지진파를 이용해 지구 내부 구조를 조사할 때의 장점을 설명해 보자 |
| 친구에게 설명 | "우리 주변의 물체를 이용해 지구 내부 구조를 비유해 볼까?" |

## 3. 표기
- 용어: 지권, 지구 내부, 지표, 지표면, 지진, 지진파, 진동, 층상 구조, 지각, 대륙 지각, 해양 지각, 맨틀, 외핵, 내핵, 지구 중심, 암석, 용암, 화산 활동, 화산 분출물, 시추, 밀도, 고체, 액체, 철, 니켈, 부피, 중력, 인공위성
- 인물: 모호로비치치(Mohorovičić, A., 1857~1936)
- 수치: 1909년, 약 35 km, 약 70 km, 약 5 km, 약 2900 km, 약 5100 km, 6400 km, 약 80 %, 그림의 5~35 km
- 띄어쓰기: '대륙 지각', '해양 지각', '지구 내부', '층상 구조', '지구 중심', '화산 활동'은 띄어 쓴다. '지진파', '지표면', '지권'은 붙인다. 단위는 숫자와 띄어 쓴다(35 km, 80 %)

## 4. 사용 금지 (넘기 쉬운 것)
- **모호면·모호로비치치 불연속면, 구텐베르크면, 레만면** 같은 경계 이름 (교과서는 '지각과 맨틀의 경계', '약 35 km 부근'으로만 씀)
- P파·S파, 지진파 암영대, 지진파 속력의 수치, 굴절·반사
- 지구 내부의 **온도·압력 수치**와 "깊을수록 뜨겁다" 같은 온도 설명 (교과서 본문에 없음). 내핵이 고체인 까닭(압력)
- 각 층의 밀도 수치(g/cm³), 각 층의 부피·질량 비율 중 맨틀 약 80 % 외의 수치
- 암석권·연약권, 상부 맨틀·하부 맨틀, 맨틀 대류, 판, 지구 자기장의 생성 (다음 차시일 수 있음)
- 지각을 이루는 암석 이름(화강암·현무암 등), 원소 비율
- 가장 깊은 시추 기록 같은 교과서 밖 수치, GOCE의 발사 연도·운용 기관·궤도 높이
- 지구 반지름이라는 말 (교과서는 '지구 중심인 6400 km'로 씀. 웹에서도 '깊이 6400 km(지구 중심)'로만 씀)

## 5. 정성적으로만 다루는 것
- 3D·2D 단면 그림에서 **지각 두께는 실제보다 두껍게** 그린다(실제로는 지구 크기에 비해 아주 얇음). 그림마다 표시한다. 맨틀·외핵·내핵의 두께는 깊이 수치에 맞춘다.
- 층의 색(갈색·붉은색·주황색·흰색)은 교과서 그림 Ⅱ-3을 따른 것이며 온도를 뜻하지 않는다. 글·퀴즈에서 색과 온도를 연결하지 않는다.
- 밀도는 "지각 < 맨틀 < 외핵 < 내핵" 순서만 막대 높이로 보여 준다. 막대 높이는 모형이며 수치가 없다.
- 지진파가 퍼지는 그림에서 경계를 지날 때 물결 간격이 달라지는 것은 "지진파의 모습이 달라진다"는 개념 이해를 위한 모형이다. 빨라지는지 느려지는지를 글·퀴즈로 묻지 않는다. 모호로비치치 그림은 교과서대로 "약 35 km 부근에서 속력이 크게 변한다"까지만 쓴다.
- 지구 속 여행 캡슐은 상상 장치다. 실제로 사람이 들어갈 수 없다는 것을 화면에 밝힌다.
- 외핵의 일렁이는 움직임은 '액체 상태'를 보여 주기 위한 그림 표현이다. 흐름의 방향·까닭은 다루지 않는다.
