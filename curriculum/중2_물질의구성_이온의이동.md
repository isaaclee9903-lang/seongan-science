# 중2 과학 Ⅳ. 물질의 구성 — 2. 물질의 구성 입자 / 02 이온이 이동하는 까닭은 무엇일까?

출처: 중학교 과학 2 교과서(임성숙) 156~157쪽. 159쪽 개념 확인 1~3, 160쪽 정리, 161쪽 7번, 162쪽 10번(장마철 누전), 163쪽 가치·태도 목표도 이 차시 범위(2026-11-16 교과서 파일로 다시 대조).

## 학습 목표
- 이온이 전하를 띠고 있음을 설명할 수 있다.

## 본문 핵심
- 소금물에서는 이온이 있어 전류가 잘 흐른다.
- 이온이 든 수용액에 전류를 흘려 주면 양이온은 (−)극, 음이온은 (+)극으로 이동한다. 이온이 전하를 띠고 있기 때문이다.
- 황산 구리(Ⅱ) 수용액: 파란색 성분이 (−)극으로 이동 → 구리 이온(Cu²⁺). 과망가니즈산 칼륨 수용액: 보라색 성분이 (+)극으로 이동 → 과망가니즈산 이온(MnO₄⁻). 칼륨 이온(K⁺), 황산 이온(SO₄²⁻)은 그림 Ⅳ-13에 함께 나타남.

## 탐구 (156쪽): 전기력을 이용한 이온의 이동 관찰하기
페트리 접시를 흰 종이 위에 놓고 양 끝에 금속판, 질산 칼륨 수용액을 넣고 전원 장치와 연결, 전류를 흘린다. 가운데에 황산 구리(Ⅱ) 수용액 한 방울, 변화 관찰. 과망가니즈산 칼륨 수용액으로 반복. 안전: 시약 냄새·피부 주의, 폐수통 처리, 감전 위험으로 전선·금속판을 맨손으로 만지지 않기.

## 스스로 평가 (157쪽)
1. 이온이 든 수용액에 전류를 흘려 주면 양이온은 ( − )극으로, 음이온은 ( + )극으로 이동한다.
2. 전류를 따라 이온이 이동할 수 있는 까닭을 설명해 보자. (이온이 전하를 띠고 있어 전기력을 받기 때문)

## 정리 문항 (157·159·161·162쪽)
- 정리하기 1: 과정 3과 4에서 나타난 변화(파란색 → (−)극 쪽, 보라색 → (+)극 쪽). 정리하기 2: 파란색 이온 (+)전하, 보라색 이온 (−)전하와 그 까닭.
- 159쪽 개념 확인 1: K⁺·Cu²⁺ → (−)극, MnO₄⁻·SO₄²⁻ → (+)극. 2: (−)전하 이온은 (+)극, (+)전하 이온은 (−)극. 3: 빈칸 (−), (+), 전하.
- 161쪽 7번: 파란색 구리 이온이 이동하는 극 → (−)극.
- 162쪽 10번: 순수한 물은 전기가 흐르지 않지만 빗물·습기 찬 물체에는 물에 녹은 이온 때문에 전기가 흐름 → ㉠ 이온, 전하를 띠고 있음.

## 용어 표기
이온, 양이온, 음이온, 전류, 전원 장치, 금속판, 페트리 접시, 질산 칼륨 수용액, 황산 구리(Ⅱ) 수용액, 과망가니즈산 칼륨 수용액, 구리 이온, 황산 이온, 칼륨 이온, 과망가니즈산 이온, (+)극, (−)극, 전기력

## 초과 (쓰지 않음)
전기 분해, 산화·환원, 이온 이동 속도, 전압 수치

## 미확인 (선생님 확인 필요)
- 실제로 이 실험을 하는지. 가상 실험(3D)으로 넣었다.
- 이동 빠르기와 번지는 모양, 입자 크기는 정한 모형이다. 실제로는 금속판에서 거품이 생길 수 있지만 전기 분해(초과)라 그리지 않았다.
- 질산 칼륨 수용액을 "전류가 흐르도록 넣는 것"으로만 설명했고 까닭은 더 쓰지 않았다(어느 극으로 갈까에서 K⁺·NO₃⁻가 이동하는 모습만 보임).
- 과정 4의 "과정 1~2를 반복한다"는 교과서 표기 그대로 두었다(새 페트리 접시로 1~3을 다시 하게 만듦).
- 어느 극으로 갈까의 소금물(Na⁺, Cl⁻)은 156쪽 도입(소금물 속 이온)과 155쪽 그림 Ⅳ-12의 이온으로 만들었다. 소금물 이온 이름은 156~157쪽에 직접 나오지 않는다.
- 구리 이온 입자는 그림 Ⅳ-13처럼 파랗게, 나머지 원자 색은 분자와 이온·원소 수업과 같게 그렸다.
- 전원 장치 숫자판은 숫자 없이 켜진 표시만 그렸다(전압 수치 초과).
