# 교육과정 기준 문서 — 중2 과학 Ⅶ. 전기와 자기 › 전기 에너지의 이용 (소비 전력과 전력량)

> **출처:** 교과서 사진 2장 (이삭 선생님 제공, 2026-10-02). ① 단원 표지 "우리는 전기 에너지를 어떻게 이용할까?"와 본문, 그림 Ⅶ-10 ② 그림 Ⅶ-11 전기 에너지 전환과 에너지 소비 효율 등급 본문. 쪽수는 사진에 보이지 않음(미확인).
> **앞 차시:** `중2_전기와자기_옴의법칙.md`, `중2_전기와자기_저항의연결.md`. 앞 차시 표기를 그대로 따른다.

## 1. 학습 목표 (교과서 "이번 시간에 나는!")
- 일상생활에서 전기 에너지가 다양한 형태의 에너지로 전환됨을 소비 전력과 관련지어 설명할 수 있다.

## 2. 교과서에서 다루는 내용
| 구분 | 교과서 표현 |
|---|---|
| 도입 그림 | 형광등과 LED등. "밝기는 같은데 전기 에너지 사용량이 달라." |
| 생활 속 이용 | 핸드폰을 충전하고, 헤어드라이어로 머리를 말리며, 전기 버스를 타고 등교하기도 한다 |
| 에너지 전환 | 전기 에너지는 **빛에너지나 열에너지, 운동 에너지 등** 다양한 형태의 에너지로 전환되고, 우리는 이 에너지를 이용한다 |
| 소비 전력 | 전기 기구마다 사용하는 전기 에너지의 양은 다르다. **1초 동안 전기 기구가 소모하는 전기 에너지의 양**을 소비 전력이라 하고, 단위는 **W(와트)** |
| 정격 전압 | 전기 기구를 작동하기 위해 필요한 전압 (용어 풀이) |
| 그림 Ⅶ-10 | 전기 기구의 소비 전력. 에어컨: 정격 전압 220 V, 소비 전력 690 W / 선풍기: 정격 전압 220 V, 소비 전력 10 W. 소비 전력이 큰 에어컨은 소비 전력이 작은 선풍기보다 같은 시간 동안 더 많은 전기 에너지를 사용한다 |
| 전력량 | 전기 기구가 **일정 시간 동안 소모하는 전기 에너지의 양**. **전력량 = 소비 전력 × 시간**. 단위는 **Wh(와트시)**나 **kWh(킬로와트시)** |
| 1 Wh | 소비 전력이 1 W인 전기 기구를 1시간 동안 사용했을 때 소모하는 전기 에너지의 양 |
| 단위 환산 | 1 kWh = 1000 Wh |
| 그림 Ⅶ-11 전기 에너지 전환 | 전기 에너지 → **운동 에너지**(드론, 믹서), **빛에너지**(조명, 텔레비전), **열에너지**(전기 주전자, 전열기), **화학 에너지**(배터리), **소리 에너지**(텔레비전, 헤드폰) |
| 동시 전환 | 전기 에너지는 **한 가지의 에너지뿐만 아니라 두 가지 이상의 에너지로 동시에 전환**되기도 한다 (예: 텔레비전 → 빛에너지와 소리 에너지) |
| 기구 선택 | 전기 기구는 **성능이 같아도 소비 전력이 다를 수 있어** 전기 기구를 선택할 때 소비 전력을 비교해야 한다 |
| 에너지 소비 효율 등급제 | 우리나라에서는 전기 에너지의 효율적인 사용을 위해 에너지 소비 효율 등급제를 시행. **1~5 등급**으로 구분하며, **1 등급에 가까울수록** 전기 에너지를 효율적으로 사용하는 전기 기구 |
| 활동 예고 | 다양한 전기 기구에서 일어나는 에너지 전환과 소비 전력을 조사해 보자 (활동 쪽은 사진에 없음) |

## 3. 표기
- 용어: 전기 에너지, 빛에너지, 열에너지(붙여 씀), 운동 에너지, 화학 에너지, 소리 에너지(띄어 씀), 에너지 전환, 소비 전력, 정격 전압, 전력량, 전기 기구, 에너지 소비 효율 등급(제), 1 등급~5 등급
- 단위: W(와트), Wh(와트시), kWh(킬로와트시), V
- 식: 전력량 = 소비 전력 × 시간 (시간은 '시간(h)' 단위로 계산)

## 4. 사용 가능 (계산)
- 전력량(Wh) = 소비 전력(W) × 사용 시간(h). 예: 에어컨 690 W × 2시간 = 1380 Wh = 1.38 kWh
- Wh ↔ kWh 환산 (1 kWh = 1000 Wh)
- 같은 시간 동안 소비 전력이 큰 기구가 더 많은 전기 에너지를 사용한다는 비교

## 5. 사용 금지 (넘기 쉬운 것)
- P = VI, P = I²R, P = V²/R 등 전압·전류로 전력을 구하는 식
- 줄(J) 단위, 1 W = 1 J/s, 줄열, 에너지 보존 법칙의 정량 계산
- 에너지 효율(%) 계산, 등급을 정하는 기준·계산, 대기 전력
- 전기 요금 계산(누진제, 원/kWh 단가)
- 분·초 단위 시간을 쓰는 전력량 계산(초등 분수 계산이 필요해짐) — 시간은 정수 또는 0.5 단위 시간으로만
- 교류·직류, 송전, 발전소

## 6. 교사 요청·수업 설계로 넣되 정성적으로 다루는 것
- 기구별 에너지 전환: 교과서 그림 Ⅶ-11의 기구(드론, 믹서, 조명, 텔레비전, 전기 주전자, 전열기, 배터리, 헤드폰)와 앞 쪽 기구(전등, 선풍기, 헤어드라이어, 전기 버스). 화살표·띠 그림으로만 보여 주고 비율 숫자는 쓰지 않는다
- 에너지 소비 효율 등급: '1~5 등급, 1 등급에 가까울수록 효율적'까지만. 등급 표시 그림은 실제 표시를 흉내 내지 않은 단순한 막대 그림으로 그린다
- 기구 고르기 예시: 성능이 같은 두 기구의 소비 전력·등급을 예시 값으로 비교하고 전력량을 계산한다 (예시 값 표시)
- 형광등과 LED등: "밝기가 같아도 소비 전력이 다르면 같은 시간 동안 사용하는 전기 에너지가 다르다"까지
