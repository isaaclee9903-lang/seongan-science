# 범위 문서(초안) — 읽기 자료(교양·진로) › 전기를 담는 작은 그릇, MLCC

> **성격:** 중학교 정규 교육과정 밖의 **읽기 자료**(교양·진로). 「여기도, 저기도 반도체」의 후속 특별 수업. 교과서 원문이 없어 Claude가 중2 「전기와 자기」 기준 문서 범위에 맞춰 보수적으로 만든 **초안**이다. 선생님 확인 후 '초안'을 뗀다.
> **선생님 결정(2026-10-03, 디스커션):** 반도체 자료의 후속(교양·진로) / 원리는 **용어와 단위까지**(축전기·충전·방전 용어, 용량 단위는 이름만) / 옴의 법칙 기본형 4페이지 + 3D / **실험 없음**(가상 시뮬레이션과 읽기만).
> **근거 조사:** 웹 검색 요약(2026-10-03). 조사 환경에서 제조사 원문 페이지가 차단되어 열지 못했으므로 7절 항목은 원문 확인이 필요하다.

## 1. 앞 차시에서 가져오는 개념 (그대로 사용)
- 수로 모형: 펌프=전지, 물의 흐름=전류, 수로=도선, 수문=스위치, 물레방아=전구(저항), **수면의 높이 차=전압** (중2 옴의 법칙)
- 전자는 (-)극 → (+)극, 전류는 (+)극 → (-)극. 전선에는 이미 전자가 꽉 차 있음 (중2 옴의 법칙)
- 도체·부도체(전기가 거의 통하지 않는 물질) (반도체 읽기 자료)
- 전기 에너지가 빛·열 등으로 전환 (중2 전기 에너지)
- 시스템 반도체 = 두뇌(CPU, AP), 메모리 = 창고 (반도체 읽기 자료)

## 2. 사용 가능
- **축전기**(커패시터, 콘덴서): 전기를 잠깐 모아 두었다가 내보내는 부품. 금속판 두 장 사이에 전기가 통하지 않는 얇은 층(부도체)을 끼운 구조
- **충전**: 전지를 연결하면 전자가 한쪽 판으로 몰려가 (-)를, 다른 판은 전자를 잃어 (+)를 띤다. 전자는 부도체 층을 건너가지 못한다
- **방전**: 전지 대신 전구 등을 연결하면 모였던 전자가 회로를 따라 돌아가며 잠깐 전류가 흐르고 곧 멈춘다
- **용량**(전기를 담을 수 있는 정도) 단위 이름만: 패럿(F), 마이크로패럿(μF), 피코패럿(pF). 계산·환산 없음
- 정성적 관계(숫자·공식 없이): 판이 넓을수록, 겹을 많이 쌓을수록, 사이 층이 얇을수록 더 많이 담는다 → "개념 이해를 위한 모형" 표시
- **MLCC** = 적층 세라믹 축전기(콘덴서). 세라믹 층과 금속 전극 층을 번갈아 **수백 겹** 쌓고, 양 끝에 **외부 전극**을 붙임. 내부 전극은 한 장씩 번갈아 왼쪽·오른쪽 외부 전극에 이어짐
- 크기: 작은 것은 길이가 1 mm도 안 되어 모래알만 함. 층 하나는 머리카락 굵기보다 훨씬 얇음(수치 없이 비교만)
- 개수: 최신 스마트폰 약 1,000개, 전기 자동차 1만 개가 넘게(약 1만 8천~2만 개 보도) (삼성전기 발표 보도)
- 역할(삼성전기 비유): **댐** — 전기를 모아 두었다가 반도체 칩이 필요한 만큼 일정하게 공급, 전압이 흔들리는 것(노이즈)을 줄임
- 별명: "전자 산업의 쌀"(어디에나 많이 들어가서)
- 만드는 과정(이름과 순서만): 세라믹 가루 반죽 → 얇은 시트 → 내부 전극 인쇄 → 쌓기(적층) → 눌러 붙이기 → 자르기 → 높은 온도에서 굽기 → 외부 전극 → 검사
- 산업: 일본과 한국 기업들이 세계 MLCC를 많이 만든다. 한국 기업도 스마트폰·전기 자동차·AI 서버용 MLCC를 만든다(순위·점유율 수치 없음)
- 진로: 재료 개발, 공정·설비, 품질 검사, 제품 개발(회로에 맞는 부품 고르기) — 반도체 자료의 직무 구분과 같은 말로

## 3. 사용 금지
- 전기 용량 공식(Q = CV, C = εA/d), 에너지 공식, 시간 상수, 유전율 수치
- '유전체', '분극', '강유전체' 같은 고등·대학 용어(→ "전기가 통하지 않는 얇은 세라믹 층")
- 티탄산바륨, 화학식(BaTiO₃) 같은 화학 용어. 금속 이름은 "금속"으로(니켈 이름은 미확인 항목)
- 교류·직류, 주파수, 임피던스, 필터 회로, 디커플링 같은 회로 용어
- 마이크로미터(μm) 단위 수치, 소성 온도 수치
- 회사별 점유율 순위, 매출, 주가, 수출액
- 축전기 직렬·병렬 계산
- 수업에서 하지 않는 실험(축전기 충전 실습 등) 안내

## 4. 앞 차시와 연결
- 옴의 법칙 수로 모형: 칩 바로 옆의 **물탱크(댐)** = MLCC. 칩이 갑자기 물을 많이 쓰면 멀리 있는 펌프보다 탱크가 먼저 물을 내줘서 수면(전압)이 덜 내려감
- 반도체 읽기 자료: 반도체가 '두뇌'라면 MLCC는 두뇌 옆에서 전기를 고르게 대 주는 '댐'. 반도체처럼 층을 쌓는 기술(HBM)과 비교
- 전기 에너지: 방전할 때 전구에서 전기 에너지 → 빛에너지·열에너지

## 5. 웹 자료에서 정한 표현
- 3D 모형의 겹 수(실제 수백 겹 → 화면 10여 겹), 크기, 전자 개수, 빠르기는 "개념 이해를 위한 모형"으로 표시
- 비유 출처 구분: 공식 비유(댐 — 삼성전기, 전자 산업의 쌀 — 업계·언론) / 선생님 수업 비유(수로 모형의 물탱크)
- 시뮬레이션의 수면 높이·전압 그래프에는 눈금 숫자를 쓰지 않는다

## 6. 미확인 (선생님 확인 필요)
- 용어: '축전기'와 '콘덴서'·'커패시터' 중 어느 것을 주 용어로 쓸지 (이 자료는 축전기를 주로, 나머지는 괄호로)
- MLCC 우리말 표기: '적층 세라믹 콘덴서'(업계) / '적층 세라믹 축전기' (이 자료는 앞의 것을 소개하고 축전기라고 설명)
- 충전 때 전자가 판에 모인다는 설명이 중2 「전기」 단원 전하·대전 설명과 표현이 맞는지
- 단위 μF, pF의 '마이크로', '피코' 접두어 소개 여부(이 자료는 이름만 한 번 보여 줌)
- '칩에 걸리는 전압이 잠깐 떨어지면 칩이 계산을 틀리거나 멈출 수 있다'는 설명(읽기 ④, 수로 모형의 '멈칫')은 일반적인 설명으로 썼음. 멈칫하는 높이는 모형 값
- 정리 페이지의 MLCC 분야 직무 구분(재료 개발·공정 기술·설비·품질 검사·제품 설계·기술 영업)은 Claude가 공정 단계에 맞춰 나눈 것(회사 공식 구분 아님)
- 3D 공정의 '시트 → 인쇄 → 쌓기 → 눌러 붙이고 자르기 → 굽기 → 외부 전극·검사'는 핵심 순서만 보인 것(실제는 바인더 제거, 도금 등 단계가 더 있음)
- 7절의 모든 숫자는 원문 확인 필요
