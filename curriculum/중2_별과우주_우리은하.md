# 교육과정 기준 문서 — 중2 과학 Ⅷ. 별과 우주 › 우리은하에는 어떤 천체가 있을까?

> **출처:** 교과서 사진 3장 (도입 '우리은하에는 어떤 천체가 있을까?' + 은하수 사진, 그림 Ⅷ-7 우리은하의 구조, '# 우리은하를 구성하는 천체_성단', '# 우리은하를 구성하는 천체_성운' + 그림 Ⅷ-8 오리온자리에서 볼 수 있는 성운. 쪽 번호 291~292쪽 근처)
> **교육과정:** 2022 개정으로 판단 (앞 차시와 같은 교과서). 출판사 미확인
> **규칙:** 웹페이지의 모든 글·시뮬레이션·퀴즈는 이 문서 범위 안에서만 만든다.
> **만든 방식:** AUTO(프로토타입) 모드. 교과서 사진 3장으로 작성. 사진에 없는 다음 쪽(해 보기, 스스로 평가 등)은 확인하지 못함

## 1. 학습 목표 (교과서 '이번 시간에 나는!')
- 우리은하의 구조와 크기를 이해할 수 있다.
- 성운과 성단의 특징을 비교할 수 있다.

## 2. 교과서에서 다루는 내용
| 개념 | 교과서 표현 |
|---|---|
| 도입 그림 | 조선 시대의 천문도인 천상열차분야지도에도 은하수가 표현되어 있다 (말풍선 한 줄) |
| 은하수 | 맑은 날, 불빛이 없는 곳에서 밤하늘을 보면 하늘을 가로지르는 뿌연 띠 모양의 은하수를 볼 수 있다. 은빛 강물처럼 밤하늘에 넓게 퍼져 있는 은하수는 수많은 별로 이루어져 있다 |
| 은하 | 우주에는 은하수처럼 수많은 별로 이루어진 집단이 있는데, 이를 **은하**라고 한다 |
| 우리은하 | 수없이 많은 은하들 중에서 태양계가 속한 은하를 **우리은하**라고 한다. **은하수는 지구에서 보이는 우리은하의 일부이다** |
| 사진 | 강원도 함백산 만항재에서 본 은하수 / 하늘 전체를 촬영한 것으로, 은하수는 밤하늘을 가로질러 나타난다 |
| 구조 (위) | 위에서 보면 **중심부에 별들이 밀집해 막대 모양**을 이루고, 그 주변으로 별들이 **나선 모양으로 분포하는 나선팔**이 있다 |
| 구조 (옆) | 옆에서 보면 **중심부가 볼록한 원반 모양**이다 |
| 크기 | 우리은하의 지름은 **약 30000 pc**이고, 태양계는 우리은하의 중심에서 **약 8500 pc** 떨어진 **나선팔에 위치**한다 |
| 그림 Ⅷ-7 | 위에서 본 모습 / 옆에서 본 모습. 태양계, 은하 중심. 8500 pc(약 3만 광년), 30000 pc(약 10만 광년) |
| 성단 | 우리은하에는 수천억 개의 별이 있다. 별들은 대부분 서로 떨어져 있지만 일부는 여럿이 모여 집단을 이루기도 한다. 이렇게 별이 무리 지어 있는 것을 **성단**이라고 하며, 별이 모여 있는 형태에 따라 **산개 성단**과 **구상 성단**으로 구분한다 |
| 산개 성단 | **수십~수만 개**의 별이 **엉성하게** 모여 있으며, **파란색을 띠는 고온의 별**이 많다. 사진: 플레이아데스 성단 |
| 구상 성단 | **수만~수십만 개**의 별이 **촘촘하게 공 모양**으로 모여 있으며, **붉은색을 띠는 저온의 별**이 많다. 사진: M80 |
| 성간 물질 | 별과 별 사이에는 **가스와 티끌** 등의 물질이 있는데, 이를 **성간 물질**이라고 한다 |
| 성운 | 성간 물질이 모여 **구름처럼 보이는 것**. 크게 **방출 성운, 반사 성운, 암흑 성운**으로 나눈다 |
| 방출 성운 | 성간 물질이 주변의 **별빛을 흡수하여 온도가 높아져 스스로 빛을 낸다** |
| 반사 성운 | 성간 물질이 주변의 **별빛을 반사하여 밝게 보인다** |
| 암흑 성운 | 성간 물질이 **뒤에서 오는 별빛을 가로막아 어둡게 보인다** |
| 그림 Ⅷ-8 | 오리온자리에서 볼 수 있는 성운: 반사 성운(M78), 암흑 성운(말머리 성운), 방출 성운(오리온 대성운) |

## 4. 사용 금지 (넘기 쉬운 것)
- 헤일로(은하 헤일로), 팽대부, 은하면, 은하 원반 두께 수치, 우리은하의 질량·나이·회전 속도·공전 주기, 블랙홀(궁수자리 A*)
- 나선팔 이름(페르세우스팔, 오리온팔 등), 막대 나선 은하라는 분류 이름, 허블의 은하 분류, 외부 은하(안드로메다 등) — 다음 차시 내용일 수 있음
- 성단의 나이·거리, 구상 성단이 헤일로에 분포한다는 것, 별의 탄생·진화, 성운에서 별이 태어남
- 성운의 색이 생기는 원리(수소의 빛, 산란 등), 이온화·전리, 성간 소광
- 등급 계산, 분광형, 켈빈(K)

## 5. 정성적으로만 다루는 것
- 우리은하 3D 모형과 그림은 위에서 본 모습(막대 모양 중심부 + 나선팔), 옆에서 본 모습(중심부가 볼록한 원반)만 보여 준다. 두께·팔 개수·감긴 정도는 모형이며 숫자로 쓰지 않는다.
- 길이 숫자는 교과서의 약 30000 pc, 약 8500 pc만 쓴다 (광년은 괄호 안에 교과서처럼).
- 성단 그림은 별의 수와 모인 모습(엉성 ↔ 촘촘)과 별의 색(파란색 ↔ 붉은색)만 비교한다. 화면 속 별 개수는 모형이다.
- 성운은 별빛의 흐름(흡수 → 스스로 빛 / 반사 / 가로막음)을 빛 알갱이 애니메이션으로만 보여 준다. 성운 그림은 사진이 아니라 개념 이해를 위한 모형으로 그리고 '모형'이라고 표시한다.
- 성운의 색(방출 성운 붉은빛, 반사 성운 푸른빛)은 그림에서만 사진처럼 칠하고, 글·퀴즈에서 규칙으로 묻지 않는다.

## 6. 미확인
- 은하수가 띠 모양으로 보이는 까닭(태양계가 원반 안에 있어서 원반 방향으로 별이 많이 보인다)을 3D 시뮬레이션에서 '태양계에서 보기'로 보여 줌 → 교과서 다음 쪽에 있는지 확인 필요
- 다음 쪽의 해 보기·스스로 평가·친구에게 설명하기 → 사진에 없어 정리 페이지 글쓰기 주제를 임의로 정함
- 교과서 출판사 → 화면에 쪽수를 넣지 않음
