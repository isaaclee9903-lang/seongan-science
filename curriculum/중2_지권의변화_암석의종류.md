## 2. 교과서에서 다루는 내용
| 개념 | 교과서 표현 |
|---|---|
| 도입 (64쪽) | 같은 재료를 써도 요리 방법에 따라 구이나 찜, 튀김 등 음식의 종류가 달라지는 것처럼, 암석도 **생성 과정에 따라 분류**할 수 있다. 암석의 종류에는 마그마가 식어서 생긴 **화성암**, 퇴적물이 쌓여서 만들어진 **퇴적암**, 원래 있던 암석이 높은 열과 압력을 받아 성질이 변하여 생긴 **변성암**이 있다 |
| 지각 | 이런 다양한 암석은 지권의 층상 구조에서 가장 바깥층인 **지각**을 이룬다. 우리나라 곳곳에서도 화성암이나 퇴적암, 변성암으로 이루어진 지형을 만날 수 있다 |
| 도입 사진 | 전남 해남 두륜산(화성암), 경기도 가평 명지 계곡(변성암), 정선 봉양리(퇴적암). 말풍선: 암석으로 이루어진 지형을 본 경험을 이야기해 보며, 사진에 나타난 각 암석의 특징을 설명해 보자 |
| 화성암 (65쪽) | 지하 깊은 곳에서 암석이 녹아 만들어진 **마그마**가 지표로 흘러나와 굳거나 지하에서 식어 굳으면 암석이 되는데, 이를 **화성암**이라고 한다 |
| 화산암 | 마그마가 **지표로 분출하여 빠르게 식으면** 광물 입자의 크기가 **매우 작은** 암석이 된다. 이 암석을 **화산암**이라고 하며, 대표적인 화산암에는 **현무암과 유문암**이 있다 |
| 심성암 | 마그마가 **지하 깊은 곳에서 천천히 식으면** 광물 입자의 크기가 **큰** 암석이 된다. 이렇게 만들어진 화성암을 **심성암**이라고 하며, 대표적으로 **화강암과 반려암**이 있다 |
| 화성암의 색 | 화성암은 암석의 색에 따라 구분할 수도 있다. **화강암과 유문암**은 석영과 장석 등 **밝은색 광물이 많아** 암석의 색이 밝다. 하지만 **반려암과 현무암**에는 감람석, 휘석 등 **어두운색 광물이 많아** 암석의 색이 어둡다 |
| 그림 Ⅱ-5 화성암의 종류 | 가로축 '암석의 색' (어둡다 ↔ 밝다), 세로축 '입자 크기' (작다 ↕ 크다). 화산암: 현무암(어둡다)·유문암(밝다), 심성암: 반려암(어둡다)·화강암(밝다). 배경에 화산과 땅속 단면 그림 |
| 퇴적암 (66쪽) | 땅 위에 드러난 암석은 시간이 흐르며 **자갈, 모래, 진흙** 등으로 잘게 부서진다. 이들은 바람이나 물 등에 의해 운반되어 강이나 바다, 호수 등의 바닥에 쌓이는데, 이를 **퇴적물**이라고 한다. 이 퇴적물이 오랜 시간 **다져지고 단단하게 굳어져** 만들어진 암석을 **퇴적암**이라고 한다 |
| 그림 Ⅱ-6 퇴적암의 생성 과정 | ① 퇴적물이 쌓인다. ② 퇴적물이 다져진다. ③ 물에 녹아 있는 여러 물질이 퇴적물을 붙여 단단한 암석이 된다 |
| 퇴적암의 종류 | 퇴적암은 퇴적물의 크기나 종류에 따라 구분한다. **역암**은 주로 **자갈**로, **사암**은 주로 **모래**로, **이암**은 **진흙**으로 만들어진다. 또 **석회암**은 물에 녹아 있던 **석회 물질**이 쌓이거나, **산호나 조개껍데기** 같은 석회 물질로 된 생물의 유해가 쌓여 만들어진다 |
| 그림 Ⅱ-7 퇴적암의 종류 | 역암-자갈, 사암-모래, 이암-진흙, 석회암-산호 등 석회 물질 |
| 층리 | 퇴적암에는 크기나 종류, 색 등이 다른 퇴적물이 쌓이며 만들어진 **나란한 줄무늬**가 나타나기도 하는데, 이를 **층리**라고 한다 |
| 화석 | 또 퇴적물이 쌓이는 과정에서 과거에 살았던 **생물의 유해나 흔적**이 퇴적암에 **화석**으로 남기도 한다. (사진: 층리, 공룡 발자국 화석. 말풍선: 경남 고성 상족암에서는 층리와 화석을 볼 수 있어) |
| 변성암 (67쪽) | 깊은 땅속에서 암석이 **높은 열이나 압력**을 받으면 암석을 이루는 **광물의 구성이나 배열** 등이 바뀌어 암석의 성질이 변한다. 이러한 작용을 **변성 작용**이라고 하며, 변성 작용으로 만들어진 기존 암석과 다른 성질의 암석을 **변성암**이라고 한다 |
| 입자 변화 | 열이나 압력에 의한 변성 작용을 받으면 암석을 이루는 광물 입자가 **더 커지거나 치밀**해진다 |
| 엽리 | 또한 그림 Ⅱ-8처럼 **압력을 받는 방향과 수직 방향**으로 광물 입자가 재배열되며 줄무늬가 나타나기도 하는데, 이를 **엽리**라고 한다. 엽리는 **편암과 편마암**에서 잘 관찰할 수 있다 |
| 그림 Ⅱ-8 엽리의 형성 과정 | 원래 암석(양쪽에서 압력 화살표) → 변성 작용 → 변성암(입자가 한 방향으로 늘어선 줄무늬) |
| 변성암의 종류 | 변성암은 원래의 암석이나 변성 작용이 일어난 정도에 따라 규암, 대리암, 편암, 편마암 등으로 구분할 수 있다 |
| 그림 Ⅱ-9 변성암의 종류 | 원래 암석 → (열과 압력) → 변성암: **사암 → 규암**, **석회암 → 대리암**, **화강암 → 편마암**, **이암 → 편암 → 편마암** |
| 탐구 (68~69쪽) | 암석을 관찰하여 분류하기. 목표: 암석의 특징을 관찰하고 특징에 따라 암석을 분류할 수 있다. 자료 수집·분석 및 해석 / 협력적 소통 |
| 준비물 | 암석 표본 6가지(화강암, 현무암, 역암, 사암, 편마암, 대리암), 숫자 붙임딱지, 돋보기, 묽은 염산, 스포이트, 페트리 접시, 실험복, 보안경, 실험용 장갑 |
| 과정 | 1 모둠별로 암석 표본에 ①~⑥의 숫자 붙임딱지를 붙인다. 2 각 암석을 관찰하고 특징을 정리한다 (돋보기로 암석의 색과 입자 크기, 무늬 등의 특징을 관찰한다). 3 각 암석에 묽은 염산을 2~3방울 떨어뜨려 반응이 일어나는지 관찰한다. 4 관찰한 암석의 특징을 정리한다 |
| 결과 표 | 번호 × 암석의 특징(색, 줄무늬의 유무, 암석을 이루는 입자의 크기) + 염산 반응. 예시: 밝다 / 줄무늬가 보이지 않는다 / 눈에 보일 정도로 크다 / 일어나지 않는다 |
| 분류표 (과정 5) | 암석에 어둡고 밝은 줄무늬가 번갈아 나타나는가? → 예: (편마암) / 아니요 → 입자의 크기를 눈으로 구별할 수 있는가? → 예: 입자 모양이 모서리가 깎인 것처럼 대체로 둥근가? → 예: 입자의 크기가 매우 다양한가? (예: 역암 / 아니요: 사암) · 아니요: (화강암) / 입자를 눈으로 구별 못 함 → 묽은 염산을 떨어뜨리면 거품이 발생하는가? → 예: (대리암) / 아니요: (현무암) |
| 정리하기 | 1 ①~⑥의 암석을 화성암, 퇴적암, 변성암으로 구분해 보자. 2 관찰 결과를 토대로 모둠원들과 토의하여 각 암석의 이름을 위의 표에 써 보자 |
| 스스로 평가 | 1 마그마가 굳어 만들어진 암석을 (화성암)이라고 하며, 이 중 지하 깊은 곳에서 생긴 것은 입자 크기가 (크고 / 작고), 지표 부근에서 생긴 것은 입자 크기가 (크다 / 작다). 2 화석이 주로 퇴적암에서 발견되는 까닭을 설명해 보자 |
| 친구에게 설명 | "화성암, 퇴적암, 변성암의 생성 과정은 어떻게 다를까?" |

## 4. 사용 금지 (넘기 쉬운 것)
- 마그마의 온도·성분(SiO₂ %), "염기성·산성·중성암", 섬록암·안산암 등 교과서 밖 화성암, 반심성암, 반상 조직, 유리질 조직
- 현무암 구멍(기공)의 이름과 생성 원리 (모형에는 사진처럼 보이게 그리되, 글로 설명하지 않음)
- 퇴적암의 "쇄설성·화학적·유기적" 분류 이름, 셰일, 응회암, 암염, 처트 등 교과서 밖 퇴적암, 입자 크기 기준 수치(2mm, 1/16mm)
- 다짐 작용·교결 작용 같은 한자 용어 (교과서는 "다져진다", "물에 녹아 있는 여러 물질이 퇴적물을 붙여"로 씀)
- 변성암의 "접촉 변성·광역 변성", 점판암·천매암, 변성 온도·압력 수치, 혼펠스, 변성 정도의 이름(저변성·고변성)
- 암석의 순환 (교과서 이 쪽에 없음. 다음 차시일 수 있음)
- 지역(두륜산, 명지 계곡, 봉양리, 상족암)의 교과서 밖 정보(나이, 높이 등)
- 공룡 이름, 화석이 만들어지는 자세한 과정(광물 치환 등)

## 5. 정성적으로만 다루는 것 / 모형 표시
- 3D 암석은 사진이 아니라 실제 표본의 생김새(색, 알갱이 크기, 줄무늬, 둥근 자갈)를 참고해 만든 모형이다. 화면에 "모형"이라고 밝힌다.
- 마그마가 식는 장면: "빠르게 식으면 입자가 작고, 천천히 식으면 입자가 크다"를 결정이 생기고 자라는 애니메이션으로 보여 준다. 식는 시간·온도 숫자는 쓰지 않는다.
- 퇴적암 생성 장면: 교과서 그림 Ⅱ-6의 세 단계(쌓인다 → 다져진다 → 붙어서 단단해진다)만 쓴다. 걸리는 시간은 "오랜 시간"으로만 쓴다.
- 변성 작용 장면: 압력 방향과 수직으로 입자가 늘어서는 모습(엽리), 입자가 커지거나 치밀해지는 모습을 정성적으로 보여 준다. 열·압력의 크기 숫자는 쓰지 않는다.

## 6. 미확인 (선생님 확인 필요)
- **탐구 사진의 표본 번호** → 교과서 68쪽 사진을 보고 ① 현무암, ② 대리암, ③ 역암, ④ 편마암, ⑤ 화강암, ⑥ 사암으로 정함 (교과서 정답 미확인. 화면에서는 번호를 고정함)
- **사암의 분류표 답** → 분류표대로 '입자를 눈으로 구별할 수 있다 → 둥글다 → 크기가 매우 다양하지 않다'로 둠
- **대리암의 분류표 답** → 분류표대로 '입자를 눈으로 구별하기 어렵다 → 염산에 거품이 생긴다'로 둠. 실제 대리암은 결정이 보이는 표본도 있음
- **석회암·대리암의 염산 반응** → 교과서 분류표에 대리암 '거품 발생'이 있음. 석회암도 거품이 생기는 것으로 정리 화면에 쓰지 않고, 탐구 표본(대리암)에서만 보여 줌
- **결과 표의 '색' 칸 정답** → 현무암·편마암(어두운 줄과 밝은 줄)·역암은 학생마다 다르게 적을 수 있어 고르기 칩으로만 두고 채점하지 않음 (입자 크기·줄무늬·염산 반응만 채점)
- 퇴적암 생성 장면의 "물에 녹아 있는 여러 물질"을 알갱이 사이를 채우는 연한 색으로 표현함
- 이암 → 편암 → 편마암 순서를 "변성 작용이 더 많이 일어나면"으로 설명함 (교과서: '변성 작용이 일어난 정도에 따라')
