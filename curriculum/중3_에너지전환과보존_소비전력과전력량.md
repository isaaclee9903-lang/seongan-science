|---|---|
| 문제 발견하기 | 누가 더 많은 전기 에너지를 사용했을까? 우재와 지우는 머리를 감고 나서 가전제품을 사용하여 머리카락을 말렸다. 우재: 헤어드라이어 **3분** 사용, 지우: 선풍기 **20분** 사용. 두 사람 중 누가 더 많은 전기 에너지를 사용했는지 알기 위해서는 무엇을 알아야 할지 이야기해 보자 |
| 도입 | 여름철에 같은 시간 동안 선풍기를 사용할 때보다 에어컨을 사용할 때 더 많은 전기 에너지를 사용한다. 선풍기 중에서도 크기가 크고 강한 바람을 불게 하는 것일수록 같은 시간 동안 더 많은 전기 에너지를 사용한다 |

| 그림 Ⅵ-13 | 가전제품에 표시된 소비 전력 (헤어드라이어 표시: 정격 전압 220 V, **소비 전력 1200 W**) |
| 과학자 이야기 | 와트(Watt, J., 1736~1819). W는 영국의 기계 기술자 제임스 와트의 이름에서 가져옴, 와트가 개량한 증기 기관은 산업 혁명의 주요한 계기 (웹에는 넣지 않음: 요청하지 않은 일화는 늘리지 않음. 용어 풀이 한 줄만) |
| 소비 전력을 구하는 식 | **소비 전력(W) = 전기 에너지(J) / 시간(초)** |
| 예 | 어떤 전기 기구의 소비 전력이 **20 W**라면, 이 전기 기구를 사용할 때 **1초 동안 20 J**의 전기 에너지를 소비한다. 소비 전력은 전기 기구들이 같은 시간 동안 전기 에너지를 얼마나 사용하는지를 알 수 있는 기준 |
| 그림 Ⅵ-14 | 열화상 사진기를 통해 본 두 전등의 모습. 밝기는 같지만 소비 전력이 다른 두 전등 (가), (나). 열화상 사진 눈금 **17 ℃ ~ 83 ℃**. (가)가 더 뜨겁게(가운데 흰·붉은색) 보임 |
| 열화상 사진기 | (용어 풀이) 물체가 방출하는 열에너지를 눈으로 볼 수 있도록 영상으로 표현하는 사진기 |
| 그림 Ⅵ-15 | 밝기가 같은 두 전등이 방출하는 열 및 빛에너지. (가) 나선형 전구: 빛에너지 **6 J**, 열에너지 **6 J** / (나) 둥근 전구: 빛에너지 **6 J**, 열에너지 **2 J**. 두 전등은 1초 동안 같은 양의 빛에너지를 방출하지만 열에너지의 양이 다르다. 각 전등이 1초 동안 사용하는 전기 에너지의 양, 즉 소비 전력이 다르다 |
| 활동+ 그림 이해하기 | 그림 Ⅵ-15의 (가), (나) 중 소비 전력이 더 큰 전구는 무엇일까? 그렇게 생각한 까닭을 설명해 보자 (답: (가), 1초 동안 12 J > 8 J) |
| 기구 선택 | 같은 성능을 갖더라도 소비 전력이 더 작은 전기 기구를 선택하면 더 적은 전기 에너지를 소비한다 |
| 과학, 생활을 만나다 | 전구에 표시된 밝기와 소비 전력: 소비 전력이 같더라도 전구의 종류에 따라 밝기가 다르다. 전구를 구입할 때는 포장 용기에 적힌 전구의 밝기와 소비 전력을 모두 고려해야 한다 |
| 전력량 | 가정에서는 사용한 전기 에너지의 양인 전력량에 따라 전기 요금을 납부한다. **전력량은 소비 전력을 사용한 시간과 곱한 값**으로, 단위로 **Wh(와트시), kWh(킬로와트시)** 등을 사용한다 |

## 3. 표기
- 용어: 전기 기구, 가전제품, 전기 에너지, 소비 전력, 전력량, 전기 요금 청구서, 에너지 소비 효율 등급(표시제), 에너지절약(표시), 대기전력, 열화상 사진기, 정격 전압
- 에너지: 빛에너지, 열에너지 (붙임) / 전기 에너지, 소리 에너지, 운동 에너지 (띄움)
- 단위: W(와트), J(줄), Wh(와트시), kWh(킬로와트시), 초, 시간(h)
- 식: 소비 전력(W) = 전기 에너지(J) / 시간(초), 전력량(Wh) = 소비 전력(W) × 시간(h)
- 등급은 교과서처럼 '1등급', '5등급'으로 붙여 쓴다(이 교과서 표기. 중2 옛 교과서는 '1 등급')

## 4. 사용 가능 (계산)
- 소비 전력 = 전기 에너지 ÷ 시간(초). 예: 1초 동안 20 J → 20 W, 1초 동안 12 J → 12 W
- 같은 식을 거꾸로 써서 '소비 전력 × 시간(초) = 전기 에너지(J)'로 몇 초 동안 쓴 전기 에너지를 구하기 (교과서 식의 변형, 문제 발견하기의 답을 내는 데 씀 → 미확인 목록에도 적음)
- 전력량(Wh) = 소비 전력(W) × 시간(h). 시간은 정수 시간으로. 예: 20 W × 1 h = 20 Wh
- Wh와 kWh 바꾸기(1 kWh = 1000 Wh): 교과서 본문에 kWh 단위와 청구서(kWh)가 있으므로 사용. 단, 1 kWh = 1000 Wh라는 문장은 사진에 없음 → 미확인
- 청구서 읽기: 당월·전월·전년동월 전력량 비교(124, 145, 111 kWh)

## 5. 쓰지 않는 것 (초과)
- P = VI, P = I²R, P = V²/R 등 전압·전류로 소비 전력을 구하는 식 (정격 전압 220 V는 표시 그림 속 글자로만)
- 1 Wh = 3600 J 같은 Wh ↔ J 환산, kJ·MJ
- 에너지 효율(%) 계산, 등급을 정하는 기준, 등급별 수치
- 전기 요금 계산(원/kWh 단가, 누진제), 대기전력 수치
- 분 단위 시간을 쓰는 전력량(Wh) 계산(0.05시간 같은 소수 계산). 분 단위가 필요한 문제 발견하기는 초(J)로 계산
- 와트 일화 확장, 증기 기관·산업 혁명 이야기
- 발광 다이오드·형광등의 원리(왜 열이 덜 나는지), 루멘 같은 밝기 단위
