# 교육과정 기준 문서 — 중2 과학 Ⅲ. 빛과 파동 › 1. 빛 › 03 다양한 거울과 렌즈에 의해 생기는 상은 어떤 모습일까?

> **출처:** 교과서 사진 4장 (도입 '다양한 거울과 렌즈에 의해 생기는 상은 어떤 모습일까?', 탐구 '거울과 렌즈에 의한 상의 특징 비교하기' 활동하기 1·2, 105쪽 관찰 기록지, 관찰 결과 사진, 본문, 그림 Ⅲ-7, 그림 Ⅲ-8)
> **교육과정:** 2022 개정으로 판단 (01·02 문서와 같은 교과서). 출판사 미확인
> **규칙:** 웹페이지의 모든 글·시뮬레이션·퀴즈는 이 문서와 01·02 문서 범위 안에서만 만든다.
> **선생님 결정 (2026-10-15):** 구성 ① 읽기·퀴즈 ② 거울 관찰대 ③ 렌즈 관찰대 ④ 나란한 빛 보내기 ⑤ 정리(관찰 기록지·정리표). 모두 2D 일러스트. 관찰 물체는 교과서의 공룡·기린 인형 대신 위아래·좌우가 구별되는 **F 모양 블록**으로 한다(선생님 요청).

## 1. 학습 목표 (교과서 '이번 시간에 나는!')
- 다양한 거울과 렌즈에 의해 생기는 상의 특징을 설명할 수 있다.

## 2. 교과서에서 다루는 내용
| 개념 | 교과서 표현 |
|---|---|
| 도입 | 숟가락에 얼굴을 비춰 보면 숟가락 앞면과 뒷면에서 얼굴 모습이 다르게 보인다 |
| 거울의 종류 | 거울 면이 평평한 **평면거울**, 숟가락 앞면처럼 면이 오목하게 들어간 **오목 거울**, 숟가락의 뒷면처럼 면이 볼록하게 나온 **볼록 거울** |
| 렌즈의 종류 | 가운데가 오목한 **오목 렌즈**, 가운데가 볼록한 **볼록 렌즈** |
| 탐구 목표 | 여러 가지 거울과 렌즈에 의해 생기는 상을 관찰하고 특징을 비교할 수 있다 |
| 준비물 | 물체, 스탠드, 볼록 거울, 오목 거울, 볼록 렌즈, 오목 렌즈 |
| 활동하기 1 | ① 볼록 거울 앞에 물체를 놓고 물체를 거울에 가까이 할 때와 거울에서 멀리 할 때 거울에 생긴 상의 모양과 크기를 관찰하여 그린다 ② 볼록 거울 대신 오목 거울을 놓고 반복 ③ 거울과 물체 사이의 거리에 따른 상의 특징을 정리 |
| 활동하기 2 | ① 볼록 렌즈 뒤에 물체를 놓고 물체를 렌즈에 가까이 할 때와 렌즈에서 멀리 할 때 렌즈를 통해 보이는 상의 모양과 크기를 관찰하여 그린다 ② 오목 렌즈로 반복 ③ 렌즈와 물체 사이의 거리에 따른 상의 특징을 정리 |
| 관찰 기록지 (105쪽) | 원 칸: 거울과 가까울 때 / 거울에서 멀 때, 렌즈에서 멀 때 / 렌즈와 가까울 때. "거리에 따른 상의 특징" 칸. 말풍선: 관찰자가 렌즈와 물체를 잇는 일직선상의 멀리 떨어진 고정된 위치에 있을 때 거리에 따른 상을 정확히 비교할 수 있다 |
| 관찰 결과 (가까이 / 멀리 / 더 멀리) | 볼록 거울: 물체보다 작은 크기의 바로 선 상 (세 위치 모두) |
| | 오목 거울: 물체보다 큰 크기의 바로 선 상 / 물체보다 큰 크기의 거꾸로 선 상 / 물체보다 작은 크기의 거꾸로 선 상 |
| | 볼록 렌즈: 물체보다 큰 크기의 바로 선 상 / 물체보다 큰 크기의 거꾸로 선 상 / 물체보다 작은 크기의 거꾸로 선 상 |
| | 오목 렌즈: 물체보다 작은 크기의 바로 선 상 (세 위치 모두) |
| 본문: 거울 | 볼록 거울과 오목 거울에 물체를 비춰 보면 실제 물체와 비교하여 크기나 방향이 다른 상이 생긴다. 이는 거울 면의 모양에 따라서 거울에서 반사된 빛이 이동하는 경로가 다르기 때문이다 |
| 그림 Ⅲ-7 | 나란한 빛을 거울에 비출 때 빛이 반사하는 모습. 나란한 빛을 볼록 거울에 비추면 빛이 거울 면에서 반사된 뒤 **넓게 퍼지고**, 오목 거울에 비추면 거울 면에서 반사된 뒤 **한 점에 모인다** |
| 본문: 볼록 거울 | 항상 물체보다 작고 바로 선 상이 생기며, 물체가 거울에서 멀어질수록 상의 크기는 더 작아진다 |
| 본문: 오목 거울 | 물체가 거울에 가까이 있을 때는 물체보다 크고 바로 선 상. 물체가 거울에서 멀어지면 어느 순간 상이 뒤집혀 보이고, 멀어질수록 거꾸로 선 상이 점점 작아진다 |
| 본문: 렌즈 | 빛은 렌즈를 통과하면서 굴절하는데, 렌즈의 종류에 따라 빛이 굴절되는 경로가 다르다 |
| 그림 Ⅲ-8 | 나란한 빛을 렌즈에 비출 때 빛이 굴절하는 모습. 볼록 렌즈에 비추면 빛이 굴절되어 **한 점에 모이고**, 오목 렌즈에 비추면 굴절되어 **퍼진다** |
| 본문: 볼록 렌즈 | 물체가 렌즈와 가까이 있을 때는 물체보다 크고 바로 선 상. 물체가 렌즈에서 멀어지면 어느 순간 상이 뒤집혀 보이고, 멀어질수록 거꾸로 선 상이 점점 작아진다 |
| 본문: 오목 렌즈 | 항상 물체보다 작고 바로 선 상이 생기며, 렌즈와 물체 사이의 거리가 멀어질수록 상의 크기는 더 작아진다 |
| 평가하기 | 지식·이해: 거울과 렌즈의 종류 및 거리에 따라 상이 달라짐을 이해. 과정·기능: 상의 크기와 모양을 비교하며 관찰. 가치·태도: 호기심과 새로운 발견에 흥미 |
| 실험 동영상 | QR (웹에는 넣지 않음) |

## 3. 앞 차시에서 이어 쓰는 것
- 01: 빛의 반사, 반사 법칙, 빛의 굴절(빛이 서로 다른 물질의 경계에서 꺾여 나아감), 광원, 직진
- 02: 상(거울이나 유리, 렌즈 등으로 물체를 볼 때 생기는 물체의 모습), 평면거울의 상(같은 크기, 같은 거리)

## 4. 표기
- 용어: 평면거울, 오목 거울, 볼록 거울, 오목 렌즈, 볼록 렌즈, 나란한 빛, 바로 선 상, 거꾸로 선 상, 물체보다 큰(작은) 크기의 상, 굴절, 반사
- 띄어쓰기: '오목 거울', '볼록 거울', '오목 렌즈', '볼록 렌즈'(띄움), '평면거울'(붙임), '바로 선 상', '거꾸로 선 상', '나란한 빛'
- 거리는 "가까이 / 멀리 / 더 멀리"로만 나눈다 (cm 수치 없음)

## 5. 사용 금지 (넘기 쉬운 것)
- 초점, 초점 거리, 광축, 실상·허상, 배율, 렌즈(거울) 공식, 곡률 중심
- 상 작도(세 광선 작도). 상이 생기는 원리는 그림 Ⅲ-7·8의 '나란한 빛이 퍼진다/모인다'까지만
- 볼록 렌즈로 스크린에 상 맺기, 사진기·눈의 구조(교과서 이 쪽에 없음)
- 생활 속 쓰임(자동차 측면 거울, 돋보기, 안경 등): 교과서 사진 범위에 없음 → 넣지 않음

## 6. 정성적으로만 다루는 것
- 관찰대 시뮬레이션은 내부에서 실제 광학 관계로 상의 크기·방향을 계산하지만, 화면에는 수식·수치·'초점'을 쓰지 않는다. "개념 이해를 위한 모형"이라고 적는다.
- 오목 거울·볼록 렌즈의 '뒤집히는 순간' 근처에서 상이 크게 흐려지는 모습은 교과서 관찰 사진(멀리 칸)과 같게 흐리게 그린다.
- 나란한 빛이 모이는 '한 점'에는 이름을 붙이지 않는다.

## 7. 미확인
- 'F 모양 물체'는 교과서에 없는 관찰 물체(선생님 요청으로 바꿈)
- 관찰대의 '빛이 닿은 곳 보기'에서 곡면 거울에 반사면과 수직인 선을 그은 것(01 차시 반사 법칙을 곡면에 적용) → 교과서 그림 Ⅲ-7에는 없음
- 시뮬레이션 ③ 정리의 '나란한 빛을 모으는 거울·렌즈는 상이 뒤집히기도 하고, 퍼지게 하는 거울·렌즈는 항상 작고 바로 선 상'은 교과서 관찰 결과를 묶어 말한 것
- 탐구를 실제 수업에서 하는지 → 선생님 결정(2026-10-15)으로 가상 관찰대 탭을 둠
- 볼록 거울·오목 렌즈의 '멀리 할수록 작아진다'를 관찰대에서 얼마나 크게 보여 줄지(실제 관찰 사진은 차이가 작음) → 차이가 보이게 조금 키워 그림
