## 2. 교과서에서 다루는 내용
| 개념 | 교과서 표현 |
|---|---|
| 도입 | 나무 속에서 벌레가 나무를 갉아 먹는 소리가 어떻게 들리지? (청진기로 나무 소리를 듣는 그림) |
| 소리의 발생 | 말을 하고 있을 때 목에 손을 대면 진동을 느낄 수 있다. 북을 치면 북이 떨리면서 소리가 나고, 고무망치로 소리굽쇠를 두드리면 소리굽쇠가 진동하며 소리가 난다 |
| 소리의 전달 | 물체에서 생긴 진동은 주변 공기로 전달되고, 이 진동이 퍼져 나가 우리 귀에 닿으면 소리가 들린다. 소리는 물체의 진동 등에 의해 생기는 파동이며, 공기와 같은 매질을 통해 전달된다 |
| 그림 Ⅲ-15 | 소리를 듣는 과정: 공기 입자(매질)가 진동하여 소리가 전달된다. 소리는 기체뿐 아니라 액체와 고체를 통해서도 전달되므로 물속에서도 소리를 듣고 땅이나 벽을 통해서도 소리를 들을 수 있다. 하지만 우주 공간이나 진공 상태처럼 매질이 없는 곳에서는 소리를 들을 수 없다 |
| 탐구 | 디지털 탐구 도구를 이용하여 소리 분석하기. 목표: 소리 분석 프로그램을 이용하여 여러 가지 소리의 특징을 분석할 수 있다. 준비물: 스마트 기기, 실로폰, 리코더. ① 스마트 기기에 소리 분석 애플리케이션 설치 ② 실로폰의 같은 건반을 약하게 치고 세게 치며 파동을 관찰하여 그린다 ③ 실로폰의 '낮은 도'와 '높은 도'를 같은 세기로 치고 파동의 모습을 관찰하여 그린다 ④ 실로폰과 리코더로 각각 '솔' 음을 내고 파동의 모습을 관찰하여 그린다. 기록 칸: 가로축 '시간'인 모눈 |
| 정리하기 | 1 세기가 다른 소리의 파동을 비교하여 설명해 보자 2 높낮이가 다른 소리의 파동을 비교하여 설명해 보자 3 같은 높이의 음을 다른 악기로 연주할 때 파동을 비교하여 설명해 보자 |
| 평가하기 | 지식·이해: 파동의 모습을 비교하여 다양한 소리의 특징을 알 수 있다 / 과정·기능: 소리 분석 프로그램을 사용해 소리의 파형을 관찰할 수 있다 / 가치·태도: 디지털 탐구 도구를 활용해 과학 문제를 융합적으로 접근할 수 있다 |
| 소리의 세기 | 북을 세게 치면 큰 소리가 나고 약하게 치면 작은 소리가 난다. 두 소리의 파동 모습을 비교하면 작은 소리가 날 때보다 큰 소리가 날 때 진폭이 더 크다. 소리의 세기는 파동의 **진폭**에 따라 달라진다 |
| 그림 Ⅲ-16 | 소리의 세기: 큰 소리일수록 진폭이 크다 (큰 소리 / 작은 소리, 모눈, 가로축 '시간', 진폭 표시) |
| 소리의 높낮이 | 낮은 음과 높은 음을 같은 세기로 낼 때 소리의 파동 모습을 비교해 보면 낮은 소리보다 높은 소리의 진동수가 크다. 소리의 높낮이는 파동의 **진동수**에 따라 달라진다 |
| 그림 Ⅲ-17 | 소리의 높낮이: 높은 소리일수록 진동수가 크다 (높은 소리 / 낮은 소리) |
| 소리의 음색 | 소리의 세기와 높낮이가 같아도 실로폰과 리코더에서 나는 소리는 다르게 들린다. 같은 음의 실로폰과 리코더 소리의 파동 모양, 즉 소리의 **파형**이 다르다. 이처럼 소리의 파형이 달라 서로 구분되는 특징을 **음색**이라고 한다. 목소리로 사람을 구별할 수 있는 것도 사람마다 내는 목소리의 파형이 다르기 때문이다 |
| 그림 Ⅲ-18 | 음색: 악기의 종류에 따라 파형이 다르다 (실로폰 / 리코더) |

- 소리의 속력(340 m/s 등), 매질에 따른 소리 속력 비교
- 배음·기본 진동수·푸리에·스펙트럼, 공명, 정상파, 맥놀이, 도플러 효과
- 종파·횡파(소밀파) 구분, 압력·밀도 그래프
- 현의 길이·굵기·장력과 음 높이의 관계, 관의 길이와 음 높이의 관계(정량)

## 6. 선생님 요청으로 더하는 것 (교과서 본문에 문장으로는 없음)
- 오케스트라 악기 14가지(바이올린·첼로·콘트라베이스·하프 / 플루트·클라리넷·바순 / 트럼펫·호른·트롬본·튜바 / 실로폰·팀파니, 그리고 교과서 비교용 리코더)의 실제 녹음 소리를 연주하고 파형을 보는 가상 소리 분석 프로그램
- 악기별 진동하는 부분 한 줄 설명(줄, 관 속 공기, 막, 나무 막대): 교과서 '물체의 진동으로 소리가 난다'를 악기에 적용한 정성적 설명

## 7. 정성적으로만 다루는 것
- 화면의 파형은 실제 악기 녹음을 그대로 그린 것이다. 세기는 녹음의 크기를 줄이거나 키워 나타낸다(실제 악기를 약하게 치면 음색도 조금 달라지지만 다루지 않음).
- 진동수 표시: '1초에 약 ○○번 진동(○○ Hz)'으로만 쓴다. 음과 진동수의 대응(도 ≈ 262 Hz 등)은 계산해서 보여 줄 뿐 외우게 하지 않는다.

## 8. 미확인
- 탐구 ①(스마트 기기 소리 분석 앱)을 실제 수업에서 하는지 → 가상 소리 분석 프로그램으로 둠(실제 탐구와 함께 쓸 수 있음)
- 진동수 수치(도 약 262 Hz, 솔 약 392 Hz 등)를 화면에 보여 주는 것: 교과서 그림에는 수치가 없음
- 악기 분류 이름(현악기·목관 악기·금관 악기·타악기): 음악 교과 용어. 과학 교과서에는 없음
- 악기별 진동하는 부분(줄·관 속 공기·막·나무 막대) 설명: 교과서에 없음
- 그림 Ⅲ-15의 공기 입자 그림: 입자가 제자리에서 진동하는 모습만 그리고, 진동 방향의 이름(종파 등)은 쓰지 않음
