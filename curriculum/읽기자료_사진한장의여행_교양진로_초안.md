# 범위 문서(초안) — 읽기 자료(교양·진로) › 사진 한 장의 여행: 빛과 0과 1

> **성격:** 중학교 정규 교육과정 밖의 **읽기 자료**(교양·진로). 「여기도, 저기도 반도체」, 「전기를 담는 작은 그릇, MLCC」의 후속. 교과서 원문이 없어 Claude가 중2 「전기와 자기」 기준 문서와 앞의 두 범위 문서에 맞춰 보수적으로 만든 **초안**이다. 선생님 확인 후 '초안'을 뗀다.
> **선생님 결정(2026-10-04, 오토):** ① 0과 1(스위치로 정보 만들기)과 ② 빛과 반도체(LED·태양 전지·이미지 센서)를 한 자료로 묶는다. 조사 후 중학생 눈높이로 서술. 만들고 게시까지.
> **근거 조사:** 저장소 밖 조사 보고서 「사진 한 장의 여행 반도체 조사」(2026-10-04, 조사 노트 3개). 일부 원문은 검색 요약으로만 확인했으므로 7절은 원문 확인이 필요하다.

## 1. 앞 차시에서 가져오는 개념 (그대로 사용)
- 스위치를 닫으면 전류가 흐르고 열면 멈춘다. 직렬·병렬 연결 (중2 저항의 연결)
- 전기 에너지가 빛에너지·열에너지 등으로 전환된다 (중2 전기 에너지)
- 반도체로 만든 아주 작은 스위치, 켜짐=1·꺼짐=0 약속, 메모리=창고·시스템 반도체=두뇌, D램·낸드 플래시, AP (반도체 읽기 자료)
- MLCC는 칩 곁의 댐 (MLCC 읽기 자료)

## 2. 사용 가능
- **비트·바이트:** 0 또는 1 하나 = 비트, 8비트 = 1바이트, 1바이트 = 256가지(0~255) (삼성전자 반도체 용어사전)
- **자리값:** 1·2·4·8·16·32·64·128, 켜진 칸의 수를 더한다 (CS Unplugged 점 카드 방식)
- **글자 번호:** 'A' = 65 = 01000001 (Computer Science Field Guide). 한글 한 글자는 요즘 쓰는 방식(UTF-8)에서 3바이트(예전 방식은 2바이트)
- **색:** 픽셀마다 빨강·초록·파랑 밝기를 0~255로, 픽셀 하나 24비트(3바이트), 16,777,216가지 색 (CSFG)
- **사진 크기(교사 계산):** 2억 화소 × 3바이트 ≈ 600 MB ≈ 48억 비트(압축 전). 압축하면 보통 수 MB~수십 MB, 기종·장면마다 다름
- **그리고/또는 맛보기:** 스위치 2개 직렬 = 둘 다 닫혀야 켜짐(그리고), 병렬 = 하나만 닫혀도 켜짐(또는). 전류 계산·합성 저항·기호 없음
- **LED:** 전기 → 빛. 백열전구는 필라멘트를 뜨겁게 달궈 빛을 내서 많은 전기가 열로 사라지고, LED는 같은 밝기에서 전기를 훨씬 덜 쓰고 덜 뜨겁다 (한국에너지공단 비교표를 정성적으로만)
- **태양 전지:** 빛 → 전기. 컴퓨터 칩과 같은 재료인 실리콘으로 만든다 (SK하이닉스 뉴스룸 2016, 전기신문)
- **이미지 센서:** 렌즈로 들어온 빛을 전기 신호로 바꾸고, 그 양을 숫자로 바꿔 AP로 보낸다. "디지털 기기의 눈"(삼성), "망막 역할"(SK하이닉스). 마이크로 렌즈, 컬러 필터(빨강·초록·파랑, 초록이 2배), 칸마다 한 색만 재고 나머지 색은 계산으로 채움
- **화소:** 메가픽셀 = 100만 화소, 2억 화소 센서(삼성 ISOCELL HP3, 2022 발표) 픽셀은 머리카락 굵기보다 훨씬 작음(비교만). 어두우면 이웃한 4개(16개)를 묶어 큰 픽셀처럼 → 5,000만(1,250만) 화소
- **사진의 여행(역할 이름):** 이미지 센서(눈) → AP(두뇌) 안의 ISP(색·밝기를 다듬고 여러 장을 합침) → D램(임시 저장, 전원이 꺼지면 사라짐) → 낸드 플래시(사진·동영상을 기기 안에 저장, 전원이 꺼져도 남음) → 화면 (DDI는 "신호등", OLED 픽셀은 스스로 빛을 냄)
- **여러 장 합치기:** 셔터 한 번에 여러 장을 연달아 찍어 합친다(구글 Night Sight: 손에 들면 최대 15장, 2018). 장수는 기종·모드마다 다름

## 3. 사용 금지
- 띠틈(밴드갭)·에너지띠, p-n 접합, N형/P형, 전자·양공(정공), 도핑, 광전 효과, 트랜지스터·게이트 동작 원리, 논리 게이트 회로 구조, 불 대수 기호
- 아날로그-디지털 변환기라는 용어와 원리("숫자로 바꾸기"로만), D램·낸드 셀 구조
- 전력·와트(W)·lm/W 수치, "전력 관리"(→ "전기를 고르게 나눠 준다"), 전위·전위차
- 압축 방식(JPEG·HEIF) 원리와 계산, 1,000/1,024 단위 계산
- 회사별 점유율 순위·매출, 사람 눈과 화소 수 비교("사람 눈은 몇억 화소")
- 오래된 제품 수치(LPDDR4X 8GB, eUFS 512GB 등)
- 수업에서 하지 않는 실험(LED·태양 전지 실습 등) 안내 → 가상 시뮬레이션만

## 4. 앞 차시와 연결
- 저항의 연결: 직렬 스위치 = 그리고, 병렬 스위치 = 또는
- 전기 에너지: LED·백열전구의 에너지 전환(전기 에너지 → 빛에너지·열에너지), 태양 전지(빛에너지 → 전기 에너지), OLED 화면도 전기 → 빛
- 반도체: 켜짐 1·꺼짐 0의 작은 스위치, 메모리(창고)·시스템(두뇌), 낸드·D램
- MLCC: AP 곁의 댐(사진 처리로 칩이 바빠질 때)

## 5. 웹 자료에서 정한 표현
- 3D 모형의 픽셀 수(실제 수천만~2억 → 화면 64~96칸), 크기, 빛 알갱이 수, 빠르기, 막대 길이는 "개념 이해를 위한 모형"으로 표시. 막대에는 눈금 숫자를 쓰지 않는다
- 비유 출처 구분: 공식 비유(눈 — 삼성, 망막 — SK하이닉스, 두뇌 — 삼성, 신호등 — 삼성디스플레이, 댐 — 삼성전기) / 선생님 비유(D램 = 책상, 낸드 = 책장 — 반도체 읽기 자료와 같은 비유, 사진 한 장 = 스위치 48억 개)
- 생활 예(그리고: 전자레인지는 문이 닫히고 시작 버튼을 눌러야 돈다 / 또는: 자동차 실내등은 문 하나만 열려도 켜진다)는 이해를 돕는 예로 표시
