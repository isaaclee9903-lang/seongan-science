## 1. 학습 목표 (교과서 '이번 시간에 나는!')
- 광물의 특성을 관찰하고 비교할 수 있다.
- 암석을 이루는 조암 광물을 설명할 수 있다.

## 2. 교과서에서 다루는 내용
| 개념 | 교과서 표현 |
|---|---|
| 도입 | 광명 동굴은 자연이 만든 동굴이 아니라 사람들이 금을 캐기 위해 땅을 파 만든 광산이다. 광산에서 발견되는 금이나 은, 철광석 등과 같이 **자연적으로 만들어진 고체 물질**을 **광물**이라고 한다. 지구에는 보석으로 사용하는 다이아몬드부터 연필심에 사용하는 흑연까지 매우 다양한 광물이 있다 |
| 탐구 | 광물의 특성 관찰하기. 목표: 광물을 관찰하고 주요 특성에 따라 광물을 구별할 수 있다 |
| 준비물 | 광물 표본(석영, 방해석, 황철석, 황동석, 자철석, 흑운모), 조흔판(흰색과 검은색), 묽은 염산, 스포이트, 페트리 접시, 클립, 실험용 장갑, 실험복 |
| 안전 | 묽은 염산을 사용할 때는 묽은 염산이 피부 등에 닿지 않도록 주의한다 |
| 과정 1 | 준비한 광물의 색을 관찰한다. (말풍선) 광물은 부분적으로 조금씩 색이 달라. 전체적으로 어떤 계열의 색인지 관찰하자 / 흰색 조흔판에 긁었을 때 색이 잘 보이지 않으면 검은색 조흔판에 긁어 보자 |
| 과정 2 | 광물을 흰색과 검은색 조흔판에 긁어 조흔색을 관찰한다. → 광물의 색과 조흔색은 서로 비슷하게 나타나는가, 다르게 나타나는가? |
| 과정 3 | 클립에 각 광물을 가져다 대어 클립이 광물에 붙는지 확인한다 |
| 과정 4 | 각 광물에 묽은 염산을 조금씩 떨어뜨려 반응이 나타나는지 확인한다. → 묽은 염산과 반응하는 광물에서는 어떤 변화가 나타나는가? |
| 과정 5 | 석영과 방해석을 서로 긁어 어떤 광물이 긁히는지 확인한다. → 두 광물 중 더 단단한 것은 무엇인가? |
| 과정 6 | 결과 표: 구분(석영, 방해석, 황철석, 황동석, 자철석, 흑운모) × 색, 조흔색, 클립 붙음, 염산 반응, 긁힘. 긁힘은 석영·방해석만(나머지 칸은 X 표시). (광물에 클립이 붙으면 ○, 붙지 않으면 ×) |
| 용어 | ***조흔판** 초벌구이 도자기 판, ***조흔색** 광물 가루의 색으로, 광물을 조흔판에 긁어 확인할 수 있다 |
| 정리하기 | 1 석영을 조흔판에 긁었을 때 조흔색이 나타나지 않은 까닭 2 석영과 방해석을 구별할 수 있는 방법 3 관찰한 광물 중 두 개를 선택하여 특성 비교 4 각 광물의 특성을 바탕으로 광물을 구별하는 방법 토의 |
| 평가하기 | 지식·이해: 광물의 주요 특성을 설명할 수 있다 / 과정·기능: 광물의 주요 특성을 관찰하고 기록할 수 있다 / 가치·태도: 광물 관찰로 자연의 아름다움을 느끼고 자연을 이해하려는 태도를 기를 수 있다 |
| 광물의 특성 | 광물은 종류에 따라 **고유한 특성**을 가진다. 광물의 특성에는 **색, 조흔색, 굳기, 자성, 염산 반응** 등이 있으며, 이 특성을 이용하여 광물을 서로 구별할 수 있다 |
| 광물의 색 | 겉으로 보이는 광물의 색은 광물을 쉽게 구별할 수 있는 특성이다. **석영과 방해석은 일반적으로 무색투명**하고, **장석은 보통 밝은색**을 띤다. 반면 **감람석, 휘석, 각섬석, 자철석, 흑운모는 대부분 어두운색**을 띤다. (그림: 석영·장석 '밝다', 감람석·휘석·각섬석 '어둡다') |
| 조흔색 | 조흔색은 광물 가루의 색으로, 조흔판에 광물을 긁어 관찰할 수 있다. **금, 황동석, 황철석**은 겉보기에는 모두 노란색이지만 조흔판에 긁으면 각각 **노란색, 녹흑색, 검은색**의 조흔색이 나타난다. 또 **투명한 방해석과 검은색 흑운모는 모두 조흔색이 흰색**으로, 겉으로 보이는 색은 다르지만 조흔색은 같다. 이처럼 색과 조흔색은 다를 수 있으며, 색이 비슷한 광물을 조흔색으로 구별하기도 한다. (사진: 흰 조흔판 위 황동석·황철석, 검은 조흔판 위 방해석·흑운모) |
| 굳기 | 굳기는 광물의 **단단한 정도**를 말한다. 석영과 방해석을 서로 긁었을 때 **방해석에만 흠집**이 생기는 것처럼, 굳기가 다른 두 광물을 서로 긁으면 **단단한 광물에 무른 광물이 긁힌다**. 이를 이용하여 서로 다른 두 광물의 굳기를 비교할 수 있다. (사진: 석영과 방해석의 굳기 비교) |
| 자성 | 자성은 자석처럼 철을 끌어당기는 성질을 말한다. 대표적으로 **자철석은 자성**을 가지고 있어 철로 된 클립이나 핀을 끌어당긴다. (사진: 자철석의 자성) |
| 염산 반응 | 일부 광물은 염산에 반응한다. **방해석에 묽은 염산을 떨어뜨리면 이산화 탄소가 발생해 기포가 생긴다.** 이를 이용하여 다른 광물과 방해석을 구별할 수 있다. (사진: 방해석의 염산 반응) |
| 조암 광물 | 지구에는 **수천 종의 광물**이 있으며, 광물이 모여 암석을 이룬다. 예를 들어 **화강암은 장석과 석영, 흑운모 등**으로 이루어져 있다. 특히 **장석, 석영, 휘석, 각섬석, 흑운모, 감람석** 등은 지각을 이루는 암석에서 흔하게 볼 수 있는데, 이렇게 암석을 이루는 주된 광물을 **조암 광물**이라고 한다. (그림 Ⅱ-4 화강암을 이루는 광물: 장석, 석영, 흑운모) |
| 스스로 평가 | 1 두 광물을 서로 긁어 보면 광물의 단단한 정도인 (굳기)을/를 비교할 수 있다. 석영과 방해석을 서로 긁으면 (방해석)이 긁혀 흠집이 난다. 2 광산에서 나오는 노란색 광물이 금, 황철석, 황동석 중 무엇인지 쉽게 알 수 있는 방법을 설명해 보자 |
| 친구에게 설명 | "광물을 구분할 때 광물의 특성을 어떻게 이용할까?" |

## 4. 사용 금지 (넘기 쉬운 것)
- **모스 굳기계**, 굳기 숫자(석영 7, 방해석 3 등), 손톱·유리·동전과 비교하는 굳기 판정
- 광물의 화학식(SiO₂, CaCO₃, FeS₂ 등), 결정계 이름(육방정계 등), 쪼개짐·깨짐, 광택(금속·유리 광택), 비중, 복굴절(방해석 글자 두 겹 보이기), 형광 등 교과서에 없는 특성
- 염산 반응의 화학 반응식, "탄산염 광물" 같은 분류 이름
- 자철석 외의 광물이 자성을 띠는지에 관한 이야기(자류철석 등), 자석에 붙는 정도의 수치
- 장석의 종류(정장석·사장석), 운모의 종류(백운모 등), 감람석·휘석·각섬석의 조흔색
- 광물·암석의 생성 과정(마그마가 식어서 등), 화성암·퇴적암·변성암 분류 (다음 차시일 수 있음)
- 광명 동굴의 위치·역사 등 교과서 밖 정보

## 5. 정성적으로만 다루는 것 / 모형 표시
- 3D 광물은 사진이 아니라 실제 표본의 생김새(결정 모양, 빛깔, 투명도, 표면 무늬)를 참고해 만든 모형이다. 화면에 "모형"이라고 밝힌다.
- 탐구 장면은 가상 실험이다. 실제 실험의 결과와 같게(교과서 결과) 보여 주되, 수치를 쓰지 않는다.
- 염산 반응 기포는 "이산화 탄소가 발생해 기포가 생긴다"까지만 쓴다.
- 굳기 비교는 "석영이 방해석보다 단단하다(방해석에 흠집)"만 다룬다. 다른 광물끼리의 굳기 순서는 다루지 않는다.

## 6. 미확인 (선생님 확인 필요)
- **자철석의 조흔색 '검은색'** → 교과서 본문에 없음. 일반적인 값으로 표에 씀
- **석영의 조흔색** → 교과서 정리하기 1이 "조흔색이 나타나지 않은 까닭"을 묻는다. 웹에서는 결과를 '나타나지 않음'으로 기록하고, 까닭은 "석영이 조흔판보다 단단해서 긁어도 가루가 생기지 않는다"로 설명함 (교과서 굳기 개념에서 이끌어 낸 설명. 교과서 정답 미확인)
- **자철석·황철석·황동석·흑운모의 색 표기** → 자철석·흑운모 '검은색'(교과서 '검은색 흑운모', 자철석 '어두운색'), 황철석·황동석 '노란색'(교과서 '겉보기에는 모두 노란색')으로 씀
- 탐구 결과 표의 '색' 칸 정답 표기(무색투명/노란색/검은색) → 학생 기록 방식은 선생님마다 다를 수 있어 고르기 칩으로만 둠
- 탐구 결과의 염산 반응은 방해석만 '반응함'으로 둠 (교과서 본문 기준)
- 다음 쪽 내용(암석의 분류 등) → 사진에 없어 확인하지 못함
