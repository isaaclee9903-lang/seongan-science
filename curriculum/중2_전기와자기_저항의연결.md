## 2. 교과서에서 다루는 내용

| 과정 2 | 스위치를 모두 닫고 각 전구의 밝기를 비교해 회로 카드 ②, ③에 표시한다 (카드의 칸 3개를 색칠해 밝기 표시, 카드 ①은 3칸) |
| 과정 3 | ②, ③처럼 연결한 회로에서 스위치를 하나만 열고 전구의 밝기를 비교해 회로 카드 ④, ⑤에 표시한다 |
| 과정 4 | 전구의 연결 방법에 따른 특징을 비교해 이야기한다 |
| 저항의 직렬연결 | 전구 두 개를 직렬연결하면 **저항이 길어지는 것과 같아서** 회로 전체의 저항은 커지고, 회로 전체에 흐르는 전류의 세기는 작아진다. 각 전구에는 전구를 한 개만 연결할 때보다 **낮은 전압**이 걸려 각 전구의 밝기는 전구를 한 개만 연결할 때보다 **어둡다**. 전류가 **하나의 경로**로 흐르기 때문에 직렬연결된 두 전구 중 한 개의 연결이 끊어지면 **모든 전구는 꺼진다** |
| 저항의 병렬연결 | 전구 두 개를 병렬연결하면 **저항이 굵어지는 것과 같아서** 회로 전체의 저항은 작아지고, 회로 전체에 흐르는 전류의 세기는 커진다. 각 전구에는 전구를 한 개만 연결할 때와 **같은 크기의 전압**이 걸려 각 전구의 밝기는 전구를 한 개만 연결할 때와 **같다**. 전류가 **두 개의 경로**로 흐르기 때문에 병렬연결된 두 전구 중 한 개의 연결이 끊어져도 **다른 쪽 전구는 꺼지지 않는다** |
| 그림 | 직렬: 전구 2개를 한 줄로 연결한 회로 + "저항이 길어짐" 그림(짧은 막대 2개 → 긴 막대 1개). 병렬: 전구 2개를 나란히 연결한 회로 + "저항이 굵어짐" 그림(막대 2개 → 굵은 막대 1개). 가운데: 전구 1개 회로(기준). 모두 건전지 2개 |
| 스스로 평가 1 | 저항을 직렬연결하면 전체 저항은 (작아 / 커)지고, 병렬연결하면 전체 저항은 (작아 / 커)진다 |
| 스스로 평가 2 | 교실 천장 등은 하나의 스위치로 켜고 끄지만, 등 하나가 고장 나도 다른 등은 꺼지지 않는다. 등은 어떻게 연결되어 있을지 설명해 보자 |
| 친구에게 설명 | "가정에서 사용하는 전기 기구가 모두 직렬로 연결되어 있으면 어떻게 될까?" |

## 3. 앞 차시(옴의 법칙)와 연결하는 데 쓸 수 있는 것
- 물질의 종류가 같을 때 **길이가 짧고 굵을수록 저항이 작다** (p.243~246) → 이번 차시의 "길어지는 것과 같다 / 굵어지는 것과 같다"의 근거
- 옴의 법칙: 전압이 같을 때 저항이 클수록 전류가 작다 (**I = V/R**) → "전체 저항이 커지면 전체 전류가 작아진다"의 근거
- 옴의 법칙의 V는 **그 저항(전구)에 걸리는 전압** → "각 전구에 걸리는 전압"을 말할 때의 근거
- 수로 모형: 펌프=전지, 물레방아=전구(저항), 수면의 높이 차=전압. 앞 차시 시뮬레이션의 "저항 2개" 모드에서 높이가 두 계단으로 나뉘어 내려오는 것을 이미 봄

## 4. 표기
- 용어: **직렬연결, 병렬연결** (붙여 씀), 저항의 직렬연결, 저항의 병렬연결, 회로 전체의 저항, 회로 전체에 흐르는 전류의 세기, 전구에 걸리는 전압, 경로, 회로 카드, 전구 끼우개, 전지 끼우개
- 기호·단위: 앞 차시와 같음 (I, V, R / A, mA, V, Ω)
- 저항이 "길어진다", "굵어진다" (교과서 표현). "단면적"은 교과서 사진에 없는 낱말이라 괄호 보충으로만 쓴다 (아래 6번 참고)

## 5. 사용 금지 (넘기 쉬운 것)
- 합성 저항 공식(R = R₁ + R₂, 1/R = 1/R₁ + 1/R₂), 합성 저항을 숫자로 구하는 계산
- 직렬·병렬 회로에서 전압·전류를 숫자로 나누는 계산 (예: "각 전구에 1.5 V", "전류가 2배") — 교과서는 크다/작다, 낮다/같다로만 말한다
- 키르히호프 법칙, 전압 강하, 전위·전위차, 전력·소비 전력·전력량, 줄열, 비저항
- 전구 밝기와 전력의 관계, 필라멘트 온도
- 혼합 연결(직렬과 병렬을 섞은 회로), 전지의 직렬·병렬연결

## 6. 교사 요청으로 넣되 정성적으로만 다루는 것
- **"직렬은 저항의 길이가 길어지는 것, 병렬은 단면적이 넓어지는 것과 비슷하다"** (이삭 선생님 요청, 2026-10-02): 교과서 표현 "길어지는 것과 같아서 / 굵어지는 것과 같아서"를 기본으로 쓰고, "굵어진다(단면적이 넓어진다)"처럼 괄호로 보충한다. 숫자 없이 막대 모형과 자유전자 애니메이션으로만 보여 준다.
- **옴의 법칙과 연계** (이삭 선생님 요청): "전체 저항이 커진다 → 전압이 같으면 전류가 작아진다(I = V/R)"처럼 비례·반비례 관계를 말로만 잇는다. 숫자 계산은 하지 않는다.
- **수로 모형 확장**: 직렬은 물레방아 2개를 차례로 지나며 높이를 나눠 내려오고, 병렬은 물길이 두 갈래로 나뉘어 각 물레방아가 높이를 모두 내려온다. 높이 눈금 숫자는 쓰지 않는다.

## 7. 미확인 (선생님 확인 필요)
- 교과서의 직렬연결·병렬연결 **정의 문장** (p.248~249 사진에는 없음). 웹페이지에서는 "한 줄로 이어 연결 / 여러 갈래로 나누어 나란히 연결"로 썼다
- **해 보기 실험을 실제 수업에서 하는지** (하지 않으면 가상 실험 탭을 빼거나 "교과서 해 보기"라는 표현을 고친다)
- 회로 카드(부록 334쪽)의 실제 모양과 카드 ④, ⑤의 스위치 위치. 웹페이지에서는 전구마다 스위치 1개씩으로 그렸다
- 병렬연결에서 "전류가 갈라졌다가 다시 합쳐진다"는 표현 (교과서 사진에는 "두 개의 경로로 흐른다"까지만 있음)
- 가정의 전기 기구·멀티탭 콘센트가 병렬연결이라고 단정해 써도 되는지 (교과서는 질문으로만 제시)
