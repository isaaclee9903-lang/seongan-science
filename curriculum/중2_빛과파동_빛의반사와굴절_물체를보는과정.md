# 교육과정 기준 문서 — 중2 과학 Ⅲ. 빛과 파동 › 1. 빛 › 01 물체에 닿은 빛은 어떻게 이동할까?

> **출처:** 교과서 사진 4장 (98~101쪽: 도입 '물체에 닿은 빛은 어떻게 이동할까?', 탐구 '빛의 반사와 굴절 알아보기' 활동하기 1·2, '# 빛의 반사' + 그림 Ⅲ-1, '# 빛의 굴절' + 그림 Ⅲ-2, '# 물체를 보는 과정', 해 보기 '물체를 보는 과정 이해하기', 그림 Ⅲ-3·Ⅲ-4, 스스로 평가)
> **교육과정:** 2022 개정으로 판단 (Ⅱ·Ⅶ·Ⅷ 단원과 같은 교과서). 출판사 미확인
> **규칙:** 웹페이지의 모든 글·시뮬레이션·퀴즈는 이 문서 범위 안에서만 만든다.
> **선생님 확인 (2026-10-15):** 활동하기 1(반사), 활동하기 2(굴절), 해 보기(원통으로 물체 보기) 모두 수업에서 함. 시뮬레이션은 2D 일러스트. 물체를 보는 과정의 오개념(눈에서 빛이 나온다, 광원이 아닌 물체에서 빛이 직접 나와 눈에 도달한다)을 화살표 그리기로 다룸.

## 1. 학습 목표 (교과서 '이번 시간에 나는!')
- 빛의 반사와 굴절 현상을 말할 수 있다.
- 물체를 보는 과정을 빛의 경로를 이용하여 표현할 수 있다.

## 2. 교과서에서 다루는 내용
| 개념 | 교과서 표현 |
|---|---|
| 도입 | 영화 촬영장에서는 반사판을 사용한다. 반사판은 빛을 반사해 원하는 방향으로 보내어 대상을 더 밝고 선명하게 보이도록 한다. 빛은 직진하다가 다른 물체를 만나면 경계면에서 반사하기도 하고, 굴절하기도 한다 |
| 활동하기 1 빛의 반사 | 준비물: 슬릿 레이저, 반원 각도기, 평면거울, 레이저 보안경. ① 주위를 어둡게 한 뒤 반원 각도기를 놓고 평면거울을 수직으로 세운다 ② 각도기에 표시된 곳에 슬릿 레이저를 놓고 각도기 중심을 향해 비춘 뒤 빛의 경로를 종이에 표시 ③ 비추는 각도를 바꾸며 반복. 표: 입사각 30°, 45°, 60° → 반사각. "입사각과 반사각은 어떤 관계가 있는가?" |
| 입사각과 반사각 (날개) | 거울면에 수직인 선과 빛이 이루는 각도를 각각 입사각(거울에 비춘 빛), 반사각(거울에서 반사된 빛)이라고 한다 |
| 안전 | 레이저 빛이 눈에 직접 닿지 않도록 한다 |
| 활동하기 2 빛의 굴절 | 준비물: 원형 각도기, 각도가 표시된 반원 통, 물, 우유. ① 주위를 어둡게 한 뒤 원형 각도기 위에 반원 통을 놓고, 물을 채운 뒤 우유를 2~3방울 떨어뜨린다 ② 레이저 빛을 반원 통의 중심을 향해 비스듬히 비추고, 빛이 물을 통과할 때 빛의 경로를 종이에 표시 ③ 비추는 방향을 달리하며 반복. "빛이 공기에서 물을 지날 때 진행 방향은 어떻게 바뀌는가?" |
| 빛의 반사 | 직진하던 레이저 빛이 거울 면에 닿으면 진행 방향을 바꾼다. 일정한 방향으로 나아가던 빛이 다른 물체에 부딪쳐 진행 방향을 바꾸는 현상을 **빛의 반사**라고 한다 |
| 빛의 반사 법칙 | 그림 Ⅲ-1처럼 빛이 반사할 때 빛이 물체로 향하는 입사각과 반사되어 나오는 반사각의 크기는 항상 같다. 이를 **빛의 반사 법칙**이라고 한다 |
| 그림 Ⅲ-1 | 반사면(거울), 반사면과 수직인 선, 입사 광선, 반사 광선, 입사각, 반사각 |
| 빛의 굴절 | 그림 Ⅲ-2처럼 공기에서 물로 빛을 비추면 빛이 공기와 물의 경계면에서 꺾인다. 빛이 한 물질에서 다른 물질로 비스듬히 진행할 때 두 물질의 경계면에서 진행 방향이 꺾이는 현상을 **빛의 굴절**이라고 한다. 두 물질의 경계면에 수직인 선과 입사 광선이 이루는 각을 **입사각**, 굴절 광선이 이루는 각을 **굴절각**이라고 한다 |
| 그림 Ⅲ-2 | 공기, 물, 경계면과 수직인 선, 입사 광선, 입사각, 굴절각, 굴절 광선 (레이저를 물이 든 수조에 비춤) |
| 물체를 보는 과정 (도입) | 영화가 시작되기 전 모든 조명이 꺼져 캄캄할 때는 주변이 보이지 않지만, 영화가 시작되면 스크린이나 주변 사람의 모습이 보인다 |
| 해 보기 | 준비물: 검은색 종이 2장, 작은 물체, 야광 물체. ① 책상 위에 검은색 종이를 깔고 작은 물체를 놓는다 ② 다른 검은색 종이를 원통 모양으로 말아 물체를 완전히 덮은 뒤 통 입구에 눈을 대고 관찰 ③ 통을 천천히 들어 올리며 관찰 ④ 야광 물체로 ②, ③ 반복 ⑤ 물체를 볼 때 빛의 경로를 화살표로 그려 보기 ⑥ 물체를 볼 수 있거나 없었던 까닭을 빛의 경로로 설명 (문제 인식 / 과학적 근거에 기반한 주장). 안전: 눈이 종이에 닿지 않도록 조심 |
| 해 보기 그림 | 2×2 칸: 작은 물체(통을 덮음 / 통을 듦), 야광 물체(통을 덮음 / 통을 듦). 위에 눈 그림 |
| 물체를 보는 과정 | 빛이 없는 어둠 속에서 우리는 주변의 물체를 볼 수 없다. 물체를 보기 위해서는 빛이 필요하고, 그 빛이 우리 눈에 들어와야 한다 |
| 광원 | 태양이나 전등, 촛불과 같이 스스로 빛을 내는 물체를 **광원**이라고 한다. 광원에서 나온 빛은 사방으로 퍼져 나가고, 그림 Ⅲ-3과 같이 그 빛이 우리 눈에 들어오면 볼 수 있다 |
| 광원이 아닌 물체 | 광원에서 나온 빛의 일부가 물체에 반사되어 눈에 들어오면 우리는 그 물체를 볼 수 있다. 그림 Ⅲ-4와 같이 햇빛이 공에 반사되어 눈에 들어오므로 우리가 공을 볼 수 있다 |
| 그림 Ⅲ-3 | 전등을 볼 때 빛의 경로 (전등 → 눈) |
| 그림 Ⅲ-4 | 공을 볼 때 빛의 경로 (태양 → 공(반사) → 눈) |
| 스스로 평가 | 1. 빛이 (반사 / 굴절)할 때 입사각과 반사각의 크기는 항상 (같다 / 다르다). 2. 우리가 촬영 중인 대상을 보는 과정을 반사판을 포함하여 빛의 경로로 설명 |
| 친구에게 설명 | "우리는 어떤 과정으로 책을 볼 수 있을까?" |
| 평가하기 | 지식·이해: 빛의 반사와 굴절을 이해할 수 있다. 과정·기능: 빛의 반사 실험에서 입사각과 반사각 사이의 규칙성을 추리할 수 있다. 가치·태도: 실험을 하며 빛의 성질에 흥미를 느낄 수 있다 |
| 디지털 ON | 'AR 빛 실험실' 앱 (웹에는 넣지 않음) |

- 각도는 ° (30°, 45°, 60°)
- 띄어쓰기: '빛의 반사 법칙', '반사면과 수직인 선', '경계면과 수직인 선', '반원 통'

## 4. 사용 금지 (넘기 쉬운 것)
- 굴절률, 스넬 법칙, sin, 빛의 속력 비교(물속에서 느려진다), 전반사, 임계각
- 법선이라는 말 (교과서는 '수직인 선'으로 씀)
- 정반사·난반사(교과서 다음 차시인지 미확인 → 쓰지 않음), 상(像), 평면거울의 상, 볼록·오목 렌즈, 빛의 합성, 색
- 눈의 구조(수정체, 망막, 시신경)

## 5. 정성적으로만 다루는 것
- 굴절 시뮬레이션의 꺾이는 정도는 실제 물(공기→물)과 비슷하게 그리지만, 계산식은 보이지 않는다. 각도기 눈금으로 읽은 굴절각은 실험 기록처럼 정수 °로만 보여 준다.
- '광원에서 나온 빛은 사방으로 퍼져 나간다'는 빛 알갱이·광선 여러 개로 보여 준다(수치 없음).
- 오개념(눈에서 빛이 나온다 / 광원이 아닌 물체에서 빛이 직접 나온다)은 교과서 문장(빛이 눈에 들어와야 한다, 광원에서 나온 빛의 일부가 물체에 반사되어 눈에 들어온다)과 해 보기 결과로만 반박한다.

## 6. 미확인
- 공기에서 물로 비스듬히 들어갈 때 '경계면과 수직인 선 쪽으로 꺾인다(굴절각이 입사각보다 작다)'는 교과서 그림 Ⅲ-2와 탐구 질문의 기대 답으로 보이지만, 본문 문장으로는 없음 → 시뮬레이션의 관찰 결과로만 보여 주고 퀴즈에는 '꺾인다'까지만 냄
- 수직으로(입사각 0°) 비추면 꺾이지 않고 그대로 들어간다: 교과서 정의의 '비스듬히'에서 끌어낸 것 → 시뮬레이션에서 보여 주기만 함
- 반원 통의 둥근 면을 지날 때 꺾이지 않는 것(중심을 향한 빛): 실험 장치 설명으로만 씀
- 야광 물체를 광원처럼(스스로 빛을 냄) 다룸: 교과서 해 보기 그림(덮어도 보임)에서 추론
- 교과서 출판사 → 화면에 쪽수를 넣지 않음
